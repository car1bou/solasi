# Mac UX 보호·필기·대본 검증 — 2026-10-17

## 적용한 동작

사용자가 승인한 여섯 개선을 기존 흑백 디자인과 로컬 보관함 위에 적용했다. UI UX Pro Max의 키보드 초점·오류 복구 지침으로 검토하고, grilling에서 합의한 원문·사용자 적용 정책을 유지했다. 구현은 ponytail 기준으로 기존 닫기 보호·설정 테이블·내보내기·출처 컴포넌트를 재사용했다.

1. **미저장 입력 보호:** 과목·기록·홈·설정 이동, 입력을 없애는 하위 탭·자료·결과 교체 전에 미저장 편집을 확인한다. 수정한 입력이 있으면 화면을 유지하고 해당 입력 이름을 알린다. 질문 지침·퀴즈 답안·모델 설정·API 키 입력에도 적용하며, 키를 별도 초안 파일에 저장하지 않는다. 같은 기록의 자료·노트와 보강 입력은 탭을 숨겨도 유지한다. 저장·초기 로드 응답이 새 입력을 덮지 않도록 입력 잠금과 중복 요청 방지를 보완했다.
2. **펜·보기 설정:** 펜과 형광펜의 색·굵기·불투명도, 지우개 크기, 마지막 도구는 기기 설정으로 기억한다. 배율·회전·메모 패널은 자료 ID와 원본 SHA별로 기억한다. 새 자료는 폭 맞춤이며 사용자가 고른 수동 배율은 유지한다. 기존 잉크 좌표·압력·색은 변경하지 않는다.
3. **정상 내보내기:** 페이지 헤더의 `메모·필기 JSON 내보내기`를 정상 저장 상태에서도 제공한다. 전체 원본 SHA·페이지·기준 revision·저장/초안 상태·현재 메모·잉크를 포함한다. Mac 저장 완료와 사용자 취소를 구분하고, 브라우저 검증에서는 다운로드 요청 시작으로 안내한다.
4. **대본:** 대본의 Tab 진입점을 하나로 줄이고 방향키·Home·End로 문장을 이동한다. Enter·Space 선택 시 듣기 버튼으로 초점을 옮긴다. 클릭·드래그는 초점을 강제로 옮기거나 자동 재생하지 않는다. 수정 취소는 `계속 수정 / 수정 취소 확인`으로 구분한다. 원래 전사·버전·시각·원음 연결은 유지한다.
5. **요약 원문:** 강의와 과목의 요약 모두 처리 원문 수·최종 인용 수·불완전 선택·미인용 원문·구간 요약을 같은 컴포넌트로 표시한다. 처리량이 의미적 누락 없음의 증거는 아니다.
6. **재연결:** 최초 실패 시 실제 연결과 목록 조회를 다시 실행한다. 재시도 중에만 연결 중으로 표시한다. 네이티브 상태 초기화 실패에도 재시도 버튼을 제공하고, 개발용 연결의 실패한 Promise는 재사용하지 않는다.

회차 노트·대본·질문 등의 일반 입력을 새 자동 저장 시스템으로 바꾸지는 않았다. 정상 이동·종료를 보호하며, 사용자가 저장하거나 명시적으로 되돌린 뒤 이동한다. 강제 종료·OS 장애에서 모든 일반 입력의 복원을 보장하지 않는다. 페이지 메모·필기는 기존 지속 초안·복구 저널을 사용한다.

## 화면 조작 검사

현재 컴퓨터 사용 도구는 설치 앱의 WebKit 본문을 읽거나 촬영하지 못한다. 사용자는 이전 점검에서 실제 본문이 정상 표시된다고 확인했다. 이번 검증은 **설치 앱 기동·종료**와 **동일 프런트의 독립 합성 UI fixture**를 구분했다. 임시 fixture는 기존 bootstrap/cookie/CSRF를 유지한 localhost 테스트 환경이며 제품의 내장 실행 방식을 바꾸지 않는다. 사용자 보관함·실제 음성·외부 AI를 사용하지 않았다.

| 실제 수행한 조작 | 관측 |
|---|---|
| 최초 과목 조회를 합성 503으로 실패시킨 뒤 다시 연결 | 버튼 클릭 후 과목·기록 목록과 작업 버튼 복구 |
| 과목 질문 입력 후 요약 탭 선택 | 이동 차단, 입력 문자열 유지, 입력 이름 안내 |
| 대본 300문장에서 방향키·Enter 선택 | Tab 진입점 1개, 듣기 버튼 초점, 자동 오디오 0개 |
| 대본 수정 후 홈 선택 | 화면 이동 차단, 수정 입력 유지 |
| 대본 수정 취소 후 계속 수정 | 확인 UI 표시, 입력란 초점·수정 문자열 유지 |
| 회차 노트 수정 후 과목 이동 | 이동 차단, 노트 유지; 저장 후 과목 이동 가능 |

| 형광펜 굵기·150%·90°·메모 접힘 설정 후 다음 페이지 | 도구·굵기·배율·회전·패널 상태 유지 |

합성 재생 파일은 무음이다. 이 검증을 실제 한국어 ASR 정확도·새 모델 성능·마이크 장시간 검증으로 해석하지 않는다. 설치 앱의 저장 대화상자 클릭, 실제 펜 장치, VoiceOver 전체 흐름, 모든 화면의 시각 검증은 수행하지 못했다.

## 실제 동결 엔진과 설치 앱

- 앱: **0.3.4 / build 14**, 기존 보관함·runtime 경로 유지, 이전 앱 백업 보존.
- 내장 엔진: `frozen-engine-v9`, SHA256 `60eecf960c8133904cff0e0fa1df90e0402c7a8aca4f78c30714ec433d01abea`.
- 엔진 manifest의 7,766개 파일 검증과 frozen self-check 통과. 새 환경설정은 기존 `settings` 테이블의 제한된 키에 저장하며 테이블·스키마를 추가하지 않는다.
- 별도 합성 보관함·빈 runtime에서 실제 파이프 프로세스를 두 번 실행했다. 설정 PUT/GET 후 정상 종료·재실행 GET이 일치했다. 잘못된 키·값·회전·4KiB 초과 4건은 422로 거절하고 기존 값을 보존했다.
- 원문·잉크 1획·이전 사본·추가 필드를 포함한 444,538바이트 초안과 복구 저널 두 행을 재실행 후 대조했다. 34 ACK, 두 프로세스 모두 exit 0, 잔류 자식 0. 네트워크 표본 6개에서 소켓 없음. 모델 호출 없음.
- 설치한 프런트 파일은 최종 빌드와 바이트 단위로 일치했다. 앱과 소유 엔진의 네트워크 소켓을 발견하지 못했고 정상 ⌘Q 뒤 두 프로세스가 종료됐다.
- 사용자 저장·종료 확인 후 보관함 기준을 만들고 새 앱 기동·종료 뒤 대조했다. **43개 테이블·86개 스키마 항목·원음과 연결 자료 18개 모두 동일**, 누락 파일 0, integrity/foreign key 검사 통과.

원음·DB·전체 파이프 응답·합성 UI 데이터·개인 경로를 담은 상세 증거는 Git에서 제외한 로컬 검증 폴더에 보관한다.
