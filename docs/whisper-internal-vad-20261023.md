# 고정 분할에서 Whisper 내부 VAD 켜기·끄기 비교

2026-10-23 · Mac 로컬 Whisper large-v3-turbo

## 적용 판정

**내부 VAD를 끄는 조건을 제품 기본 경로에 적용하지 않았다.** 개별 발화의 삭제·삽입·전체 오류, 소음·SIL 출력, 처리 실패를 기준과 대조했다. 합계 개선으로 다른 조건의 악화를 상쇄하지 않는다. 실제 누락·환각이 해결됐다는 판정이 아니다.

이번 main 변경은 기존 비교기의 VAD 선택 옵션·검사·비식별 집계·보고서다. 제품의 기본 설정·재전사 후보 정책·실제 설치 앱·기록·원음·필기·초안·완료 전사·수동 수정·과거 출처는 바꾸지 않았다.

## 고정한 조건

- [이전 발화 경계 비교](speech-boundaries-20261023.md)와 같은 16개 파일을 사용하고, 원래 에너지 분할 91개를 그대로 고정했다. 겹침·전처리·구간 재배치·별도 VAD gate는 없다.
- 두 조건 모두 같은 실제 PCM 범위, Whisper 모델, 한국어, 빈 힌트, 확정 전사 디코더를 사용한다. 내부 VAD 켬은 기존 1000ms padding·최소 발화 250ms를 유지하고, 끔은 native `--vad`·VAD 모델·padding·최소 발화 옵션을 모두 전달하지 않는다.
- 비교 실행 전 원음·provenance·경계·코드·모델을 고정했다. 두 결과에 동일 manifest SHA와 VAD 조건을 기록하고, 실제 실행 중인 이 작업의 자식 프로세스에서 native 옵션도 각각 관찰했다.
- 정확히 모든 PCM 값이 0인 구간은 기존 비교기처럼 두 조건에서 똑같이 생략하며 기록에 표시한다. **이번 91개 구간에는 해당 디지털 영점 입력이 0개다.** 실제 비영점 SIL과 생활 소음을 모델에 모두 전달했다.
- `--vad`는 기본 켬, `--no-vad`는 끔이며 새 옵션을 생략한 기존 경계 비교 호출은 이전처럼 VAD를 켠다. 끔 단독 실행에서는 VAD 가중치 검증을 요구하지 않지만 Whisper 모델 검증은 유지한다.
- 원래 인식문과 문장 시각을 보존하고, 문구가 같다는 이유로 삭제하지 않는다. 시각은 선택한 원본 WAV 시간축으로 환산한 native 문장 시각이며 단어별 정렬은 아니다.

## 실제 자료와 정답 범위

| 자료 | 조건 수 | 정답 범위 |
|---|---:|---|
| 실제 한국어 기술 강연 2개, 각 약 2분 | 원본·사무실·식당 6 | 검수 자동 자막. 완전한 축어 정답 아님 |

| 비영점 SIL 주석 원음 | 3 | 짧은 비발화 대조, 각 단일 구간 |

총 약 37.9분의 파일 조건이다. 같은 원음의 소음 대응본을 독립 화자·녹음으로 세지 않는다. 환경 소음을 섞은 발화는 파생 혼합 조건이며, 실제 소음 현장에서 새로 녹음한 강의·회의라고 부르지 않는다. 긴 대화의 식당 소음은 기존 300.004초 환경음이 반복되지만 실제 사람 발화는 반복하지 않았다. 65초 환경음 대조는 원래 연속 구간이다. [자료·출처 기록](lecture-material-hints-20261020.md)을 재사용했고 새 모델·음성·의존성 다운로드는 없다.

## 측정 방법

수동 정답과 검수 자막은 NFKC·소문자·문자/숫자 정규화 후 문자 편집 거리·삭제·삽입·치환으로 비교한다. 문자 삭제·삽입 수는 실제 단어 누락·환각 사건 수가 아니며, 자막 표기와 머뭇거림 편집 차이도 영향을 준다.

긴 대화의 전체 CER는 계산하지 않는다. 주석 시각에 걸치는 모델 문장을 이어 응답자 정답 구절의 연속 일치·반복과 기준에서 사라진/새로 일치한 구절을 부분 진단한다. 표기·분절·시각 차이도 일치 수에 영향을 주므로 단어 삭제 사건으로 단정하지 않는다. native 문장 전체가 SIL 주석 안에 들어간 경우만 세며, 일부만 걸친 문장의 단어는 판정하지 않는다.

인접 입력 구간의 마지막·첫 문장에서 정규화 suffix/prefix 4자 이상이 일치하면 경계 반복 후보로 기록한다. 실제 발화 반복일 수 있어 자동 제거하지 않는다. 입력이 겹치지 않으므로 이전 겹침 시험처럼 시각 겹침을 후보 조건으로 요구하지 않는다.

## 코드·검증·보존

- VAD 끔이 실제 native 명령 옵션에 도달하고 VAD 자산 없이 실행되는 검사, 디지털 영점의 동일 처리·표시, 잘못된 조건 거절의 RED→GREEN을 확인했다.
- 관련 19개, Python 670개 중 665개 통과·선택 5개 생략, 프런트엔드 104개·TypeScript·CLI·링크·diff 검사를 확인했다.
- 새 기준 실행 16파일의 인식문과 native 문장 시각이 이전 기준과 모두 일치했다. 원음·provenance·실행 코드·모델·VAD·runtime·기록 로그 해시를 대조했다.
- 별도 QA 보관함에서 이번 기준 디코더 출력을 실제 파일 등록·저장 경로에 재생했다. PCM 5구간·전사 21개의 텍스트와 시각, 수정 전 source snapshot 21개 보존과 DB integrity `ok`·FK 오류 0을 확인했다. 추가 ASR·설치 앱 GUI 검증으로 부르지 않는다.
- UI UX Pro Max의 파괴적 변경 방지 기준에 따라 기존 수정·원음·과거 출처를 그대로 두었다. 새 UI나 검증되지 않은 정밀 시각을 추가하지 않았다.

[본문·경로 없는 개별 집계](verification/whisper-internal-vad-20261023.json)에 조건별 원음 해시·고정 프레임 경계·완료 입력 해시·삭제/삽입·부분 참조·시각 검사·실제 native 옵션 관찰·시간·적용 판정을 남긴다. 원음·정답·인식문·모델·개인 보관함은 공개하지 않는다.

## 재현

같은 고정 manifest와 준비된 runtime을 사용하고 각 조건마다 새 출력 파일을 지정한다. `--overlap-ms 0`은 원래 분할을 유지한다.

```sh
.venv/bin/python experiments/compare_chunk_context.py \
  --manifest /absolute/path/to/fixed-manifest.json \
  --runtime /absolute/path/to/prepared-runtime \
  --overlap-ms 0 --vad \
  --output /absolute/path/to/new-vad-on.json

.venv/bin/python experiments/compare_chunk_context.py \
  --manifest /absolute/path/to/fixed-manifest.json \
  --runtime /absolute/path/to/prepared-runtime \
  --overlap-ms 0 --no-vad \
  --output /absolute/path/to/new-vad-off.json
```

완료 파일의 비교가 실시간 preview·실제 packet gap·마이크·절전·강제 종료 복구까지 검증한 것은 아니다. 제품의 전역 VAD 기본값을 바꾸지 않았다. 모든 경계를 직접 청취하거나 불완전 정답의 전체 대화 정확도를 확정한 결과는 아니다.
