# 문장 내부 전사·긴 요약·동시 실행 검증

후속 개선과 같은 입력의 새 실행은 [재전사 후보·무음·요약 검증](fidelity-followup.md)에서 확인한다. 아래는 이전 단계의 기록이다.

2026-10-15 · Apple M4, 16GiB. 설계 검토는 grilling, 구현은 Ponytail로 진행했다. 외부 API·새 모델 다운로드·원격 GPU를 사용하지 않았다. 음성·전사 본문은 로컬 시험 폴더에 두고 이 문서에는 집계·해시·재현 경로만 기록한다.

## 적용한 변경

- **실시간 잠정 인식은 10초 간격**으로 요청한다. 기존 약3초 간격보다 화면의 임시 문장 갱신은 느려진다. 확정 전사·원음 저장·기본 `after_stop` 흐름은 유지한다. 실행 중 생성은 유지하고 확정 전사가 밀리면 새 로컬 요청을 대기시킨다.
- 짧은 말이 과도하게 반복되는 인식도 원음 확인 후보로 표시한다. 실제 반복·웃음일 수 있으므로 삭제하거나 더 긴 인식문을 자동 채택하지 않는다. 기존 최대1회 재인식·사용자 적용 정책을 따른다.
- 새 로컬 일반 요약·회의록의 구조화 생성은 `temperature=0`, `presence_penalty=0`을 명시한다. 설치된 Qwen 기본값은 각각1과1.5였다. 반복 억제가 원문 복사 작업에도 적용되던 조건을 제거했다. 이 두 설정의 독립적인 효과나 모든 의미 오류의 해결을 주장하지 않는다.
- 주어 복사는 근거 원문의 정확한 구절을 요구한다. 띄어쓰기만 다르면 유일한 실제 원문 구절을 복구한다. 조사·철자·숫자는 추측해 바꾸지 않는다. 조건절에서 주어 명사를 임의로 잘라내는 구현은 반례 확인 후 제외했다.
- 강의의 명확한 가정·조건·예시는 그대로 보존한다. 조건절을 사실로 바꾸거나 전제·부정·적용 값을 잃은 생성문은 원문으로 대체한다. 조건절 전체를 주어 칸에 복사해 요약문과 맞지 않는 경우도 원문을 유지하고 **원문 가정·조건 발췌 / 생성 요약 확인 필요**로 표시한다. 이 확인 표시는 원문 조건의 불확실성 판정이 아니다.
- 회의에서는 제목·설명에 숨은 담당 확정 표현도 검사한다. 모델이 인용 ID 순서를 바꿔도 원래 시간순으로 후반 정정을 검사한다. 담당을 확정하는 사람을 담당자로 바꾸는 명시적 목적격 반례와 소유 표현을 행위자로 바꾸는 반례도 보호한다. 강의에서도 평소 행동을 원문에 없는 확정 결정으로 바꾼 설명은 발췌로 남긴다.
- 회의록 기한은 실제 ISO 날짜와 원문의 `날짜+까지`를 함께 허용한다. 날짜 인용의 공백 차이만 인용한 전사의 정확한 구절 하나로 복구한다. 복구 함수는 전달된 기한 표현의 숫자·단어·조건절을 바꾸지 않는다. 모델이 처음부터 조건을 빼고 짧은 날짜만 인용하는 의미 오류까지 검출하지는 못한다.
- 생성 설정·회의록 지시는 새 작업에 고정하고 병합 캐시 서명에 포함한다. 기존 작업의 설정은 유지한다. 실험의 map 재사용도 완료된 보고서의 동일한 요청·원문·분할·지시·모델 설정·현재 후처리를 확인한 경우에만 허용한다. 실패 보고서 재사용 우회는 제거했다.

검사는 한국어의 일반 의미 함의를 증명하지 않는다. 이름·인용이 맞아도 행위의 방향이나 관계가 틀릴 수 있고, 보수적 검사 때문에 올바른 패러프레이즈가 발췌로 남을 수 있다.

## 같은 사람 음성 90조건

[집계와 입력 해시](verification/sentence-asr-20261015.json). 기존 동일 음성·생활 소음 조건84개와 공개 성인 인터뷰의 수동 정답6개를 사용했다. 조건이 다른 동일 발화가 포함되므로 90명의 독립적인 화자로 해석하지 않는다. 정규화는 NFKC/소문자/문자·숫자만이며 맞장구·반복은 유지한다.

| 모델 | 편집 / 정답 글자 | CER | 치환 / 누락 / 삽입 |
|---|---:|---:|---:|
| 현재 Whisper large-v3-turbo |185 /1829|10.11%|88 /86 /11|
| 기존 설치 Qwen3-ASR1.7B4bit|137 /1829|7.49%|95 /29 /13|

Qwen은28조건에서 개선,15조건에서 악화,47조건에서 동률이었다. 방/실내 소음의 일부 조건은1→7편집으로 악화했다. **제품 기본 ASR을 바꾼 결과가 아니다.** Qwen의 시간 정렬·실제 제품 경로 검증은 남아 있다. 두 실행은 모델 상주 방식이 달라 처리 시간의 공정한 속도 순위를 산출하지 않는다. 삽입 편집 수는 의미적 환각률과 같지 않다.

Whisper의13개 고정 진단 조건에서 beam8은38편집으로 기본과 같았고 greedy는39편집이었다. 검증하지 않은 디코더 설정으로 기본값을 바꾸지 않았다. 토큰 점수0.2미만은 정답이 맞는32개 비어 있지 않은 출력 중1개, 틀린49개 중2개에만 있었다. 생성된 토큰의 점수로 **빠진 단어의 정확도**를 판단할 근거가 부족해 점수만으로 자동 후보 범위를 넓히지 않았다. 문장 내부 누락·환각 자체는 아직 남아 있다.

재현(이미 준비된 음성·모델만 사용, 결과는 전사 본문이 포함되므로 로컬 경로):


## 11분 브라우저 녹음 + 실제 전사·생성

[전체 집계·실패 포함](verification/sentence-browser-20261015.json). 입력은 같은666.3299375초 성인 인터뷰와 실제 사무실 소음의10dB 파생 혼합이다. 인터뷰어/응답자 대화이며 전체 발화·화자 정답이 완전한 회의 자료는 아니다. 동일 SHA256 `f2853174c62403390654010eac174f1a30af64893ff991179954e98316e700cc`를 실제 속도로 브라우저에 재생했다. 저장·worklet·Whisper·Ollama는 실제 경로이며 물리 마이크는 사용하지 않았다. 생성은 동일한 작성 노트에 대한 질문11건으로 부하를 만들었다.

## 같은 긴 음성의 요약·병합

[실행·최종 검사 집계](verification/sentence-summary-20261015.json). 같은 인터뷰179전사+작성 메모1개와 낭독292전사+작성 메모1개를 사용했다. 세 실행 사이의 전사 ID·본문·시각 일치를 검사했다. 낭독 입력은878.304초이며 요청 cutoff는876.050초다.

| 자료 | 기존 설정의 새 생성 | 원문 복사 설정의 새 생성 | 최종 검사 후 항목 / 확인 발췌 | 직접 인용하지 않은 원문 단위 |
|---|---:|---:|---:|---:|
| 인터뷰666.33초|219.532초,7호출|258.374초,7호출|39 /36|26→6|
| 낭독878.30초|272.382초,9호출|517.152초,9호출|60 /39|49→53|

- 두 자료 모두 병합 선택에서 빠진 구간은0개였고, 처리한 전사 시간 범위와 최종 인용의 원문 부분 문자열을 검증했다. 인터뷰의 본인 성장담·부모 사망 가정·후반 건강 발언과 낭독의 후반 냉수 요청·쓰러짐·방 이동·퇴장 구절은 원문 인용/발췌에 남았다. 단순한 단어 검색을 사건 전체의 의미 보존으로 취급하지 않는다.
- 실제 생성 후 발견한 주어·결정 검사 보완은 **동일한 실제 모델 응답을 최종 제품 검사·저장 경로에 재생**해 확인했다. 각7/9호출의 모델 입력 메시지·스키마가 원래 native 실행과 정확히 같음을 검사했고, 최신 후처리로 다시 계산해 저장 결과가 같음도 확인했다. 이 재생의0.958/2.230초는 새 모델 추론 또는 전체 요약 시간으로 사용하지 않는다.
- 인터뷰의 요약문은 확인용 발췌가 많다. 발언 성격 라벨과 인물 관계를 포함한 의미 오류가 여전히 남는다. 낭독도 확인 발췌가39/60항목이며, 원래 ASR 오탈자가 요약에 그대로 이어지는 경우가 있다. 발췌 보존과 자연스러운 요약 품질을 구분한다.
- 원문 복사 설정에서 낭독의 출력량이 늘고 실제 생성 시간도 길어졌다. **긴 요약 지연의 해결이나 전체적인 속도 향상을 주장하지 않는다.** 이 비교는 프롬프트·스키마·sampling·공유 호스트 상태가 달라 각 변경의 효과를 분리한 시험이 아니다.
- 미인용 원문 단위 수는 직접 인용 범위의 보조 지표다. 낭독은49→53으로 증가했으며 별도 원문 목록과 경고를 유지한다. 이 수를 의미적 누락률로 해석하지 않는다.

### 실제 모델의 작성 문장 대조

수동 작성한 전사를 넣어 일반 요약과 회의록을 따로 확인했다. 음향 인식 시험이 아니다. HTTP payload6호출에서 `temperature=0`, `presence_penalty=0`이 실제 전송됐음을 확인했다.

- **회의록:**108.590초,구조·인용 검증 및 내용 대조7개 모두 통과. 후반3대/4대 정정·취소·미확정·로컬 조건, 담당 후보 배제, 명시 담당자와 ISO 기한을 보존했다.
- **일반 요약:**71.527초,구조·인용 검증 통과. 예시·정정 등6개 대조는 통과했으나 명확한 가정의 자연스러운 요약 검사는 실패했다. 모델이 조건절 전체를 주어로 복사해 **원문 가정·조건 발췌 / 생성 요약 확인 필요**로 남았다. 결과를 `all_checks=true`로 바꾸지 않았다.
- 초기 시행의 빈 항목 인용 실패, 기한의 `날짜+까지` 검사 실패와 공백 차이 실패도 집계에 보존했다. ISO 기한만 원문 구절로 복구하는 수정 후 최종 회의록이 완료됐다. 사람 이름·일반 문장을 추측해 수정하는 경로는 만들지 않았다.
