# 솔라시 초기화와 기본 사용법

Mac 0.3.43/build53 기준. 초기화는 앱을 남겨 둔 채 원래 보관함·수정 이력, 설정, 저장된 API 키, 전용 다운로드 모델과 추가 엔진, 앱 캐시·로그를 정리하는 기능이다.

## 초기화하기

1. 녹음과 실행 중인 작업을 마치고 **설정 → 앱 초기화…**를 누른다.
2. **필기·문서 / 녹음 / 전사·AI 결과**에서 각각 **보존** 또는 **삭제**를 선택한다. 처음에는 모두 보존이다.
3. 보존 자료를 둘 폴더를 고른다. 그 안에 새 `Solasi 보관자료-…` 폴더가 만들어지며 기존 파일은 덮어쓰지 않는다.
4. 보존 파일 생성과 검증이 끝날 때까지 기다린다. 누락·손상·저장 공간 문제 등이 있으면 실행 단계로 넘어가지 않는다.
5. 마지막 화면에서 선택 범주, 파일 수·위치, 초기화 대상을 확인한다. **보존 폴더 열기**로 파일을 살펴볼 수 있다. **선택 변경**을 누르면 이전 선택을 유지해 돌아가며 새 보존·검증을 진행한다.
6. 실행할 때만 **솔라시 초기화**를 정확히 입력하고 **초기화 실행**을 누른다. 여기서 앱이 종료되고, 도우미가 검증 후 정리한다.
7. 완료 안내에서 **솔라시 다시 열기**를 누른다. 빈 보관함으로 시작한다. 결과 보고서는 보존 폴더에 남는다.

**보존**은 앱 없이 읽을 수 있는 사본을 남기는 선택이다. 원래 앱 보관함을 그대로 유지한다는 뜻은 아니다. 초기화를 실행하면 원래 보관함과 편집 이력은 제거된다. **삭제**를 고른 범주는 보존 사본을 만들지 않는다.

| 범주 | 보존 파일 |
| --- | --- |
| 필기·문서 | 필기가 그려진 열람용 PDF, 원본 문서, 메모·인식문 등 텍스트 |
| 녹음 | 일반 재생기로 열 수 있는 원음 파일 |
| 전사·AI 결과 | 전사, 현재 결과·퀴즈·응답 등을 담은 TXT/Markdown |

PDF는 열람용이다. 원래 필기 편집과 수정 이력의 복원을 보장하는 백업은 아니다. 이미 만들어진 보존 폴더와 외부 원본, 별도 백업, 공유 도구·소유가 확인되지 않은 실험 자료는 정리하지 않는다.

## 초기화 후 준비와 평소 사용

- **설정 → 엔진·OCR 준비 → 엔진 설치·관리**에서 녹음 전사·OCR·자료 추출 등 사용할 기능의 준비 상태를 확인하고 필요한 항목을 다시 준비한다.
- **설정 → 로컬 AI 준비 → 모델 설치·관리**에서 사용할 모델의 용량·라이선스를 확인하고 다운로드한다. 다운로드한 전용 모델은 초기화로 지워지므로 AI 기능을 다시 쓰려면 재준비가 필요하다.
- 외부 AI 제공자를 사용할 때는 **AI 실행**에서 제공자를 고르고, **서비스별 API 키 관리**에서 해당 키를 다시 연결한다.
- 왼쪽 **과목 추가**로 과목을 만든다. 과목의 자료 화면에서 **자료 연결**로 PDF·이미지·텍스트를 추가하고 열어 필기한다.
- 과목의 **새 강의 기록**으로 강의를 만들고 녹음·전사와 결과 정리를 사용한다. 과목과 무관한 회의는 **회의 기록**에서 시작한다.

## 초기화와 설치 삭제의 차이

| 항목 | 앱 초기화 | 설치 삭제 |
| --- | --- | --- |
| 솔라시 앱·내장 기본 엔진 | 유지 | 제거 |
| 원래 보관함·편집 이력 | 제거 | 제거 |
| 전용 다운로드 모델·추가 엔진·설정·저장 API 키 | 제거 | 제거 |
| 선택한 범주의 독립 보존 파일 | 먼저 생성·검증 | 먼저 생성·검증 |
| 최종 확인 문구 | 솔라시 초기화 | 솔라시 삭제 |

준비 중 취소하면 원래 기록과 앱을 유지한다. 실제 정리가 시작된 뒤 일부 항목에서 실패하면 완료로 표시하지 않으며, 이미 삭제된 원본을 자동으로 되돌리지는 못한다. 보존 자료와 결과 보고서를 확인한다.
