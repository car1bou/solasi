# 공개 사람 음성 전사 검증

2026-10-13, Apple M4·16 GiB·macOS 27.0.1. whisper.cpp 1.9.5, multilingual base, CPU `-ng`, 기본 beam/best-of 5, Silero v6.2.0 VAD 기본값. 외부 AI/API로 음성을 보내지 않았다.

## 입력과 출처

[Google FLEURS](https://huggingface.co/datasets/google/fleurs)의 한국어 `ko_kr/test` 행 0·2·3·5·7. [논문 2.1절](https://arxiv.org/html/2205.12446)은 원어민 녹음과 추가 작업자의 검수 절차를 설명한다. 합성 음성이 아니다. 공개 행에 speaker_id가 없어 서로 다른 5명이라고 단정할 수 없다.

- 리비전: `70bb2e84b976b7e960aa89f1c648e09c59f894dd`.
- 라이선스: CC BY 4.0. 출처: Conneau et al. (2022), *FLEURS: Few-shot Learning Evaluation of Universal Representations of Speech*, Google FLEURS.
- 다운로드: WAV 5개만, 총 **50.88초·3,256,610 bytes(3.11 MiB)**. 전체 데이터셋은 다운로드하지 않았다.
- 원본: 16 kHz·mono·IEEE float32 WAV. FFmpeg로 필요한 PCM16 구간을 변환했다. 파일 연결 시 앱 데이터 폴더에 원본 복사 0건. 소프트웨어 녹음 재생 경로는 실제 입력한 PCM을 임시 검증 폴더에 저장하고 종료 후 제거한다.
- 모든 원본의 SHA256와 크기를 검증 전후 확인했다. 샘플별 해시·기준 전사·인식문·시간은 결과 JSON (로컬 검증 자료·공개본 미포함)에 보관한다.

## 검사 방법

1. 파일 연결: 실제 연결·검사·구간 변환·로컬 ASR·최종 저장을 실행했다.
2. PCM 재생: 각 원본을 48 kHz PCM16으로 변환해 250 ms 패킷으로 빠르게 입력했다. 저장 frame 수·누락·전사 시각 범위를 검사했다. 이 경로는 입력 종료 뒤 ASR을 실행한다.
3. 동시 처리: 작은 음량의 행 3(12.54초)을 인증된 ASGI WebSocket에 실제 재생 속도로 주입했다. 실제 로컬 ASR을 동시에 실행하고 잠정 전사→종료→확정 전사를 확인했다. 브라우저·실제 TCP 네트워크·마이크 입력 검증은 아니다.

CER은 기준 문자 대비 삽입·삭제·치환 횟수다. NFKC·소문자화 후 Unicode 문자/숫자를 남기고 공백·문장부호를 제거했다. `두/2`, `일만/1만` 같은 표기 차이도 오류로 계산한다. 전체 편집 수/전체 기준 문자 수로 합산했다. **공식 FLEURS 점수나 정확도 환산값이 아니다.**

## 결과

| 경로 | 편집 수 / 기준 문자 | 진단용 CER | 처리 시간 |
|---|---:|---:|---:|
| 파일 연결 5개 | 25 / 215 | **11.63%** | **3.240초** |
| PCM 재생 5개 | 24 / 215 | **11.16%** | **3.280초** |
| 동시 WebSocket 재생 1개 | 6 / 50 | **12.00%** | 종료 뒤 확정까지 **0.721초** |

파일/PCM 처리 시간은 연결·변환·저장·ASR 작업을 포함한 해당 실행의 합계다. 실시간 자막 지연이나 다른 PC의 성능 보장이 아니다. 동시 재생에서 51개 패킷·601,920frames 저장, gaps=[]·WAV/DB frame 수 일치, 잠정 문장 관찰, stop job=done. 매초 관찰한 최대 대기/처리 중 구간은 1개였다.

| 행·내용 | 길이 | 파일 CER | PCM CER |
|---|---:|---:|---:|
| 0·수치와 날짜 | 12.48초 | 7.55% | 7.55% |
| 2·동물과 지명 | 8.94초 | 15.15% | 15.15% |
| 3·여행, 작은 음량 | 12.54초 | 12.00% | 12.00% |
| 5·과학 | 9.90초 | 5.00% | 5.00% |
| 7·안내 | 7.02초 | 20.51% | 17.95% |

기준과 다른 실제 사례: `이란의 자그로스산맥 → 1안의 자그러스 3맥`, `겨울에 북발트해 → 저울의 북바이트 애`, 파일 경로의 `안전 경고 → 안정경구`. 최종 행 0의 2011년·2017년은 기준과 일치했다. 원음을 독립 청취하거나 전사 시각을 수동 정렬하지는 않았다.

## 발견한 결함과 수정

- 기존 고정 RMS≤0.01 판단은 작은 목소리 샘플을 무음으로 처리했다. 파일/PCM 전체 CER은 31.63%/31.16%, 행 3은 빈 전사였다. 0이 아닌 음성을 버리지 않도록 수정했다.
- 작은 소리까지 decode하자 거의 무음인 꼬리에서 기준에 없는 영상 안내 문장이 생성됐다. [Whisper의 네이티브 VAD](https://github.com/ggml-org/whisper.cpp/blob/v1.9.5/README.md#voice-activity-detection-vad)를 적용했다. 추가 모델은 885,098bytes, MIT이며 별도 Python 패키지를 추가하지 않았다.
- VAD만 적용했을 때 PCM 행 3을 3초 단위로 끊는 기존 음량 경계가 남아 `감사합니다`가 추가됐다. 고정 음량 경계를 제거했다. 정확한 digital silence 800 ms·최대 20초·종료·누락에서 구간을 닫고, 3초마다 잠정 전사를 갱신한다. 배경 잡음이 있으면 확정 전사는 최대 20초 구간과 처리 시간을 기다릴 수 있다.
- 최종 실행에서는 앞서 관찰한 추가 문장이 재현되지 않았다. 모든 환경에서 환각이 제거됐다는 의미는 아니다.
- 작은 음량 보존·문맥 분할·무음 꼬리·VAD 원음 시각·재시도에 회귀 테스트를 남겼다. VAD 적용 자체가 모든 인식 정확도를 높였다고 주장하지 않는다. VAD 전 파일 CER 9.30%보다 최종 11.63%는 높아졌다.

VAD: 리비전 `9ffd54a1e1ee413ddf265af9913beaf518d1639b`, SHA256 `2aa269b785eeb53a82983a20501ddf7c1d9c48e33ab63a41391ac6c9f7fb6987`. JSON의 문장 offsets만 사용하며 VAD 처리 후 token clock은 근거 시각으로 사용하지 않는다.

## 다시 실행

준비된 프로젝트 런타임과 해당 fixture가 있는 환경에서:

```sh
.venv/bin/python -m tests.evaluate_human_audio
.venv/bin/python -m tests.evaluate_live_audio
.venv/bin/python -m unittest discover -s tests -v
```

원본 다운로드 URL은 만료되는 signed URL이다. 고정 데이터셋 리비전·행 번호·해시를 보존했으며 전체 음성 corpus나 만료 URL은 저장소에 넣지 않는다.

## 미확인

짧은 낭독 음성 5개, 경로별 1회 결과다. 실제 강의·회의의 먼 거리·잔향·겹친 발화·장시간 입력·전문용어 정확도와 base 외 모델 비교는 미확인이다. 동시 재생의 TestClient는 기존 httpx 사용에 대한 Starlette 폐기 예정 경고를 냈지만 실행은 완료됐다. Windows·외부 AI 제공자 검증은 포함하지 않는다.


## 고유명사와 추가 모델 확인

사용자 지시에 따라 전사 품질을 우선하고 base를 최종 기본값으로 고정하지 않는다. 관련 이름만 힌트로 주는 조건부 실험에서 북발트해가 복구됐지만 이란·자그로스산맥은 안정적으로 복구되지 않았다. 모든 이름을 넣은 전역 힌트는 다른 과학 문장의 혼합물 인식을 악화시켰다. 정답을 보고 철자를 공급한 이 실험을 일반 ASR 점수로 쓰지 않는다. 힌트 조건 결과 (로컬 검증 자료·공개본 미포함).

공식 small을 무힌트로 같은5개에 적용했을 때 세 이름을 복구했고 진단CER은7/215=3.26%였다. 추가로 사전에 고정한20개 녹음(261.48초)에서는 base98/947=10.35%,small66/947=6.97%로 차이가 줄었다. small도 깁슨·제리·카탈로니아어·TMZ 등 오류가 남았다. 추가20개는19개고유기준문장이며 같은 문장의 다른 녹음이 포함됐다. 괄호 로마자·숫자 표기가 진단 CER에 영향을 준다.

Raon-Speech-9B,Komixv2,Whisper large-v3-turbo,Qwen3-ASR 후보는 별도 공식 조사·동일음성 직접 실행 결과로 비교한다. 현재 확정된 실행 결과와 아직 준비 중인 후보를 구분한다.
