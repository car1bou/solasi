# 원문 우선 로컬 답변 구현 계획

> 현재 세션에서 직접 구현한다. 사용자는 지침 비교 후 ‘원문 우선 답변·추가 해설은 선택’을 승인했다. 실패한 자유 답변 지침은 적용하지 않는다.

**목표:** 새 로컬 질문의 기본 결과를 원문과 출처로 제공하고, 생성 해설은 명시적인 추가 실행으로 구분한다.
**설계:** [승인 설계](../specs/2026-10-27-local-answer-grounding-design.md)
**구조:** 기존 원문 단위·문맥 보존·QuestionView·explain·작업 저장을 재사용한다. 모델·의존성·서버·동기화 기능은 추가하지 않는다.

## 보존과 검토 초점

기존 작업·기록·원음·필기·승인문·초안·키를 보존한다. 외부 API와 요약 경로를 유지하고, 과거 snapshot 재시도에 새 정책이 주입되지 않는지 확인한다. 모델의 원문 선택을 질문의 정답이라고 단정하지 않는다. 긴 입력의 단위별 메타데이터와 schema 비용, 추가 해설의 자동 실행 여부, 중첩 입력의 저장 보호, 실제 출처 시각을 검토한다. 다른 작업의 answers.py·outputs.py·UI 변경을 혼입하지 않는다.

## 실행

- [x] 동일 자료의 지침·반복 억제 후보를 비교하고 회귀가 있는 후보를 제외한다. 원문 발췌 요약 두 실행의 동일 본문과 주어·가정·후반 보존을 확인한다.
- [x] 원문 ID 선택·정확한 복사·잘못된 ID/중복/생성 문장 거절·빈 선택·불완전 경계 검사를 RED→GREEN으로 확인한다.
- [x] 제출 시점 정책 고정, 과거 snapshot과 고정 요청, 새 수동 해설, API/요약 유지, 실제 선택 입력 예산·내보내기를 RED→GREEN으로 확인한다.
- [x] 실제 동일 자료 12질문의 선택 결과를 확인하고 선택 누락·관련성 한계를 기록한다.
- [x] 관련 원문과 수동 추가 해설 UI를 빌드하고 전체 회귀 검사·독립 검토를 완료한다.
- [x] 현재 Mac UI와 데이터를 보존해 설치하고 질문·해설·출처·저장·재실행·내보내기를 검증한다.
- [x] 기존 행·파일 보존을 대조하고 이번 변경과 다른 작업을 분리한다.
