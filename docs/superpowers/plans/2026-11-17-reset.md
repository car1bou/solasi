# Solasi Mac 앱 초기화 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans inline; canonical status is in claude-mem work state.

**Goal:** 기존 안전한 보존/삭제 흐름을 재사용해 앱을 유지하는 초기화 기능을 추가한다.

**Architecture:** Python 보존 준비/계획은 그대로 유지한다. Native host가 검증한 계획을 reset 모드로 확정하고 다시 digest를 계산한다. Swift helper는 앱 snapshot을 검증용으로 유지하되 제거 대상에서 앱을 제외한다.

**Tech Stack:** 기존 Python 엔진, Swift/AppKit, React/TypeScript; 새 의존성 없음.

**Spec:** docs/superpowers/specs/2026-11-17-reset-design.md

## Global Constraints

- 사용자 실제 기록·키·모델을 초기화하지 않고 temporary fixture만 삭제한다.
- 검증된 보존 + 정확한 솔라시 초기화 입력 + 명시적 초기화 실행 전에는 삭제하지 않는다.
- 앱과 내장 엔진, 외부 원본/백업은 유지한다. 원래 기록·설정·전용 다운로드 모델/추가 엔진만 초기화한다.
- 기존 설치 삭제 및 deployed engine 코드는 유지한다. 무관한 diff를 변경/커밋/푸시하지 않는다.

## Review Focus

- reset/설치 삭제 문구·대상·확인 문구 혼용으로 앱 삭제가 발생하지 않을 것.
- reset 대상이 앱 번들 안에 겹치면 실패하고 앱은 byte-identical하게 유지할 것.
- 준비·취소·선택 변경이 원래 상태로 복구되고 receipt를 재사용하지 않을 것.
- 성공 후 새 vault가 생성될 수 있고 marker/잠금이 남지 않을 것.
- signed app/기존 실제 기록을 보존한 채 설치하고 모델 재준비 안내를 제공할 것.
