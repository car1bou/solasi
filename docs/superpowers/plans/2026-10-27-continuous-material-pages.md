# 연속 자료 보기 구현 계획

- 자료 페이지를 순서대로 표시하고 스크롤 위치에 따라 현재 페이지를 갱신한다. 페이지 선택과 좌우 방향키는 해당 페이지로 이동한다.
- 기존 페이지별 초안 저장소를 그대로 사용한다. 방문한 편집기는 유지해 인식문 초안과 충돌 상태가 사라지지 않도록 하고, 실행 취소는 현재 페이지에만 적용한다.
- 문서의 보기·도구 설정을 페이지 사이에 공유하고, 큰 문서는 보이는 페이지부터 불러온다.
- 여러 페이지의 메모·필기, 저장 실패, 인식문 초안, 단축키와 페이지 선택을 격리된 데이터로 확인한다. 빌드와 기존 테스트도 실행한다.
