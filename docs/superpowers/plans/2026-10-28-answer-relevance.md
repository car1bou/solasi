# Answer Relevance Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement task-by-task.

**Goal:** 실제 강의자료 비교를 통과한 원문 선택·근거 기반 해설 개선만 적용한다.
**Architecture:** 기존 ID 선택·원문 복사·작업 고정을 재사용한다. 과거 정책은 유지하고 새 정책만 분리한다.
**Tech Stack:** Python, 기존 Qwen3.5 4B 내장 worker, unittest.
**Spec:** docs/superpowers/specs/2026-10-28-answer-relevance-design.md

## Global Constraints

- 원문·기록·필기·초안·과거 작업을 보존한다.
- 외부 API·요약·다른 작업의 미커밋 변경을 보존한다.
- 실제 비교를 통과하지 않은 후보를 적용하지 않는다.

## Review Focus

- 선택 확대가 주어·부정·조건을 지우지 않는지 실제 출력과 테스트로 대조한다.
- 복수 요구의 후반 근거가 입력 예산에서 빠지는지 검사한다.
- 없는 사실을 묻는 질문에 무관한 원문을 정답처럼 제시하지 않는지 비교한다.
- 과거 snapshot·재시도에 새 정책이 소급되지 않는지 검사한다.
- 새로운 explain 지침과 실행 예산이 제출 시점부터 고정되는지 검사한다.

## Tasks

- [x] 공식 강의 PDF와 고정 질문에서 기존·후보를 실제 실행해 비교한다.
- [x] 통과한 후보의 동작과 과거 호환성 실패 테스트를 추가하고 먼저 실패를 확인한다.
- [x] 기존 헬퍼와 작업 정책을 이용해 최소 변경으로 통과시킨다.
- [x] 관련 회귀·전체 Mac 회귀를 실행하고 독립 최종 검토를 받는다.
- [x] 비교 기록·정확한 한계와 보존 증거를 기록하고 변경분만 main에 커밋·푸시한다.

## Rulings

- 큰 원문 단위화는 표시에 무관한 문장을 늘려 철회했다. 단위·출처·텍스트를 보존하는 metadata 묶기로 대체하고 동일 ID 선택의 표시 동일성을 검사했다.
- 새 해설 지침과 같은 모델의 검사기는 조건 누락·오판으로 제외했다. 검사를 더 붙였다는 이유로 정확도가 개선됐다고 보지 않는다.
- 같은 출처의 맞닿은 선택 범위만 합쳐 이중 문맥 표시를 없앤다. 실제 반복과 이전 정책·요약은 유지한다.
- 실제 GUI 설치는 이번 요청의 명시 범위에 없으므로 실행 중 앱과 보관함을 교체하지 않는다. 실제 내장 worker와 고정 자료·임시 DB로 비교한다.

## 검증 결과

- 실제 모델 비교 75회와 최종 실제 응답 9건의 표시 재구성을 기록했다. 이를 정답률로 표현하지 않는다.
- 격리 Mac 회귀 697개 중 696개 통과·1개 생략, 현재 폴더 관련 검사 17개 통과.
- 소스 선택의 모든 관련성·누락과 추가 해설 정확도는 여전히 미해결이며 이 계획을 목표 전체의 달성으로 해석하지 않는다.
