# 글상자·손글씨를 포함한 PDF 내보내기

## 목적과 범위

Mac Solasi에서 연결한 PDF 전체 페이지에 앱에서 저장한 T 글상자, 펜, 형광펜을 합친 새 PDF를 만든다. 기존 JSON 내보내기와 앱의 수정 가능한 필기·초안·출처·원본 파일은 유지한다. 외부 API나 새 모델은 사용하지 않는다.

## 승인된 동작

- 노트의 내보내기에서 PDF를 선택한다. 현재 페이지뿐 아니라 해당 자료 전체를 내보낸다.
- PDF 위의 글상자·펜·형광펜만 합친다. 페이지 밖의 메모와 인식 후보·승인문은 PDF 페이지에 추가하지 않는다.
- 저장이 끝난 페이지 버전을 모아 일관된 내보내기 스냅샷을 만든다. 현재 열린 자료에 미저장·실패·충돌 초안이 있으면 먼저 저장·해결하도록 안내하고 임의로 이전 버전을 내보내지 않는다.
- 내보낸 PDF에서는 글상자·필기를 페이지 내용으로 합친다. 앱의 원본 기록은 계속 편집할 수 있으며 PDF를 역으로 편집 가능한 Solasi 노트로 바꾸는 기능은 포함하지 않는다.
- 기존 Mac 저장 창과 새 파일 전용 저장 방식을 재사용한다. 원본 PDF나 다른 기존 파일을 덮어쓰지 않는다. 취소는 실패로 표시하지 않는다.
- 원본이 삭제·변경되었거나 접근할 수 없으면 내보내기를 중단한다. 생성 중 원본 내용이 바뀌어도 실패로 처리한다.

## 구현 접근 비교

1. 권장: 원본 PDF 페이지를 유지하고 Mac의 PDF/CoreGraphics 경로로 글상자·획을 합성한다. 원래 글자와 선명도를 보존할 수 있다. 페이지 회전·CropBox·글꼴·줄바꿈·필기 좌표를 실제 화면과 대조해야 한다.
2. 전체 화면을 이미지로 만들어 PDF에 넣는 방식은 구현이 단순하지만 원본 글자 선택·확대 품질이 떨어지고 파일이 커질 수 있어 기본으로 사용하지 않는다.

렌더링 세부 선택은 기존 코드와 실험 결과에 맞춰 정한다. 구현상 제약으로 위 동작을 바꿔야 한다면 먼저 설명한다.

## 검증과 보존

- 한글·영문·수식·빈 줄·긴 글상자, 펜 압력·형광펜 투명도, 여러 페이지, 회전된 원본과 서로 다른 페이지 크기를 비교한다.
- 생성된 PDF의 페이지 수·크기·원문 텍스트와 렌더링 결과를 확인한다. 빈 페이지와 필기 없는 페이지도 빠뜨리지 않는다.
- 미저장·충돌·원본 변경·저장 취소·기존 파일 보호를 검사한다.
- 실제 설치 Mac 앱의 분리된 검증 과목에서 필기·글상자를 저장하고 정상 종료·재실행 후 PDF를 내보내 확인한다.
- 이번 변경과 필요한 앞선 통합 노트·T 기반 변경만 별도 검토해 main에 반영한다. 함께 진행 중인 Windows·모바일·다른 AI 변경과 개인 자료·녹음·DB·모델은 커밋하지 않는다.

예: 12쪽 강의 PDF의 2쪽에 글상자와 펜 필기, 8쪽에 형광펜을 저장한 뒤 내보내면 12쪽을 모두 유지한 새 PDF가 만들어지고 2쪽·8쪽에 해당 내용이 보인다.
