# 과목·PDF·페이지 메모와 필기의 로컬 설계

날짜: 2026-10-15 (Asia/Seoul)

상태: 사용자 승인 및 추가 지시 반영. Mac 설치형 앱을 먼저 완성하고 이후 Windows·Android·iPadOS 앱으로 확장한다. 구현·검증 진행 상황은 별도 구현 계획에 기록한다.

## 1. 확정한 방향

- 각 기기는 자신의 자료·녹음·전사·메모·필기를 로컬에 저장한다.
- 드라이브·NAS·클라우드 동기화, Solasi 계정, 기기 페어링·원격 PC 작업함은 만들지 않는다.
- Mac·Windows·Android·iPadOS 설치형 앱을 대상으로 한다. 사용자는 Mac 완성 후 다른 OS 개발 순서에 동의했다. Mac에서는 AppKit + WKWebView 앱 창에 기존 화면을 표시하며 외부 브라우저를 앱 실행 화면으로 열지 않는다. 다른 기기판도 같은 로컬 저장 원칙을 따른다. 현재 Mac Python·MLX 환경을 모바일에서 그대로 실행할 수 있다고 가정하지 않는다.
- 과목 공용 PDF에 페이지 메모·필기를 누적한다. 강의 회차별 녹음·전사·일반 노트는 별도로 보존하고 페이지와 연결한다.
- 삼성노트는 공식 문서로 조작 흐름을 참고한다. REA 내부 구조 분석은 APK·설치 파일을 확보한 뒤 진행한다. 동일한 필기감·지연을 달성했다고 표시하지 않는다.
- 외부 AI API는 기존의 사용자 선택 기능이다. 로컬 자료 저장을 이유로 API 호출을 자동으로 켜거나 제공자를 바꾸지 않는다.

## 2. 사용자 흐름

```text
왼쪽: 과목 목록
  운영체제
    자료·필기
    강의 기록 목록
  다른 과목
회의 기록
미지정 강의 기록
모델·키 설정
```

1. 과목을 만들거나 선택한다.
2. 그 과목의 원본 PDF를 파일 접근 권한으로 연결한다. 강의 기록이 없어도 자료를 먼저 연결하고 열 수 있다.
3. PDF 페이지에서 메모·필기를 남긴다. 같은 과목의 다른 회차에서도 해당 페이지의 누적 내용을 연다.
4. 과목 안에 새 강의 기록을 만든다. 과목이 미리 지정되고 기존 기록·원음·노트는 보존된다.
5. 회의는 독립 기록 흐름을 유지한다. 기존 미지정 강의를 임의 과목에 자동 배정하지 않는다.

## 3. 자료·페이지 화면

- 자료 목록 → 원본 페이지 보기 → 페이지별 메모·필기 흐름으로 통합한다. 현재의 추출 Markdown 전문·OCR 항목 나열은 자료 화면에서 제거한다.
- 현재 추출기는 LiteParse다. 추출 텍스트·좌표·내장 그림은 내부 검색·페이지 설명·요약·근거 연결에 계속 사용한다.
- 페이지 번호와 원본 렌더링을 추출 성공 페이지 목록과 분리한다. OCR 실패 페이지도 원본을 열 수 있게 한다. 원본 자체가 열리지 않으면 파일 접근·손상 상태를 표시한다.
- 추출 실패는 설명·검색에 영향을 주는 상태로 표시하며, 이미 표시 가능한 원본 페이지·필기를 함께 막지 않는다.
- 중앙에는 원본 페이지, 옆에는 그 페이지의 텍스트 메모를 둔다. 좁은 화면에서는 메모 패널을 접어 페이지를 넓게 본다.
- 페이지 설명·요약·질문 결과는 사용자가 요청할 때 표시한다. 근거 확인 화면의 원문 발췌는 보존한다.
- TXT·MD와 이미지 자료의 기존 열기·검색 경로는 유지한다. PDF용 필기 도구를 텍스트 자료에 억지로 적용하지 않는다.

## 4. 메모·필기

기준 UX는 [공식 자료 조사](../../ink-research.md)에 정리했다. 다음은 Solasi의 독립 구현 범위다.

- 펜, 형광펜, 굵기·색·불투명도 조절.
- 획 전체 지우기와 부분 지우기.
- 올가미 선택, 선택한 획 이동·크기 조절.
- 실행 취소·다시 실행.
- 지원되는 펜 입력의 실제 필압·기울기·버튼을 활용한다. 마우스의 고정 압력 값을 센서 필압으로 표현하지 않는다.
- 펜 쓰기와 손가락 이동·확대를 구분한다. 취소·포커스 상실·입력 중단 뒤 다른 획이 이어 붙지 않도록 처리한다.
- 입력은 로컬 화면에 바로 표시한다. 전사·생성 작업이나 저장 응답을 기다려 획을 그리지 않는다.

텍스트 메모와 잉크는 PDF 원본을 수정하지 않고 앱의 별도 데이터로 저장한다. 문서 좌표·페이지 회전·배율을 기준으로 변환하여 확대·축소·창 크기 변경 후에도 위치를 유지한다. 각 획은 고유 ID·도구 속성·좌표·측정된 입력 정보를 가진다.

완료한 획과 메모 변경은 로컬 저장을 요청하고 실제 응답 뒤 저장 완료로 표시한다. 앱 웹뷰의 미저장 초안은 별도로 보존하고 앱 DB의 버전과 대조한다. 페이지 이동·기록 이동·창 종료 시 마지막 변경이 사라지거나 다른 페이지에 저장되지 않게 한다. 원격 동기화 큐는 만들지 않는다.

손글씨를 자동으로 정답 텍스트로 변환해 검색 색인에 넣지 않는다. 입력한 텍스트 메모는 검색 근거로 저장한다. 손글씨 OCR·AI 해석은 별도 기능으로 명시적으로 요청하고 결과를 확인하는 후속 범위다.

## 5. 데이터 경계와 기존 기록 보존

### 과목 자료

- `courses`, `sessions`, `assets`, `session_assets`의 기존 ID를 유지한다.
- 과목과 자료를 연결하는 관계를 추가한다. 기존 강의 기록에 연결된 자료는 해당 과목에도 연결하되 기존 연결은 보존한다.
- 한 PDF가 여러 과목에 연결되어도 원본·캐시는 공유할 수 있다. 페이지 메모·필기는 과목별로 구분하여 서로 덮지 않는다.
- 마지막 강의 회차를 삭제해도 과목 자료와 페이지 필기는 유지한다. 기존 파일 정리 조건에 과목 연결과 페이지 문서 소유 관계를 반영한다.

### 페이지 문서

- 과목 ID + 자료 ID + 실제 원본 문서 버전 + 페이지로 소속을 고정한다.
- 페이지 메모·잉크의 수정 버전과 근거 스냅샷을 보존한다. 기존 회차 전체 노트 저장 함수를 페이지별 메모에 그대로 사용하지 않는다.
- 원본 내용 해시·페이지 구조와 텍스트 추출 버전을 구분한다. 같은 원본을 재추출했다는 이유만으로 필기를 잃지 않게 한다.
- 실제 PDF가 변경되면 기존 필기를 이전 문서 버전에 보존한다. 다른 내용의 새 페이지 위에 기존 필기를 자동으로 덮어 표시하지 않는다. 이전 원본 파일이 없으면 메모·필기 기록을 보존하되 이전 PDF를 재현할 수 있다고 표시하지 않는다.
- 외부 원본 파일을 삭제하거나 덮어쓰지 않는다. 원본 이동·삭제·권한 거절·내용 변경 상태를 표시한다.

### 검색·AI·근거

- 해당 과목의 공용 자료와 페이지 텍스트 메모를 검색할 수 있게 한다. 회차 전사·회차 노트는 사용자가 선택한 회차 범위를 따른다.
- 과목 자료 화면의 설명·요약은 강의 회차가 없더라도 해당 과목·자료·페이지 범위를 고정해 요청할 수 있게 한다. 숨겨진 가짜 강의 기록을 만들지 않는다.
- 생성 결과는 요청한 과목 또는 회차에 소속시키고, 사용한 자료·메모 버전과 출처를 보존한다.
- 자료 소속 검사·그림 질문·개념 근거·내보내기·이전 근거 조회를 함께 수정한다. 화면에 파일만 보이고 검색·설명에서는 빠지는 상태로 끝내지 않는다.

## 6. 구현 경계

변경이 도달해야 하는 곳:

- DB 스키마·마이그레이션: 과목 자료, 페이지 문서와 버전, 과목 생성 결과, 검색 뷰.
- 백엔드: 과목 자료 연결·목록, 원본 페이지 메타데이터·렌더링, 페이지 저장·초안 복구, 자료 소속·삭제·검색·AI 근거 검증.
- 프런트엔드: 과목 탐색, 과목 화면, 강의 생성, 공통 PDF 뷰어·페이지 메모·필기 입력, 저장 상태·오류·좁은 화면 배치.
- 기존 동작: 회의, 회차 노트 보강, 근거 링크, 녹음, 모델 설정, 기존 API 결과와 인용 ID.

현재 코드를 읽고 공유 helper·컴포넌트를 우선 재사용한다. 원격 인증·클라우드 SDK·동기화 엔진을 의존성에 추가하지 않는다. 플랫폼 배포 틀을 바꾸기 전에 현재 Mac 앱에서 이 흐름과 데이터 보존을 확인한다.

## 7. 확인할 동작

아래는 수행한 검사 결과가 아니라 구현 시 확인할 항목이다.

1. 기존 기록·자료·노트·결과·근거 ID가 마이그레이션 뒤 보존된다.
2. 왼쪽 과목 선택 → 자료 연결 → 강의 생성으로 이어지며 과목이 바르게 지정된다.
3. 추출 실패 페이지도 원본이 렌더링 가능한 경우 열 수 있고, 추출 전문은 기본 화면에 나타나지 않는다.
4. 페이지·과목을 바꿔도 메모와 필기가 섞이지 않으며, 앱을 다시 열면 저장한 내용이 복원된다.
5. 배율·창 크기·회전·지우기·선택 변형·취소/재실행 후 좌표와 도구 속성이 보존된다.
6. 저장 실패·지연·연속 입력·동시 탭 편집에서 조용히 이전 내용을 덮거나 미저장 상태를 저장 완료로 표시하지 않는다.
7. 회차 삭제·자료 원본 교체·재추출 후 과목 자료와 이전 필기를 보존한다.
8. 과목 공용 자료·페이지 메모의 검색·설명·인용이 맞는 범위와 버전을 사용한다.
9. 녹음·전사·생성 중 과목 탐색과 필기 작업이 기존 작업을 뜻하지 않게 종료시키지 않는다.
10. 드라이브·NAS·기기 동기화 연결이나 자료 자동 업로드가 새로 생기지 않는다.

## 8. 검토·범위 상태

저장 범위·과목 공용 필기·REA 연기 결정은 사용자 답변으로 확정됐다. 위 화면·보존·소속 구조는 구현 전에 검토할 구체화다. 이 문서 승인 뒤 구현 계획을 작성한다. 다른 기기 설치판·필기감·장시간 모바일 녹음은 현재 Mac 구현과 별도로 검증해야 하며, 완료된 기능으로 표시하지 않는다.
