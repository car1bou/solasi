# 로컬 생성 모델 단일화

2026-10-27 · 사용자가 아래 범위를 명시 승인했다.

## 목적과 선택

사용자가 로컬 LLM을 고르는 부담을 없애고, 기존 Mac에서 검증한 Qwen3.5 4B만 로컬 생성·비전 모델로 제공한다. 모델들의 보편적 품질 우열을 선언하지 않는다. Gemma 12B에는 일부 수식의 개선 사례가 있었으나 긴 요약 우위는 확인하지 못했고 16GiB Mac에서 지연·메모리 부담이 컸다.

접근은 두 가지다. 화면만 숨기는 방법은 기존 설정·API·다운로드·Gemma OCR에서 다른 모델을 계속 요구한다. 승인한 방식은 **앱의 허용 목록·호출 경로·UI를 Qwen 4B로 통일하고 Gemma 두 모델의 파일까지 정리**하는 것이다. 미래의 모델 교체는 앱 업데이트의 책임이며 새 엔진 선택 시스템은 만들지 않는다.

## 동작

- 로컬 답변·요약·메모 보강·비전 입력은 Qwen 4B로 통일한다. 모델 ID 자유 입력과 다른 로컬 생성 모델 다운로드 선택을 제거한다. 외부 API의 제공자·모델 설정은 유지한다.
- Whisper/VAD·Qwen3-ASR 재인식, 기존 EmbeddingGemma 검색, Apple Vision 빠른 OCR은 별도 기능의 엔진으로 유지한다. 임베딩 데이터·승인·검색·필기 포맷은 바꾸지 않는다.
- 수식 대조 Gemma 버튼과 제품 실행 경로는 제거한다. Qwen 인식·Vision·원본 확인·승인은 유지한다. 비교 실험의 결과 문서는 역사적 기록으로 남긴다.
- 저장된 로컬 제공자 설정이 예전 모델을 가리키면 새 요청의 유효 설정을 Qwen으로 정규화한다. 외부 API 설정·과거 요청·결과·원문·모델 metadata를 재작성하지 않는다.
- 과거 삭제 모델의 같은 모델 재시도는 이해할 수 있는 오류를 반환한다. 사용자가 현재 로컬 AI로 새로 실행하면 새 작업을 만들고 과거 작업은 보존한다.

## 파일 정리·보존

사용자는 앱 전용 Gemma 12B·E2B의 영구 삭제를 승인했다. 전체 설치 manifest의 참조를 대조해 유지 모델과 공유하지 않는 blob만 고정 목록으로 정리한다. 현재 후보의 논리적 합계는 15,159,102,368 bytes이며 실제 회수 공간과 다를 수 있다. 재다운로드가 필요해짐을 안내했다.

삭제 전에 원래 manifest·파일 목록·해시/현재성을 기록하고 사용 중인지 확인한다. 유지 모델·ASR·임베딩·연결 자료·사용자 보관함을 보존한다. 모델 cache view는 symlink를 따라 원본을 중복 삭제하지 않는다. 승인하지 않은 다른 실험 모델·파일은 정리 대상에 넣지 않는다.

## 검증

API 설정·목록·다운로드 우회 차단, 이전 설정 정규화, 과거 작업 불변·새 Qwen 재실행, Qwen 텍스트·이미지·구조화 출력, Vision/승인·검색·필기 초안 회귀를 검사한다. 실제 Mac 격리 보관함과 새 frozen 엔진에서 실행하고, 설치 앱 교체는 미저장 작업이 없음을 확인한 뒤 진행한다. Gemma 파일 삭제는 기능 정리·보존 기준 대조 후 수행한다. main에 커밋·푸시하고 원격 SHA를 확인한다.
