# 원문 선택과 근거 기반 추가 해설

사용자는 2026-10-28 원문 선택의 관련성·누락과 추가 해설의 부정확성을 다양한 실제 강의자료에서 비교하고, 개선이 확인된 부분만 적용하도록 요청했다. grilling 질문에서 추가 해설도 자료로 직접 뒷받침되는 설명으로 제한하는 추천안을 승인했다.

## 접근과 범위

지침만 바꾸는 후보와 앱의 요약용 문맥 확장도 제한하는 후보를 분리해 비교한다. 후자는 관련 원문을 모델이 명시적으로 고르게 해 자동으로 끼어드는 무관한 문장을 줄이지만, 전제 누락 가능성이 있어 조건·부정·복수 요구의 보존을 함께 평가한다. 근거 입력 예산은 기존 순서에 따른 누락을 재현하고 개선된 경우만 변경한다. 추가 해설은 새 로컬 explain 작업에만 별도 지침을 고정한다. 자료에 없는 질문은 확보한 근거만으로 없다고 단정하지 않는다.

기존 원문·결과·실패 작업의 지침·요약·API는 보존한다. 새로운 모델이나 자동 검열·재생성은 추가하지 않는다. 전체 과정은 검증용 복사본과 고정 PDF에서 진행하고 다른 작업의 변경은 커밋에 포함하지 않는다.

## 확인 기준

공식 PDF 원본의 해시와 페이지, 실제 추출 문자열, 질문·입력·실제 모델 출력·시간을 저장한다. 관련 구간 선택, 필요한 조건과 요구 항목 보존, 무관한 표시, 해설의 사실·부호·증명·전제 오류를 따로 대조한다. 검증용 선정 페이지 시험을 전체 PDF 검색 성능으로 보고하지 않는다. 후보별 실패도 남기고 통과한 부분만 새 정책에 적용한다.

## 비교 후 채택 범위

원문 자체를 크게 묶는 후보는 관련성 회귀로 철회했다. 최종안은 선택 단위를 유지한 출처 metadata 묶기·자료 포함 입력의 질문 후치·같은 자료의 맞닿은 범위 병합이다. 기존 요약 함수는 변경하지 않는다. 새 로컬 answer만 answer-grouped-evidence-v2로 고정한다. 새 해설 지침과 자동 해설 검사는 실제 비교를 통과하지 못해 적용에서 제외한다. 해설 정확도와 모든 구간의 관련성·누락이 해결됐다는 요구 달성 주장은 하지 않는다.
