# 통합 PDF 노트와 화면 이동 재생 중단

사용자는 삼성노트·굿노트처럼 PDF 자체를 노트로 열어 한 도구막대·한 문서 보기 영역에서 연속 필기하려고 한다고 명확히 설명했다. 자유 캔버스에 PDF 객체를 놓는 해석은 철회한다. 자료·필기와 회차 노트는 같은 노트 화면에서 사용한다. 검색·개념은 기본 탭에 항상 표시하고 더보기는 세로 점 세 개로 바꾼다.

## 보존과 동작

- 기존 페이지 저장 키·revision·초안·승인·검색·과거 출처를 유지한다. 화면만 통합하고 페이지마다 도구·메모 UI를 반복하지 않는다. 공통 도구는 현재 페이지를 편집하며 연속 페이지는 같은 뷰포트에서 이동·확대한다.
- 회차 노트는 같은 화면에서 열고 기존 버전 저장소를 유지한다. 회차 내용을 과목 공용 페이지 메모로 옮겨 쓰지 않는다.
- T 도구로 PDF를 클릭해 편집 가능한 글상자를 만든다. 글상자는 정규화 페이지 좌표로 저장해 PDF와 함께 확대·이동한다. 텍스트는 직접 입력한 페이지 노트 근거로 사용하며 OCR 승인문과 혼동하지 않는다.
- 글상자는 기존 잉크 JSON의 독립 text annotation 형식으로 보존한다. 기존 펜·형광펜 JSON은 바꾸지 않는다. 기존 버전·초안·내보내기·충돌 처리 경로를 재사용한다. 손글씨 인식에는 펜 획만 사용한다.
- 화면 이동 성공 시 모든 화면 내 원음 재생을 멈춘다. 숨긴 화면의 늦은 metadata/연속 재생이 재시작하지 않게 하되, 이동이 미저장 입력 때문에 거절되면 현재 화면 재생을 유지한다.
- 원음 정리는 현 회차 전체의 앱 녹음을 삭제하고 외부 파일 연결만 해제한다. 실제 외부 원본·전사·노트·필기는 보존하며 확인 전 실행하지 않는다.

## 검증

탭 이동·늦은 원음 로딩·연속 재생, 680px 탭과 공통 도구막대, PDF 페이지 이동·확대·필기·T 입력·수정·저장·재실행·내보내기, 과거 초안과 출처·손글씨 승인 보존을 확인한다. 사용 중 실제 보관함은 복사본에서 먼저 검증하고 미저장 입력 확인 없이 앱을 교체하지 않는다.

## 추가 합의: 페이지 넘김 방식

사용자 요청에 따라 기존 세로 연속 보기와 한 쪽 보기를 함께 제공한다. 한 쪽 보기에서는 좌우 버튼·방향키로 페이지를 넘기며, 확대·이동·공통 도구와 기존 페이지별 데이터는 유지한다. 보기 방식은 자료·원본 버전별로 저장한다. 페이지를 숨겨도 편집기를 해제하지 않아 초안·검토 상태를 보존한다. 기존 설정에 방식이 없으면 연속 보기로 시작한다.

추가 UI 지시: 보기 선택은 `⋮ → 페이지 보기` 아래 연속·한 쪽 아이콘으로 제공한다. 이름은 툴팁·접근성 라벨로 제공하고 선택 상태를 표시한다. 노트·기록 더보기·자료 선택은 바깥 클릭·Tab으로 메뉴 밖 이동·Esc·화면 이동·작업 선택에 닫힌다. 펜 설정과 상호 배타적으로 열고, 본문 펼침과 미저장 입력은 닫지 않는다.

아이콘 참조: 삼성 공식 [노트 스타일 안내](https://www.samsung.com/us/support/answer/ANS10004548/)와 Samsung Members의 [실제 스크롤 방향 화면](https://r1.community.samsung.com/t5/image/serverpage/image-id/7630022i45E9B467830C5035/image-size/large?px=999&v=v2)을 시각 확인했다. 중앙 페이지·희미한 위아래/좌우 페이지 조각을 참고하여 Solasi의1.65px 선화로 직접 구성한다. 원본 SVG를 추출하거나 브랜드 자산을 포함하지 않는다. 커뮤니티 화면은 과거 버전 사례이며 최신 전체 UI와 동일하다고 주장하지 않는다.

## 구현·검증 결과

0.3.29/build39를 실제 Mac 앱에 반영했다. 페이지 아래 회차 노트의 표시명은 **메모**로 통일했다.

- 프런트엔드 140개 검사 통과. 격리 Mac 검사 707개 중 706개 통과, 선택 검사 1개 생략.
- 실제 설치 앱의 새 검증 과목에서 PDF 연결, T 한글·영문·수식 입력, 메모 저장, 페이지 보기 선택, 정상 재실행, JSON 내보내기를 확인했다.
- 실제 680×480 창의 두 테마에서 아이콘 선택과 Tab·Esc·바깥 클릭을 확인했다. 확인 후 기존 시스템 테마 설정으로 복원했다.
- WebKit에서 버튼 클릭 중 임시로 본문에 포커스가 이동해 메뉴 항목 선택이 취소되는 문제를 수정했다. 바깥 클릭과 Tab 이동 후 닫힘을 구분하고, 항목 동작 뒤 React 버블링 단계에서 메뉴를 닫는다.
- 교체 전 11개 기록·필기·초안·출처 테이블과 51개 원음·자료 파일을 보존했다. 새 검증 행만 추가했다.

예: 노트 도구막대의 **⋮ → 페이지 보기 → 좌우 페이지 아이콘**을 누르면 한 쪽 보기로 바뀐다. 앱을 종료하고 다시 켜서 같은 자료를 열어도 한 쪽 선택이 유지된다.

실제 펜 태블릿의 압력 입력과 강제 종료 복구는 이번 UI 검증에서 재시험하지 않았다.
