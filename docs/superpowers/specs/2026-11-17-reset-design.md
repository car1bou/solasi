# Solasi Mac 앱 초기화

사용자는 설정·기록·솔라시 전용 모델과 추가 엔진을 초기화하고 앱은 유지하는 3번 범위를 선택한 뒤, 이를 앱 안의 기능으로 추가해 달라고 요청했다. 실제 사용자 기록을 구현 테스트로 초기화하지 않는다.

기존 보존·삭제 선택 UI, 독립 내보내기와 내용 검증, 최종 재검증, 종료 후 안전한 삭제 도우미를 재사용한다. 별도 초기화 경로를 새로 복제하면 두 흐름의 검증이 어긋나므로 같은 계획에 네이티브가 확정하는 reset 모드만 추가한다. 설치 삭제는 종전대로 앱까지 제거하며 초기화는 앱을 보존한다. 외부 원본·별도 백업·공유 도구·미확인 실험 파일은 유지한다.

설정에 앱 초기화… 버튼과 사용 설명을 추가한다. 세 기록 범주(필기·문서, 녹음, 전사·AI 결과)는 각각 보존/삭제 선택을 제공하고 모두 보존이 기본값이다. 보존은 앱 밖에서 읽는 사본이며 원래 보관함·수정 이력은 초기화 실행 시 제거된다. 모델·추가 엔진·앱 설정·해당 보관함의 저장 API 키·캐시·로그는 제거한다. 번들 자체와 내장 기본 엔진은 유지한다.

초기화용 최종 화면에는 보존 위치와 범위, 초기화 대상, 앱 유지, 이후 모델/엔진 재설치 안내를 표시한다. 정확히 ‘솔라시 초기화’를 입력하고 ‘초기화 실행’을 눌러야 한다. 선택 변경은 영수증과 확인 입력을 무효화한다. 검증 실패·취소는 원본을 유지한다. 도우미는 앱/엔진 종료와 잠금·파일 식별자·보존 해시를 검사한 뒤 실행하고 부분 실패를 성공으로 표시하지 않는다. 초기화 성공 후 사용자가 앱 다시 열기를 누르면 빈 보관함으로 시작한다.

구현자는 기존 Swift/AppKit 화면과 React 카드, 서명 패키징을 재사용한다. 새 의존성·실제 키 삭제 테스트·자동 실제 초기화·커밋·푸시는 추가하지 않는다. 별도 검토와 임시 fixture 삭제, 실제 QA 선택/취소, 설치 전후 사용자 자료 불변을 검증한다.
