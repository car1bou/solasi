# Mac 설치 앱의 전사 용어·녹음 검증

2026-10-20, Apple Silicon Mac의 실제 `Solasi.app` **0.3.24 / build 34**에서 확인했다. [앞선 동일 음성 비교](material-guided-asr-20261020.md)의 수정본을 내장 엔진과 함께 설치하고, 기존 보관함 안의 **새 검증 과목·회차만** 조작했다. 별도 브라우저나 API 테스트만으로 실제 화면 검증을 대신하지 않았다.

## 배포·보존

- 실행 중인 모든 기존 녹음이 종료 상태임을 확인하고, 홈 화면에서 앱을 정상 종료했다. SQLite의 일관된 백업과 보관함의 APFS 사본, 파일 대조 기준을 만들었다.
- 설치기는 기존 `data`·`runtime` 설정을 유지했다. 이전 앱은 고유한 이름으로 백업했으며 모델을 다시 내려받지 않았다.
- 새 frozen 엔진의 `asr_hints`, `transcription`, `server` 코드 객체와 스키마를 현재 소스에 대조했다. 별도 보관함에서 실제 frozen 파이프를 실행해 근거 변경·용어 제외를 먼저 확인했다.
- 설치된 엔진·프런트 자산이 빌드 결과와 일치하며 앱 서명 검사를 통과했다. 화면 수정 후 최종 설치에도 같은 엔진을 사용했다.
- 설치 전 **47개 테이블**을 백업했다. 기존 기록·원음·필기·초안에 해당하는 26개 테이블의 이전 행과 **1,518개 파일**의 크기·SHA를 대조해 변경·누락이 없음을 확인했다. 검색 색인·자동 작업의 갱신은 사용자 기록 행과 구분했다.
- 기존 과목 8개·회차 11개·전사 742개·페이지 문서 10개·페이지 버전 42개·필기 인식 15개·네이티브 초안 14개를 보존했다. 검증용 과목과 새 기록은 추가했다.

## 실제 화면에서 수행한 흐름

| 단계 | 조작·관측 |
|---|---|
| 자료·노트 | 검증용 TXT 원본을 파일 선택 창으로 연결하고, 회차 노트를 직접 작성·저장 |
| 근거 선택 | 검색 결과의 자료와 노트 두 항목을 체크하고 `자그로스산맥`을 등록 |
| 직접 명칭 | 근거 없는 개념 `이란`, 직접 회차 용어 `산맥`을 저장 |
| 최초 힌트 | `Whisper 적용 힌트: 산맥, 이란, 자그로스산맥` 표시 |
| 일부 근거 변경 | 노트만 새 버전으로 저장. 다른 파일 근거가 그대로여도 다음 확인에서 `자그로스산맥 · 근거 재검토 필요` 표시 |
| 초안 유지 | 용어 입력을 미저장 상태로 바꾸고 `힌트 다시 확인`. 입력이 유지되는 것을 확인한 뒤 저장한 값으로 복원 |
| 재검토·재등록 | 변경된 노트 근거를 해제하고 파일 근거만 검토해 용어 v2로 저장. 적용 힌트 복원 |
| 원본 내용 변경 | 검증용 원본 사본을 보존한 뒤, 원본의 크기·수정 시각을 유지하고 내용만 변경. SHA 검사로 다시 제외됨 |
| 재실행 | 직접 용어·제외 상태·수정 노트·이전 대본·원음 연결·전사 당시 힌트 기록이 유지됨 |

TXT와 회차 노트는 기능 시험을 위해 작성한 예제다. 실제 강의자료에서 고유명사를 자동 추출한 품질 평가로 해석하지 않는다. 기존 자료나 원음은 수정하지 않았다.

제외된 이름이 과거 대본에도 사라져야 하는 것은 아니다. 과거 인식문과 당시 전달한 힌트는 남고, **다음 추론에 전달할 어휘만** 현재성 검사에 따라 달라진다.

## 녹음·전사

| 조건 | 저장한 원음 | 확인 |
|---|---:|---|
| 첫 실제 마이크 | 137.0초 / 48kHz / 6,576,000프레임 | 수집=저장=WAV 프레임, 기록된 gap 없음. 종료 후 5개 청크 완료 |
| 최종 화면 수정본의 실제 마이크 | 25.4초 / 48kHz / 1,219,200프레임 | 같은 프레임·gap 검사 통과. 종료 후 1개 청크 완료 |
| 실제 한국어 정답 음성 파일 | 8.94초, 같은 파일 2회 | 파일 선택 창으로 연결, 두 실행 모두 전사 완료. 동일 인식문 |

총 4개 녹음·파일 기록, 8개 Whisper 호출의 snapshot을 확인했다. 첫 마이크의 5개 snapshot에는 세 용어가 들어 있었다. 노트 변경 후의 첫 파일, 원본 변경 후의 최종 마이크·파일에는 `산맥, 이란`만 전달됐고, 제외 이유가 기록됐다. 최종 snapshot의 확인한 파일 SHA는 변경 후 실제 파일 SHA와 일치했다. 이전 snapshot과 원음 해시는 그대로 보존됐다.

마이크 입력에는 정답 전사가 없다. 빈 출력이나 한 명칭의 출력을 실제 발화·환각 중 어느 쪽이라고 확정하지 않으며 마이크 결과의 CER를 발표하지 않는다. 정답이 있는 파일은 앞선 FLEURS 사람 음성을 재사용했다. 두 실행 모두 같은 정규화 기준 **1/33자 오류(CER 3.03%)**였고, 이는 한 파일의 설치 경로 확인이지 새 품질 향상 주장이나 다양한 음성의 추가 벤치마크가 아니다.

## 발견한 UI 문제와 수정

680×480에서 전사 용어와 질문 후보가 두 열로 남아 있었다. 사이드바를 제외한 공간이 좁아 적용 힌트의 단어와 저장 안내가 과도하게 줄바꿈됐다.

기존 한 열 배치 규칙의 적용 범위를 **600px 이하 → 700px 이하**로 넓혔다. 다른 버튼·필기·녹음 동작은 바꾸지 않았다. 실패하는 CSS 회귀 검사를 먼저 확인한 뒤 수정했다.

최종 설치 앱에서 다음을 다시 확인했다.

- 680×480 라이트·다크 모두 전사 용어 카드가 한 열로 표시됨
- 용어·제외 이유·복구 안내를 세로 스크롤로 읽을 수 있고 가로 잘림 없음
- textarea → 저장 → 힌트 다시 확인 순서로 Tab 이동, Enter 실행, 포커스 테두리 표시
- 재실행 시 680×480 크기 유지
- 검증 후 원래 라이트 모드·1200×820 창·홈 화면으로 복원

초기 실행 한 번은 화면 도구에 본문이 빈 창으로 보였다. 앱의 기존 메뉴 `Solasi 열기`로 같은 창을 활성화하자 본문과 접근성 트리가 나타났다. 이 관측을 앱 엔진 실패로 취급하거나 사용자 초점을 강제로 가져오는 코드를 추가하지 않았다.

## 회귀 검사·재확인 방법

- Python 전체 **627개 중 622개 통과·5개 선택 검사 생략**
- 프런트엔드 **103개 통과**, TypeScript·Vite build 성공
- 설치 스크립트 검사 2개 통과, frozen 파이프 currentness 검사 통과
- 앱 서명·설치 자산·보관함 integrity·foreign key 검사 및 이전 행/파일 보존 대조 통과

다시 확인할 때는 다음 순서로 진행한다.

1. 새 과목에 자료와 회차 노트를 연결하고 두 근거를 가진 용어를 등록한다.
2. 노트만 수정하고 `힌트 다시 확인`에서 제외 이유를 확인한다.
3. 직접 입력한 용어가 유지되는지 확인하고, 실제 녹음 종료 후 전사를 기다린다.
4. 대본·원음과 당시 snapshot을 보존한 상태에서 앱을 정상 종료·재실행한다.
5. 새 기록을 이전 기록과 구분하고, 이전 행의 내용과 원음·연결 파일의 SHA를 비교한다.

원음·전체 대본·DB·초안·상세 snapshot·개인 경로·검증 화면은 Git 제외 로컬 검증 폴더에 보관한다. 이번에는 물리적 절전·강제 종료·장시간 녹음·다화자 정확도·외부 API를 다시 시험하지 않았다. [전사 힌트 비교의 표본·품질 한계](material-guided-asr-20261020.md)도 유지된다.
