# Mac 과목·자료·녹음 사용 흐름 검증

후속 실제 절전·강제 종료·미저장 초안 복구와 추가 정답 음성 비교는 [Mac 녹음 복구 검증](mac-recovery-validation.md)에 기록했다. 아래는 앞선 사용 흐름 검증이다.

검증일: 2026-10-16. 기존 흑백 디자인을 적용한 설치형 Solasi.app 0.2.1(8)에서 직접 조작했다. UI UX Pro Max의 입력 집중·명확한 라벨·진행 피드백 기준, grilling의 기존 합의, ponytail의 최소 수정 원칙을 적용했다. 파일 선택, 마이크, 재실행, 내보내기는 실제 macOS UI를 거쳤으며 API 호출만으로 사용 흐름을 대신하지 않았다.

## 수정

- 파일을 연결하면 응답의 첫 자료를 자동으로 열고 1쪽을 표시한다. 여러 파일은 모두 연결되며, 선택 취소 시 기존 자료·페이지를 유지한다.
- 다른 화면이나 과목 탭을 다녀와도 마지막 자료·페이지로 복귀한다. 과목/회차별 화면 상태는 서로 분리한다. 이 탐색 상태는 현재 앱 창의 실행 동안만 기억하며, 저장된 메모·잉크와 별개다.
- 새 기록 작성 중에는 홈의 과목 생성·목록·엔진 준비 영역을 숨겨 입력 폼에 집중한다. 과목에서 시작하면 해당 과목이 미리 선택된다.
- 강의 탭 `학습`을 `요약·학습`으로 표시하고, 요약 입력란을 `요약 지침`으로 표시한다.
- 요약 구간 수가 준비되면 첫 구간 완료 전부터 `완료 구간 0/N`을 표시한다. 실패 후 보존된 진행량은 유지하고, 저장 완료를 `0/N`으로 되돌려 표시하지 않는다.

자료 원본, PDF 색, 저장된 필기 색, 전사 원문·시간 연결, 마이크 권한·복구 정책에는 변경을 가하지 않았다. 새 의존성이나 저장 스키마는 추가하지 않았다.

마이크의 앞 창/사용자 동작 검사는 유지했다. 창이 비활성 상태였던 첫 자동 조작은 안내와 함께 거절됐고, 실제 창을 앞으로 가져온 뒤 성공했다. 이는 OS 권한이 없다는 증거로 해석하지 않았다.

## 긴 요약의 내용 검사

- 처리한 근거 306개, 최종 인용 근거 129개, 직접 인용하지 않은 근거 177개를 별도로 보존·표시했다.
- 5개 구간의 앞·중간·뒤 선택 검사에서 미충족 구간은 없었다.
- 35개 발췌 항목의 모든 인용이 해당 근거 원문의 부분 문자열인지 기존 `checked_excerpts` 검사로 확인했다. AI가 새 주어·사건 상태를 써 넣는 서술형 요약으로 바꾸지 않았다.
- 처리 범위는 기록 시각 912.994초까지이며, 최종 인용의 가장 늦은 근거는 890.994초였다. 모든 문장이나 후반의 모든 사건을 인용했다는 의미는 아니다. 직접 인용하지 않은 원문을 대조할 수 있다.

## 회귀 검사·보존

- 프런트엔드 52개 검사 통과. 자료 연결·취소·소유 범위별 페이지 복귀, 요약 라벨·초기 진행량·실패 후 보존·완료 표시를 추가 검사했다.
- 백엔드 `python -m unittest discover -s tests -p 'test_*.py'`: 362개 통과.
- TypeScript 검사 및 Vite 프로덕션 빌드 통과.
- 검증 이전 과목 2개·기록 5개·페이지 문서 1개·노트 2개·전사 439개·결과물 1개의 행 해시가 보존됐다. 테스트용 과목과 기록은 구분되는 이름으로 남겼다.
- 실제 음성·사용자 데이터·내보낸 대본·화면 캡처·인증 정보는 공개 Git 변경에 포함하지 않는다.

### 재현 체크리스트

1. 홈에서 과목을 만들고 파일 연결로 PDF를 고른다. 추가 클릭 없이 1쪽이 열리는지 확인한다.
2. 메모·필기를 저장한 뒤 2쪽으로 이동한다. 강의 기록을 열었다가 자료·필기로 돌아와 2쪽인지 확인한다.
3. 파일 연결을 열었다 취소한다. 현재 문서·페이지가 그대로인지 확인한다.
4. 과목에서 강의를 만들고 활성 창에서 녹음 시작·종료한다. 종료 후 전사 처리와 저장 상태를 확인한다.
5. 대본 문장을 선택해 원음을 확인하고 수정한다. 최초 인식문과 시각이 남는지 확인한다.
6. 요약·학습에서 전체 요약을 실행한다. 진행 구간과 저장 결과·원문 근거를 확인한다.
7. 앱을 정상 종료·재실행하고 과목 페이지 메모·필기, 저장된 대본·요약을 연다.

## 검증 범위

이번 마이크 시험은 조용한 실제 입력 경로 확인이다. 긴 음성은 파일 연결 시험이며, 긴 실시간 마이크 녹음·절전·강제 종료를 이번에 다시 재현한 것은 아니다. 긴 낭독에는 완전한 정답 전사를 대조하지 않았으므로 전체 CER나 누락·환각 해소를 주장하지 않는다. Windows·Android·iPad 및 펜 압력 하드웨어는 이번 범위에 포함하지 않았다.
