# Mac 긴 한국어 파일 전사·요약 실제 실행

2026-10-16 KST에 캐시된 한국어 사람 음성 전체를 실제 앱 API로 등록하고, Whisper large-v3-turbo와 Qwen3.5:4b MLX를 실행했다. 전사 33개 구간과 최종 요약 8개 구간이 모두 완료됐다. **최종 요약의 61개 표시 항목 중 48개는 원문 확인이 필요하다.** 처리 완료는 요약 정확도 확인을 뜻하지 않는다.

수치와 모델 해시는 [정제한 실행 기록](mac-long-file-validation.json)에 있다. [재현 실행기](../experiments/serve_long_file_validation.py)는 별도 데이터 폴더·런타임 제어 상태·포트를 사용하고, 기존 엔진과 모델 파일만 연결한다. 제품 코드는 이 검증에서 수정하지 않았다.

## 입력과 실제 통과한 경로

- [LibriVox 『술 권하는 사회』 Part 1](https://librivox.org/short-stories-by-jin-geon-hyun/), 현진건, 낭독 Jessie Yun. 캐시된 원본 MP3와 출처 JSON을 사용했다. Public Domain Mark 1.0 / LibriVox public-domain dedication.
- 14,058,564바이트, SHA256 `68f07d5ca8677317590af0fc1dd5b8634ae0749ba1bbddc3965962f73086f1fc`. 실행 전후 원본 해시가 같았다.
- 44.1kHz, 38,733,184프레임, **878.303492초(14분 38.303초)**. 짧은 파일을 반복하거나 합성한 음성이 아니다. 단일 화자의 문학 낭독이며 강의·회의 자료는 아니다.
- 실제 TCP 연결과 앱 인증을 거쳐 `/api/local/connect`, `/api/settings`, `/api/models/check`, `/api/ai/jobs`, `/api/sessions/{session}/recordings`를 호출했다. 앱이 소유하는 별도 Ollama 프로세스와 실제 Whisper 엔진을 사용했다. 모델 다운로드는 실행하지 않았다.
- **파일 선택기만 해당 캐시 파일 경로를 반환하도록 대체했다.** 이후 형식·크기·해시·길이 검사, 파일 등록, 구간 계획, 네이티브 전사, 출처 저장과 요약 생성은 제품 경로를 실행했다. 네이티브 파일 선택 창이나 실제 마이크·WKWebView·AudioWorklet의 검증 결과가 아니다.

먼저 설명 메모로 실제 요약을 제출했고, 로컬 생성 허용 게이트를 통과한 뒤 긴 파일을 등록했다. 따라서 첫 요약과 실제 전사 처리가 겹친다. 전사 완료 뒤에는 설명 메모를 비우고 확정 전사 전체만 새 요약 스냅샷으로 고정했다. 최종 결과의 출처 집합이 확정 전사 301개 출처와 정확히 같은지 확인했다.

모든 원본 프레임이 처음부터 끝까지 연속된 전사 처리 구간에 배정되어 완료됐는지 확인했다. 이 확인은 처리 대상의 누락 여부에 관한 것이며, 모든 발화가 정확하게 문자로 인식됐다는 뜻은 아니다. 전사 구간의 경계는 실제 발화가 없는 시간도 포함한다.

겹침 시간은 생성의 허용 게이트 통과부터 응답 종료까지의 구간과 `process_chunk` 실행 구간의 교집합 합계다. GPU 커널의 동시 점유나 첫 토큰 지연은 측정하지 않았다. 준비 상태·선택 모델과 모든 생성 응답의 digest를 확인했고, 최종 요약 결과의 digest도 같은 값이었다.

## 품질 경고와 남은 검증

입력 301개 출처의 스냅샷 보존과 직접 인용 262개는 정확도 점수가 아니다. 61개 표시 항목 중 48개에 원문 확인 표시가 있고, 직접 인용되지 않은 원문 39개도 별도로 남았다. 이 낭독 입력의 최종 결과는 사람이 원문·원음과 함께 검토해야 한다. `selection_incomplete_parts=[]`도 모든 의미가 요약에 반영됐다는 보장은 아니다.

원작 책 텍스트는 낭독 도입부와 파트 경계가 시각 정렬된 전사 정답이 아니므로 전체 CER을 계산하지 않았다. 요약의 사람 평가도 실행하지 않았다. 단일 실행이며 호스트 부하·메모리를 통제하거나 프로파일링하지 않았다. 이전 실행과 성능 개선율을 비교하지 않는다.

실제 장시간 마이크 수집, WKWebView 권한·시작 경로, 브라우저 캡처, 여러 화자·소음·겹침 발화와 강의·회의 품질은 이 실행에서 확인하지 않았다. 검증 서버가 소유한 로컬 모델 런타임은 작업 완료 뒤 연결 해제했다. 후속 내보내기 확인을 마친 뒤 검증 서버의 프로세스 종료와 포트 닫힘을 확인했다. 실제 앱의 데이터와 런타임 제어 상태에는 접근하지 않았다.

## 재현

준비된 앱 Python 환경에서 기존 엔진·모델·음성 캐시를 사용한다. 새 출력 폴더와 비어 있는 포트가 필요하다.

```sh
PYTHONDONTWRITEBYTECODE=1 PYTHONPATH="$PWD" python experiments/serve_long_file_validation.py \
  .local-state/long-file-new-run \
  --runtime .local-state/runtime \
  --audio .local-state/runtime/long-human-20261014/sul-part1.mp3 \
  --port 62437
```

실행기는 완료 뒤 서버를 유지한다. 인증 정보와 내부 작업·결과 식별자는 출력 폴더의 비공개 파일에만 있다. 공개 JSON에는 인증 값·제어 URL·절대 경로·내부 식별자·전사나 생성 본문을 넣지 않았고, 이 값들이 섞이지 않았는지 실제 결과로 검사했다.
