# 홈·설정 화면 정리 — Mac 검증 기록

검증일: 2026-11-05. 설치 버전: Solasi 0.3.38 / build 48.

## 화면 변경

- 홈은 최근 기록을 먼저 표시한다. 기존 기록 전체와 시작 시각 내림차순 정렬을 유지한다. 마지막으로 열었던 시각을 새로 추정하거나 기록을 제한하지 않는다.
- 새 기록은 버튼으로 펼친다. 접을 때 제목·과목·회차 입력은 유지하며 기존 미저장 입력 보호를 사용한다.
- 설정은 화면, 세컨드 브레인, AI 실행, API 키, 엔진·OCR, 로컬 AI 순서로 정리한다.
- 동일한 최근 오류 메시지는 묶어서 횟수와 함께 표시한다. 서버가 돌려주는 최근 오류 최대 5건의 표본과 전체 실패 건수는 구분한다. 기존 전체 실패 작업 재시도 동작은 유지한다.
- 고급 생성 설정, API 키 관리, 엔진 및 모델 설치 정보는 기본적으로 접는다. 접어도 입력 폼은 계속 유지한다. 준비·다운로드 작업의 진행·취소·오류 영역은 접힌 설치 정보 바깥에 둔다.

## 완료한 검증

- 다른 작업의 미커밋 변경을 제외한 격리된 Mac 소스에서 프런트엔드 검사 135개 통과, TypeScript 검사 및 배포 빌드 성공.
- 독립 코드 검토에서 조치할 문제 없음.
- 실제 설치 앱의 창 저장값 680×480과 캡처 1360×960(2배 해상도) 확인.
- 시스템 설정을 따르는 다크 화면에서 홈 첫 화면에 최근 기록 4개가 표시됨. 변경 전 같은 크기에서는 새 기록 입력이 공간을 차지해 최근 기록이 첫 화면에 보이지 않았음.
- 새 제목 입력 → 접기 → 이동 차단 → 다시 펼치기에서 제목 유지 확인. 검증 입력은 지움.
- 설정의 기존 전체 실패 84건과 ‘최근 오류 5건 · 1종류’가 구분됨. 펼치면 반복 메시지 한 줄과 5건 표시, 전체 실패와 다른 표본이라는 안내 확인. 기존 실패 작업은 재실행하지 않음.
- 오류 펼침의 Space 열기·닫기와 Tab으로 다음 버튼 이동 확인.
- API 키 관리에 실제 자격증명이 아닌 검증 문자열을 붙여넣은 뒤 접기 → 이동 차단 → 펼치기에서 입력 유지 확인. 입력 지우기로 제거했으며 저장·외부 전송하지 않음.
- 엔진·모델 관리의 경로, 라이선스, 기존 준비 및 다운로드 컨트롤이 펼침 안에 남아 있는지 확인. 다운로드·재설치는 실행하지 않음.
- 기존 기록·필기·원음 관련 11개 테이블의 기존 4,147개 행과 원본 파일 71개의 크기·SHA256 불변 확인. 기존 필기 도구 및 목록 보기 설정 불변 확인.
- 설치 경로와 보관함 경로 보존. 서명 검사 통과. 기존 네이티브 실행 코드와 검증된 엔진을 재사용하고 테스트한 화면 빌드만 설치.

## 최종 설치 앱 확인

- 사용자가 macOS 기본 선택창에서 라이트를 선택했고, 실제 앱의 ‘라이트 · 화면 모드 저장됨’ 상태와 라이트 화면을 대조했다. 최종 앱은 라이트 홈으로 남겨 두었다.
- 680×480 라이트 홈에서 최근 기록 네 개, 새 기록 버튼, 긴 제목과 과목명이 겹치거나 가로로 잘리지 않는지 확인했다. 시스템 다크에서 확인한 구성과 일치한다.
- 라이트 설정에서 오류 묶음과 엔진 관리 정보를 열고 닫았다. 긴 저장 경로는 줄바꿈되며 준비 상태는 접힘 밖에 유지된다. Space로 오류 펼치기, Tab으로 재시도 버튼까지 이동하는 경로도 확인했다. 재시도 실행은 하지 않았다.
- 홈의 기존 기록을 열어 해당 회차와 저장된 메모를 확인했다. 별도 기존 회차에서 연결된 135쪽 PDF를 열어 원본 페이지, 저장됨 v10, 기존 필기 영역과 도구를 확인했다. 메모·필기는 변경하지 않았다.
- 이전 임시 PDF 검증 기록의 ‘파일 없음’과 다른 자료의 기존 ‘추출 실패’ 상태는 이번 화면 변경에서 복구한 항목이 아니다. 추출 실패는 설치 전 DB에도 있었으며, 해당 자료의 원본 PDF 페이지 보기는 정상이다.
- 최종 보존 검사를 다시 실행해 4,147개 기존 행, 71개 파일 해시, 필기 도구·목록 보기 설정, 테스트한 화면 빌드와 설치본 일치 및 앱 서명을 재확인했다.

이 작업은 화면 정리 범위다. 새 모델 추론·새 녹음·PDF 내보내기 및 실제 다운로드 중 취소는 재실행하지 않았다. 작업 진행·취소 영역이 접기 밖에 유지되는지는 소스와 독립 검토로 확인했다. 비공개 보관함·검증 캡처·백업은 공개 Git에 포함하지 않는다.
