# 강의자료 기반 전사 힌트: 현재성 보완과 동일 음성 비교

검증일: 2026-10-20. Mac의 기존 로컬 모델로 실행했으며 새 모델·음성을 내려받지 않았다. 실제 설치 앱을 교체하거나 실제 보관함을 수정한 검증은 아니다.

## 적용한 변경

- 회차 직접 입력 → 같은 과목의 등록 개념 → 활성 참석자 순서와 UTF-8 200바이트 예산은 유지한다. 빈 값·중복을 정리하고 제어 문자·모델 특수 토큰은 거절한다.
- **등록 개념에 붙은 모든 근거**가 현재 검색 가능하고 같은 범위에 있으며, 필요한 손글씨 승인을 유지하는지 검사한다. 근거 중 하나라도 바뀌거나 삭제·승인 취소·자료 연결 해제되면 다음 힌트에서 해당 용어를 제외한다. 근거 없는 등록 개념과 직접 입력한 회차 용어는 유지한다.
- 실제 연결 파일을 SHA256으로 확인한다. 파일 크기·수정 시각을 유지한 내용 변경도 검출한다. 자료 한 개의 해시는 한 번의 준비 과정에서 공유하고, 다음 준비 때 다시 확인한다. 실패한 자료 검사도 그 준비 안에서만 공유한다.
- 파일 검사는 별도 스레드에서 수행해 녹음 입력을 막지 않는다. 해시가 끝나면 등록 개념 revision·회차/자료 범위·근거 검색 가능 여부·승인 상태를 다시 읽는다. 검사 도중의 필기 수정·연결 해제를 재현해 제외를 확인했다. 전송 뒤의 편집이 이미 실행 중인 추론을 소급 변경하지는 않는다.
- Whisper 호출 전에 선택한 용어·출처 ref/버전·문서 해시·제외 이유·시각을 시도별 `transcription_hint_snapshots`에 추가한다. 기존 `transcript_ranges.prompt`도 유지하며 과거 snapshot·전사·원음·source를 덮어쓰지 않는다. 완전한 0값 PCM은 추론과 파일 검사를 생략한다.
- ‘전사 용어’에 `Whisper 적용 힌트`, 제외 이유와 `힌트 다시 확인`을 표시한다. 다시 확인은 입력 중인 용어 초안을 바꾸지 않는다. 오래된 비동기 응답이 다른 회차의 화면을 덮지 않도록 요청 순서를 확인한다.

### 사용 예

1. 회차의 ‘전사 용어’에서 직접 명칭을 입력하거나 기존 과목 개념을 확인한다.
2. 근거를 수정했다면 `힌트 다시 확인`으로 제외 이유를 확인한다. 다음 실제 전사도 별도로 현재성을 검사한다.
3. `근거 재검토 필요` 용어는 과목 개념의 원문·근거를 검토해 새 버전으로 등록한다. 과거 용어·대본·출처는 남는다.

이번 변경은 기존 등록 개념의 안전한 사용 범위다. 자료 전체의 용어 자동 추출·페이지와 발화 시점 정렬·자동 용어 교정은 구현하지 않았다. 아래 비교 결과에 따라 **Qwen hotwords는 실험 경로에만 두고 앱의 재인식 worker에는 추가하지 않았다.**

## 음성·용어 조건

추론 전에 15개 파일을 고정했다. 총 **78.3405625초**, 최대 12.54초, mono PCM16 16kHz이며 모델·조건마다 같은 파일 해시를 사용했다.

| 자료 | 파일 수 | 내용 / 한계 |
|---|---:|---|
| FLEURS 한국어 낭독 | 4 | 이란·자그로스산맥, 북발트해, 합금·주기율표, 일반 문장 |
| Pansori/TED 공개 발화 | 3 | 음악·공연장·팔레스타인 관련 이름 |
| KMSAV 인터뷰 | 2 | 등장인물 이름 발화와 일반 발화. 기존 영상의 제목·설명을 독립 용어 근거로 사용 |
| 성인 서울코퍼스 대화 발화 | 6 | 서로 다른 두 발화의 clean / 실제 사무실·식당 소음 파생 혼합(전체 원본 RMS 기준 10dB로 혼합 후 발췌) |

**15개는 서로 다른 전경 발화 11개**다. 짧은 발췌별 SNR이 모두 10dB라고 보장하지 않으며, 소음 조건을 독립 화자·새 대화로 세지 않는다. 여러 화자의 발화는 포함하지만 겹침을 포함한 전체 다화자 대화의 완전한 정답 평가가 아니다. 데이터 계보·이용 범위는 [기존 한국어 검증 기록](korean-asr-validation-20261017.md)을 따른다. 원음·정답·전체 인식문은 공개 Git이나 앱에 포함하지 않는다.

각 엔진에서 `없음 / 관련 용어 / 무관 용어`를 비교했다. 처음에는 이 순서, 두 번째에는 역순으로 실행했다. **15×3×2엔진×2순서 = 180회**이며 모두 완료했다. 동일 파일·조건의 인식문은 두 순서 사이에 엔진별 45/45개가 정규화 전 문자열까지 같았다. Whisper 구간 시각도 같았다. 재실행은 독립 표본을 추가한 것이 아니다.

- 관련 용어: 이란·자그로스산맥·북발트해 등. FLEURS/TED 용어는 이미 알고 있는 정답에서 골랐으므로 **정답 참조 어휘 조건**이다. 자동 강의자료 추출 성공으로 계산하지 않는다.
- 독립 근거 조건: KMSAV의 기존 영상 메타데이터에 실제 있는 `호텔 델루나, 장만월, 구찬성, 이지은, 여진구`를 두 인터뷰 발화에 동일하게 적용했다. 강의 PDF가 아닌 영상 제목·설명이며 수동 선정이다.
- 일반 발화 8개 중 7개는 관련 용어 목록이 비어 있어 없음 조건과 같다. 일반 발화에 비어 있지 않은 관련 용어를 넣은 사례는 메타데이터 기반 1개뿐이다.
- 무관 용어: 모든 파일에 `세풀베다, 다익스트라, 케임브리지`. 정답에는 없는 명칭이다.
- 완전히 주석된 무발화·소음 전용 원음은 확보하지 못했다. 따라서 무음 환각 억제 효과를 주장하지 않는다.

## 정확도 결과

CER는 NFKC·소문자화 후 문자/숫자만 남긴 문자 편집 거리다. 공백·구두점은 제외하고 숫자/한글 수사 동치는 처리하지 않는다. 아래는 순서별 한 번의 결과이며 역순도 모두 동일하다.

| 엔진 / 조건 | 오류 / 정답 404자 | CER | 대치 / 삭제 / 삽입 |
|---|---:|---:|---:|
| Whisper large-v3-turbo / 없음 | 9 / 404 | 2.23% | 7 / 2 / 0 |
| Whisper / 관련 | 9 / 404 | 2.23% | 7 / 2 / 0 |
| Whisper / 무관 | 22 / 404 | 5.45% | 8 / 14 / 0 |
| Qwen3-ASR-1.7B-4bit / 없음 | 15 / 404 | 3.71% | 11 / 0 / 4 |
| Qwen / 관련 | 13 / 404 | 3.22% | 10 / 0 / 3 |
| Qwen / 무관 | 16 / 404 | 3.96% | 11 / 1 / 4 |

Qwen의 한 사례는 `9/15`와 `아홉/열다섯` 표기 차이가 오류에 포함된다. 이 작은 개발 표본의 CER로 엔진 전체의 우열을 정하지 않는다.

모든 조건을 **같은 정답 어휘 12개**로 재채점하면 Whisper는 **10→11→10개**, Qwen은 **11→12→12개**를 정확히 표기했다. 이 12개에는 전문 어휘도 포함된다. 원시 행의 `correct_terms`는 전달한 목록만 대상으로 하므로, 빈 목록인 기준선을 0/12로 읽으면 안 된다.

### 개선과 부작용을 함께 확인

- Whisper는 독립 영상 메타데이터를 사용한 조건에서 `장만원 → 장만월`로 고쳤다(문자 오류 1→0). 그러나 다른 발화에서는 관련 용어가 있어도 `분쟁지역 → 부쟁지역`이 생겨 전체 CER는 같았다. `와호장룡`은 명칭을 주어도 고치지 못했다.
- Qwen은 `북바이트해 → 북발트해`로 고쳤다(2→0). **무관 용어 조건에서도 `북 발트해`로 고쳤으므로 관련 hotword의 고유한 효과라고 결론 내릴 수 없다.** 순서를 뒤집어도 재현됐다.
- 일반 발화 8개(정답 182자)에서 Whisper 오류는 **3→3→15자**, Qwen은 **2→2→5자**였다. Whisper 무관 조건은 같은 발화의 clean·office에서 앞부분 `별로 안 하는데`를 빠뜨렸다(각각 1→7자). Qwen 무관 조건도 `하는데 → 하는` 누락이 있었다. `요즘엔 → 요즘에는`처럼 의미상 축약 차이도 있어 편집 오류 전체를 환각이라고 부르지 않는다.
- 한 순서에서 엔진별로 관련 조건의 ‘정답에 없는 전달 용어’ 8회 + 무관 조건 45회, **두 엔진 합계 106회 노출에서 정확히 그 명칭이 출력에 들어온 사례는 0**이었다. 역순도 같았다. 이는 지정 명칭의 문자열 삽입 검사이며 일반 환각이 없었다는 뜻이 아니다. 위의 일반 발화 누락은 실제로 있었다.

## 시간·메모리

각 셀은 15회 호출의 중앙값(초)이다. CPU/GPU의 다른 동시 작업은 추가하지 않았으며 새 앱의 장시간 녹음 부하 시험은 아니다.

| 실행 / 엔진 | 없음 | 관련 | 무관 |
|---|---:|---:|---:|
| 정순 Whisper | 1.685 | 1.683 | 1.693 |
| 역순 Whisper | 1.881 | 1.805 | 1.815 |
| 정순 Qwen | 0.465 | 0.459 | 0.469 |
| 역순 Qwen | 0.557 | 0.568 | 0.614 |

Whisper는 기존 호출 경로의 정규화·호출별 모델 로딩을 포함한다. Qwen은 엔진 실행별 한 번의 모델 로딩(1.146 / 1.218초)을 제외한 warm 호출이다. **이 표를 엔진 간 속도 순위로 사용하지 않는다.** 힌트가 지연을 줄였다고도 판단할 수 없다. Qwen의 MLX 측정 peak는 최대 2,394.53MiB였으며 전체 프로세스 RSS·시스템 메모리는 아니다. Whisper의 대응 메모리는 측정하지 않았다.

설치 환경: Whisper 실행 venv의 MLX 0.32.4 / MLX Audio 0.5.8 / Transformers 5.20.0, Qwen 전용 venv의 MLX 0.32.3 / MLX Audio 0.5.8 / Transformers 5.19.0. 서로의 힌트 조건 사이에는 같은 runtime을 유지했다.

## 적용 판단

**현재성 가드·입력 검증·추론별 기록·제외 이유 UI를 적용한다.** 기존 Whisper의 사용자가 고른 소수 용어 기능은 유지한다. 자료 표기를 근거로 전사를 문자열 치환하지 않는다.

관련 힌트는 일부 이름을 고치지만 전체 개선을 보장하지 않았고, 무관 용어는 일반 발화를 훼손했다. 따라서 자동으로 넓은 어휘를 넣거나 Qwen hotwords를 앱의 기본 재인식에 연결하지 않는다. 더 큰 강의자료/음성 대응 자료에서 독립 검증하기 전까지 자동 추출·시점별 선택은 설계로 남긴다.

## 검증과 재현 범위

- 추가 회귀: 근거 여러 개 중 하나의 변경, 승인 필기 변경/텍스트만 수정, 미승인 자료, 위조 ref, 파일 내용 변경, 자료 연결 해제, 해시 도중 획 수정/연결 해제, 파일 검사 중 PCM 추가, 스레드 실행, 실제 전달 snapshot·재시작 보존을 확인한다.
- 전체 Python 627개 중 622개 통과·5개 선택 검사 생략, frontend 102개 통과, TypeScript 검사·Vite build 성공을 확인했다. 최초 실행의 로컬 소켓 bind 권한 오류 2건은 제한을 해제한 동일 전체 검사에서 재확인했다(78.501초, 오류 없음).
- 실제 설치 앱의 새 UI 배치·클릭·권한·장시간 녹음은 이번 변경에서 재검증하지 않았다. 실제 기록·원음·필기 저장소는 열거나 교체하지 않았다.
- 로컬 증거: `.local-state/asr-hints-20261020/`의 고정 manifest·네 결과 JSON·집계·로그. 원본 15개와 정규화 파일 15개의 SHA가 실행 뒤에도 일치한다.
- 고정 manifest SHA256: `903c04726b42af935a9053b9faf08da17d7218cb0292d8723ef4ee32dfd660f5`.
- `experiments/compare_asr_hints.py`는 고정 manifest의 파일 SHA·입력 길이·특수 토큰을 검사한 뒤 기존 모델을 offline으로 실행한다. `--reverse-order`로 역순을 반복할 수 있다. 배포 데이터가 아닌 로컬 manifest 경로를 `--manifest`, 전용 모델 폴더를 `--runtime`, 새 결과 파일을 `--output`으로 전달한다.
- 첫 실행 스크립트는 역순 옵션 추가 전 버전이며 `comparison-first-pass.py`로 보존했다. 추론 시 validator는 `asr-hints-inference-version.py`로 보존했고 각 결과 JSON의 SHA와 일치한다. 이후 가드 캐시·동시성 수정은 ASR 입력 검증 규칙을 바꾸지 않았다.
