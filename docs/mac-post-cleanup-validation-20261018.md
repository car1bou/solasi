# 정리 후 Mac 앱 사용 흐름·저장 복구 검증

검증일: 2026-10-18. 설치된 **Solasi 0.3.7 / build 17**을 그대로 사용했습니다. 이전 빌드·검증 파일을 정리한 뒤에도 현재 앱·모델·보관함이 동작하는지 확인한 기록입니다.

## 범위와 방법

실제 Mac 앱에서 별도 검증 과목과 강의 기록을 만들고, 파일 선택 창·녹음 버튼·PDF 필기·전사·요약·저장 창을 순서대로 조작했습니다. 기존 사용자 기록은 편집하지 않았습니다. 앱을 닫은 상태에서 보관함 기준선을 확보하고, 작업 완료 후 저장된 내용·원음·외부 연결 파일을 대조했습니다.

새 모델을 다운로드하거나 앱을 다시 빌드·서명하지 않았습니다. 기존에 준비된 로컬 전사 엔진과 Qwen3.5 4B 직접 실행을 사용했습니다. 이 시험에서 외부 생성 API는 호출하지 않았습니다.

## 실제 사용 흐름

| 작업 | 관찰한 결과 |
| --- | --- |
| 과목·강의 생성 | 새 과목과 강의가 생성되고 다시 실행한 뒤에도 표시됨 |
| 자료 연결 | 기존 3페이지 PDF를 네이티브 파일 선택 창에서 연결하고 원본 페이지를 열었음 |
| 페이지 메모·필기 | 61자 메모와 두 획을 저장하고 다른 페이지에서 돌아왔을 때 동일한 내용·버전이 표시됨 |
| 마이크 | 권한 허용 후 재시작하여 실제 입력 89.8초를 저장함 |
| 종료 후 전사 | 마이크 전사 작업과 실제 한국어 파일 전사가 모두 오류 없이 완료됨 |
| 대본 원음 재생 | 문장 선택 후 듣기를 눌러 재생 상태·진행 시각과 구간 종료를 확인함 |
| 로컬 전체 요약 | PDF·페이지 메모·확정 전사 5개 근거로 발췌 요약을 만들고 원문 근거를 열었음 |
| 내보내기 | 네이티브 저장 창으로 페이지 JSON과 요약 Markdown을 저장함 |
| 저장 후 강제 종료 | 앱 강제 종료·재실행 후 과목·원음 연결·대본·요약·페이지 메모·필기가 복원됨 |

### 마이크 권한과 원음

첫 시작에서 macOS가 마이크 권한을 다시 확인했습니다. 권한 응답을 기다리던 시작 요청은 기존 30초 제한에 따라 취소됐고, 사용자가 권한을 허용한 뒤 다시 시작해 녹음했습니다. 늦은 권한 응답만으로 녹음이 시작되지는 않았습니다.

저장 WAV는 48kHz 모노 PCM16, **4,310,400프레임**이었습니다. WAV 프레임 수와 DB의 수집·저장 프레임 수가 같았고 기록된 누락 구간은 없었습니다. 입력 RMS는 약 −67.1dBFS로 조용한 환경이었으며 전사된 문장은 없었습니다. 이 녹음에는 정답 발화가 없으므로 빈 전사를 누락 오류나 일반 정확도 결과로 판정하지 않습니다.

### 실제 한국어 음성 전사

기존에 확보한 FLEURS 한국어 사람 음성 한 개를 파일 선택 창에서 연결했습니다. 원음은 **12.48초 / 16kHz**이며, 전사 작업 생성부터 완료 기록까지 약 **3.23초**였습니다. 전사 시각은 원음 범위 안에 있었고 앞선 마이크 녹음의 누적 시각과 구분해 연결됐습니다.

날짜·숫자는 보존됐지만 **‘밑’을 ‘및’으로 인식한 어휘 오류가 남았습니다.** 이 단일 표본에서는 새 문장이 추가되지 않았습니다. 한 표본의 동작 확인이며 다화자·생활 소음·긴 대화의 정확도나 환각률을 대표하지 않습니다. 이전 품질 비교는 [한국어 음성 검증](korean-asr-validation-20261017.md)을 참고하세요.

### 요약과 내보내기

로컬 Qwen3.5 4B의 생성 기록은 약 **25.4초**, 작업 생성부터 완료까지 약 **25.7초**였습니다. 처리 근거 5개·최종 인용 근거 5개·요약 항목 5개를 확인했습니다. 확인이 필요한 발췌 항목 한 개도 그대로 표시됐습니다. 모든 인용이 제공된 근거에 속하고 저장된 원문 버전과 연결되는지 대조했습니다.

요약 Markdown은 **1,835바이트**이며 현재 내보내기 함수의 결과와 전체 내용이 일치했습니다. 페이지 JSON과 복구 후 내용은 아래 저장 복구 대조에 포함했습니다. 이번 요약은 자료·메모·전사를 합친 기능 검증이며, 긴 음성만의 요약 품질 평가가 아닙니다.

## 저장 복구와 기존 내용 보존

녹음·전사·생성이 끝나고 페이지 저장을 확인한 뒤 앱 프로세스를 강제 종료했습니다. 앱이 소유하던 작업 엔진도 종료됐습니다. 다시 실행해 같은 페이지·대본·저장된 요약을 열어 화면 상태를 확인한 뒤 정상 종료했습니다.

강제 종료 전후의 새 강의·녹음·대본·요약·페이지 저장 행이 동일했습니다. 마이크 원음과 연결한 음성 파일 두 개의 크기·SHA256도 일치했습니다. 내보낸 페이지 JSON의 61자 메모·두 획은 재실행 후 저장값과 같았습니다.

이번 앱 검증 전후의 기존 사용자 내용 행은 보존됐습니다. 기존 보관함의 payload 파일 **27개**와 DB가 참조하던 외부 파일 **13개**는 크기·SHA256 대조에서 변경이나 누락이 없었습니다. SQLite 무결성 검사는 `ok`, 외래 키 오류는 0개였습니다. 검증 자료가 추가되면서 바뀐 FTS5 검색 색인의 내부 메타데이터는 사용자 원문 변경과 구분했습니다.

## 검사와 변경 범위

- 프런트엔드 회귀 검사 **93개 통과**.
- 사용자 가이드·개발 문서·이슈 양식의 로컬 링크와 문서 구조 점검.
- 이번 흐름에서 제품 코드의 수정이 필요한 새 오류는 확인하지 못해 앱 버전과 실행 코드는 유지했습니다.
- 공개 문서는 제품 소개·사용 가이드·개발 및 검증 기록으로 정리했습니다. 원음·DB·전사 본문·개인 경로가 담긴 실행 증거는 공개 저장소에 넣지 않았습니다.

## 이번에 확인하지 않은 범위

장시간 녹음 중 실제 절전·복귀, 녹음 도중 강제 종료, 미저장 초안이 남은 상태의 강제 종료는 이번에 다시 실행하지 않았습니다. 저장이 끝난 뒤의 복구 결과를 해당 상황의 보장으로 해석하지 마세요. 다른 Mac·깨끗한 OS·외부 API·Windows·태블릿도 이번 검증 대상이 아닙니다. 이전 절전·초안 시험은 [복구 검증](mac-recovery-validation.md)과 [후속 검증](mac-recovery-followup-validation.md)에 별도로 기록되어 있습니다.
