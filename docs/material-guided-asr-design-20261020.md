# 강의자료 기반 고유명사 전사 설계

상태: **현재성 검사·힌트 snapshot·제외 이유 UI를 구현하고 동일 음성의 Whisper/Qwen 조건 비교를 완료했다.** [실행 결과와 적용 범위](material-guided-asr-20261020.md)를 먼저 참고한다. 아래 자동 용어 추출·시점별 선정은 아직 설계이며, Qwen hotwords는 실험에서만 사용한다. 기존 원음·대본·과거 출처를 보존하며, 자료의 표기가 실제 발화의 증거를 대신하지 않는다.

## 현재 구현

- `lecture_study/transcription.py:asr_prompt()`는 수동 회차 용어 → 같은 과목의 등록 개념 canonical → 현재 활성 참석자 이름을 합친다. 공백·중복을 정리하고 UTF-8 200바이트 안에 들어가는 용어를 통째로 넣는다. canonical은 문자열순이며 별칭·설명·자료 원문은 전달하지 않는다.
- `process_chunk()`는 실행 시점의 힌트를 `transcript_ranges.prompt`에 보존하고 Whisper `--prompt`로 전달한다. 자료를 연결하는 것만으로 자료의 모든 고유명사를 찾아 전달하는 기능은 없다.
- `lecture_study/qwen_asr.py:worker()`는 Korean·greedy·최대 1024토큰으로 재인식하며 현재 용어 인자를 전달하지 않는다. 현재 앱에서 힌트가 사용된다고 소개할 수 없다. 다만 설치된 MLX Audio 라이브러리 자체에는 아래의 hotwords 입력이 있다.
- 재인식은 별도 후보이며 사용자가 적용할 때만 새 대본 버전이 생긴다.

### 보완한 현재성 검사

등록 개념의 최신 버전만 읽던 기존 공백을 보완했다. `hint_snapshot()`이 검색 가능 여부·원본 파일 SHA·범위·손글씨 승인 상태를 확인한다. 여러 근거 중 하나라도 바뀌면 용어를 ‘근거 재검토 필요’로 제외한다. 직접 입력한 회차 용어와 근거 없는 등록 용어는 유지한다. 해시가 끝난 뒤 최신 범위·근거·용어 revision을 다시 확인하며, 과거 용어와 대본·출처는 삭제하지 않는다.

## 권장 흐름

### 1. 자료에서 출처 있는 표기를 수집

현재 회차에 연결한 자료와 사용자가 고른 과목 자료를 범위로 삼는다. 검색의 현재 source 검사와 손글씨 승인 가드를 재사용한다. 미승인·거절·stale OCR, 바뀐 원본의 옛 추출문, 다른 과목은 제외한다.

우선 제목·목차·정의·인명·지명·제품명·영문 병기에서 **원문에 실제 있는 문자열**을 후보로 얻는다. 기존 개념 후보의 인용 검증을 재사용할 수 있지만, 앞 3,000자에서 최대 3개만 읽는 현재 개념 제안은 긴 자료 전체의 용어 수집과 같지 않다. 모델이 아는 이름으로 고치거나 없는 별칭·발음을 생성하지 않는다.

각 후보에 표기, source ID, 원문 인용, 문서 SHA/revision, 페이지·bbox를 보존한다. 원래 source가 제공하지 않은 좌표·시각을 만들어 넣지 않는다. 사람의 이름인지 확실하지 않은 표현은 그대로 검토 후보로 둔다.

### 2. 검토와 힌트 사용을 분리

자료를 연결한 후 ‘전사 용어 후보’에서 원문과 표기를 확인하고 선택한다. 기존 과목 용어를 재사용하되 원본이 바뀐 자동 유래 항목은 다시 검토한다. 처음부터 모든 자료의 용어를 무제한 자동 주입하지 않는다.

예시(가상의 자료):

| 자료에 보이는 표기 | 함께 표시할 근거 | 사용 시 주의 |
|---|---|---|
| `Dijkstra / 다익스트라` | 원문 인용·PDF 12쪽 | 원문에 실제 병기된 표기만 연결 |
| `자그로스산맥` | 원문 인용·PDF 4쪽 | 이 단어가 자료에 있어도 해당 원음에서 발화했다고 확정하지 않음 |
| `김민수` | 원문 인용·발표자 이름 | 자료 속 저자와 실제 참석자를 자동 동일인 처리하지 않음 |

UI UX Pro Max의 오류 회복·명확한 피드백 원칙에 따라 ‘선택됨 / 원문 변경으로 재검토 / 용량 한도로 미사용’을 문자로 구분한다. 근거 클릭으로 실제 페이지를 열고, 삭제·취소와 재시도 동작을 제공한다. 현재 구현은 기존 전사 용어 화면의 제외 이유·새로 확인 기능까지다. 별도 자료 후보 선택 UI는 설계로 남긴다.

### 3. 구간별 작은 힌트를 고정

Whisper의 기존 200바이트 예산을 유지한다. 수동 우선순위는 유지하고, 자료 후보는 사용자가 고른 페이지·현재 회차와의 관련성·해당 표기의 출처를 기준으로 작은 목록을 선택한다. 페이지와 음성의 시각 정렬이 없으면 현재 화면의 페이지를 발화 시점의 페이지라고 가정하지 않는다. 동일 과목의 과거 모든 용어를 매번 주입하지 않는다.

선택 직전에 출처 현재성을 다시 검사하고 실제 전달 문자열·선택된 용어·source 버전·제외 이유·생성 시각을 snapshot으로 고정한다. 녹음 구간의 시간과 자료 승인 시각을 혼동하지 않는다. 새 자료가 추가돼도 이미 만든 대본과 이전 힌트 기록은 바꾸지 않는다.

### 4. 원음으로 결과를 판단

자료 표기는 ASR 입력 힌트와 교정 후보의 근거일 뿐이다. `다익스트라`가 자료에 있다는 이유로 비슷한 일반 단어를 문자열 치환하지 않는다.

설치된 Whisper의 힌트 유무를 먼저 비교한다. 같은 원음·같은 구간 경계·VAD·모델·출력 설정을 고정하고, 힌트만 바꾼다. 오류 의심 구간의 추가 인식은 기존 합의대로 여유 있을 때 최대 1회, 결과는 사용자 적용 후보로 남긴다. 새 입력이 원음을 대신하거나 일반 생성 LLM이 들리지 않는 이름을 채우지 않는다.

설치된 MLX Audio 0.5.8의 Qwen3-ASR 구현을 추가 확인했다. `generate(..., system_prompt=None, hotwords=None)`가 있으며 `_generate_one()`에서 `merge_hotwords(system_prompt, hotwords)`로 용어를 system 입력에 합친다. 현재 앱 wrapper가 이 인자를 전달하지 않는 것이지 모델 경로에 인터페이스가 없는 것은 아니다.

실제 설치 앱과 검증용 runtime의 `qwen3_asr.py` SHA256은 모두 `661e6e930842dcd0cd509a75964f4b0fcf4d935a52011062d2978f050bc6b38d`로 일치했다. 모델을 실행하지 않고 파일의 인터페이스·호출 연결을 확인한 결과다. 라이브러리 버전 번호만으로 추정하지 않았다. `merge_hotwords`는 문자열을 쉼표로 연결할 뿐 음향적으로 그 단어가 발화됐다고 검증하지 않는다. 길이·중복·제어문자·모델 특수 토큰 검증도 없으므로 자료에서 꺼낸 문자열을 전달하는 앱 경계에서 검증해야 한다. 원문의 지시문 전체를 system 입력으로 복사하지 않는다.

따라서 Qwen 후보 경로에도 현재성을 검사한 용어를 `hotwords`로 전달하는 작은 확장 실험을 할 수 있다. 앱 wrapper·worker 인자·후보 receipt·관련 테스트가 함께 바뀌어야 한다. 전달 목록과 실제 모델 입력을 기록하고, 같은 원음에서 **Qwen 무힌트 대 Qwen hotwords**를 별도로 비교한다. 실험 runner에서 이 정식 API를 연결해 같은 음성으로 비교했다. 일부 개선이 무관 용어에서도 재현되고 일반 발화 악화가 있어 앱 worker 연결은 보류했다. Whisper의 200바이트는 현재 앱의 제한이지 Qwen의 고유 제한이라고 설명하지 않는다. 첫 비교에서는 용어 목록을 동일하게 제한해 조건 수를 줄일 수 있다.

## 비교 계획과 적용 조건

Qwen 비교는 현재의 mono PCM16 16kHz·31초 이하·Korean·temperature 0·batch 1·최대 1024토큰을 고정하고 hotwords만 바꾼다. Qwen과 Whisper의 모델 차이를 힌트의 효과로 계산하지 않는다. 같은 정답 전사 음성을 다음 조건으로 대조한다. 원음 자체에서 정답 용어가 확인되지 않는 경우는 고유명사 정확도 집계에서 제외하고 불확실성을 남긴다.

| 조건 | 확인할 효과 / 위험 |
|---|---|
| 힌트 없음 | 기준선 |
| 기존 수동·등록 개념 힌트 | 현재 기능의 효과 |
| 현재 자료에서 선택한 소수 용어 | 표기·고유명사 누락/오독 개선 여부 |
| Qwen 무힌트 대 Qwen hotwords | 설치된 지원 API를 사용하는 재인식 후보의 추가 효과 |
| 관련 없는 용어·같은 발음의 다른 이름 | 자료에 끌려가는 오교정·삽입·환각 위험 |
| 자료 삭제·수정·필기 승인 취소 | 다음 힌트에서 제외, 과거 대본·출처 보존 |

정확한 고유명사 표기, 누락·삽입, 일반 발화 CER, 비발화·소음 구간의 환각, 처리 시간·메모리를 함께 측정한다. 고유명사만 맞고 일반 발화를 훼손하는 조합은 적용하지 않는다. 긴 강의·대화·생활 소음을 구분하고, 자료를 만들 때 참고한 정답이나 사후 작성한 정답 이름을 자동 추출 성공으로 세지 않는다.

**권장 구현 순서:** 자료 유래 용어의 현재성 검사 → 근거 있는 후보 목록과 수동 선택 → 힌트 snapshot → 동일 음성 비교 → 개선 확인 후 선택 기능 적용. 현재성 가드·snapshot·제외 UI와 동일 음성 비교까지 완료했다. 자동 추출·새 후보 UI·Qwen 기본 hotwords는 개선 근거가 충분하지 않아 적용하지 않았다.
