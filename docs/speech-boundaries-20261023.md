# 긴 한국어 음성의 발화 사이 분할 경계 비교

2026-10-23 · Mac 로컬 Whisper large-v3-turbo · 기존 분할 / VAD 200ms 쉼 / VAD 400ms 쉼

## 적용 판정

**두 VAD 경계 조건 모두 기본 전사 경로에 적용하지 않았다.** 같은 원음에서 일부 조건이 좋아져도, 수동 정답·검수 자막의 개별 조건에서 오류·삭제·삽입 증가가 남으면 채택하지 않는다. 구간을 겹치지 않게 만든 것과 전사 누락·중복이 해결된 것은 구분한다.

이번 변경은 재현용 실험 도구·회귀 검사·비식별 집계·보고서다. 설치 앱·실제 사용자 보관함·원음·완료 전사·수동 수정·필기·초안은 수정하지 않았다.

## 비교 방법

- [앞뒤 원음을 겹친 이전 시험](chunk-overlap-20261023.md)의 동일한 16개 파일과 참조를 재사용했다. 새 오디오·모델 다운로드, 전처리, 용어 힌트, 외부 API는 없다.
- 기존 `file_boundaries`는 이미 최대 30초 창의 마지막 6초에서 200ms 상대 에너지가 낮은 지점을 찾는다. 각 파일의 기존 경계는 이전에 고정한 제품 경계와 일치하는지 검사했다.
- 추가 조건은 같은 Silero VAD로 전체 원음의 발화 구간을 한 번 검출한다. 각 30초 창의 24~30초 안에 있는 **인접 두 발화 사이** 200ms 또는 400ms 이상 간격의 중앙 중 가장 늦은 지점을 택한다. 선행·후행 비발화는 사용하지 않는다.
- 적절한 간격이 없거나 VAD가 미준비·실패·발화 미검출이면 기존 에너지 분할을 사용한다. VAD로 원음을 버리거나 인식을 보류하지 않는다. ASR 내부 VAD는 기존과 같은 설정으로 유지했다.
- 실제 PCM 모든 프레임을 정확히 한 번 포함하며 구간 사이 겹침·빈틈·압축·무음 제거가 없다. 각 구간은 최대 30초이며, 마지막 남은 부분도 포함한다.
- 참조 전사나 기존 인식문으로 경계를 고르지 않는다. 세 조건의 경계·모델 실행 입력을 모두 동결한 뒤 ASR을 시작했다.
- 선택한 원본 WAV의 시간축으로 환산한 native 문장 시각을 유지한다. 경계 중앙이 0.5ms 단위면 PCM 프레임은 그대로 사용하고, 기존 인식기의 시각 표현만 ms로 반올림한다. 단어별 정렬은 아니다.

VAD는 문장 끝을 이해하는 모델이 아니다. 소음 속 발화를 쉼으로 오인할 수 있고, 자연스럽게 이어지는 발화에서 30초 안에 적절한 쉼이 없으면 기존 경계가 남는다.

## 자료·측정 범위

| 자료 | 조건 수 | 참조 범위 |
|---|---:|---|
| 실제 한국어 기술 강연 2개, 각 약 2분 | 원본·사무실·식당 6 | 검수 자동 자막. 완전한 축어 정답 아님 |
| 실제 자연 응답 56.8초 | 원본·식당 2 | 해당 발화의 수동 어휘 정답 완전 |
| 실제 자연 대화 10.5분 | 원본·식당 2 | 응답자 수동 전사만 완전, 인터뷰어 `<IVER>` 누락. 전체 CER 없음 |
| 실제 비영점 원음의 SIL 주석 | 3 | 짧은 단일 구간 비발화 대조 |
| 연속 사무실·식당·주방 환경음 각 65초 | 3 | 목표 한국어 발화 없는 대조. 실제 배경 발화 유무 불명 |

총 약 37.9분의 **파일 조건**이며 소음 대응본을 다른 독립 화자·녹음으로 세지 않는다. 환경음을 섞은 발화는 파생 혼합 조건이고, 실제 소음 현장에서 새로 녹음한 한국어 회의로 부르지 않는다. 긴 대화의 식당 소음은 기존 300.004초 환경음이 반복되지만 실제 사람 발화는 반복하지 않았다. 65초 환경음 대조는 반복 연결하지 않은 실제 연속 구간이다. 출처·조건은 [기존 자료 기록](lecture-material-hints-20261020.md)과 같다.

완전 수동 정답·검수 자막에서는 NFKC·소문자·문자/숫자 정규화 후 문자 편집 거리와 삭제·삽입·치환을 계산한다. 그 문자 수는 실제 누락·환각 사건 수가 아니며, 자막 표기·머뭇거림 편집 차이도 포함한다.

긴 대화에서는 전체 CER를 계산하지 않는다. 주석 시각과 겹친 native 문장을 이어 정답 구절의 연속 일치·반복을 부분 진단한다. 표기·분절·시각 차이로도 일치가 달라질 수 있어 단어 삭제 사건으로 단정하지 않는다. 모델 문장 전체가 SIL 주석 안에 들어간 경우만 따로 세며, 부분적으로 걸친 문장의 단어는 판정하지 않는다.

인접 구간의 마지막·첫 문장에서 정규화 suffix/prefix 4자 이상이 같은 경우를 경계 반복 후보로 기록한다. 이번 입력은 겹치지 않으므로 시각 겹침을 후보 조건으로 요구하지 않는다. 실제 발화 반복일 수 있어 자동 제거하지 않고, 이전 겹침 시험의 후보 수와 같은 지표로 직접 비교하지 않는다.

48조건을 모두 완료했고 실패는 0행이다. 실제 입력 WAV 274개를 원본 PCM에서 독립적으로 재구성해 해시를 대조했다.
전체 원음 VAD 준비 시간은 공유 비용 5.794초다. 두 후보의 실제 완료 비용에는 이 비용이 추가되며, 기준 에너지 분할에는 필요 없다. VAD 시간에는 최초 자산 검증이 포함될 수 있다. ASR 시간은 구간 처리·파일 준비를 포함한 행 시간이며 native 프로세스 시간과 구분한다. 파일 해시 대조와 세 계획 생성까지 포함한 시작~종료 전체 walltime은 별도로 계측하지 않았다. 기준 실행 초기에는 회귀 검사도 함께 진행했다. 고정된 기존→200→400ms 순서의 단회 측정으로 일반 속도 비율을 주장하지 않는다.

- Python 667개 중 662개 통과·선택 5개 생략, 프런트엔드 104개·TypeScript·CLI·링크·diff 검사를 확인했다.
- 최초 샌드박스 전체 검사에서 localhost bind를 사용하는 `test_port_collision_uses_another_loopback_listener`, `test_owned_process_env_and_only_owned_child_stopped` 두 검사가 권한 오류로 실패했다. 로컬 테스트 소켓이 허용되는 환경에서 전체 검사를 다시 실행해 통과했다.

- 별도 QA 보관함에서 새 기준 디코더 출력을 실제 파일 등록·저장 경로에 재생했다. 실제 PCM 5구간·전사 21개의 텍스트와 시각이 일치했고, QA 수정 후 과거 source snapshot 21개가 보존됐다. DB integrity `ok`·FK 오류 0이다. 추가 ASR·설치 앱 GUI 검증으로 부르지 않는다.
- UI UX Pro Max의 파괴적 변경 방지 기준에 따라 원본·기존 수정·과거 출처는 그대로 두었다. 새 UI나 사용자에게 검증되지 않은 정밀 시각을 추가하지 않았다.

[본문·경로 없는 개별 집계](verification/speech-boundaries-20261023.json)에 조건·해시·경계·삭제/삽입·부분 참조·시간·적용 판정을 보관한다. 원음·정답 전사·인식문·모델·개인 보관함은 공개하지 않는다.

## 재현

이전과 같은 연속 mono PCM16/16kHz 파일과 고정 manifest를 준비하고, 존재하지 않는 출력 폴더를 지정한다. 입력 구조는 [이전 비교기](chunk-overlap-20261023.md)의 `reference_kind`·원음 해시·분할 경계를 사용한다. 새 비교기는 기존 경계가 현재 에너지 분할과 일치하는지 검사하고 VAD 결과와 세 manifest를 ASR 전에 저장한다.

```sh
.venv/bin/python experiments/compare_speech_boundaries.py \
  --manifest /absolute/path/to/fixed-manifest.json \
  --runtime /absolute/path/to/prepared-runtime \
  --output /absolute/path/to/new-boundary-run
```

실제 설치 앱 GUI·새 마이크·절전·수집 공백·강제 종료 복구와 모든 경계의 직접 청취는 이번 실험에 포함하지 않는다. 불연속 녹음의 선언은 거절하며, 실제 packet gap의 source/stored 축을 건너지 않는 제품 변경을 구현한 것은 아니다.
