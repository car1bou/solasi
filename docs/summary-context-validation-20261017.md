# 긴 요약의 문맥·후반 누락 재검증

2026-10-17 · Mac 로컬 Qwen3.5 4B · [한국어 전사 검증](korean-asr-validation-20261017.md).

## 설계와 수정 범위

grilling 검토에서 이미 합의한 원문 발췌·문맥 보존·추가 선택 최대1회·미충족 시 원문 보완을 유지했다. ponytail 방식으로 새 모델이나 의존성을 추가하지 않고 발췌 범위와 캐시 검증만 수정했다. 원음·확정 전사·수정 이력·이전 요약을 고쳐 쓰지 않는다.

- 새 로컬 일반 요약을 `complete-v1` 정책으로 고정한다. 이미 시작한 요청은 기존 정책을 유지하고, 서로 다른 정책의 저장 구간을 섞어 재사용하지 않는다. 외부 API 요약·회의록의 기존 해석·인용 경로는 유지한다.
- 선택한 원문이 끝나지 않았으면 뒤 원문을 최대4단위 더 붙인다. 같은 출처 또는 같은 세션의 시각이 확인되고, 순방향 발화 간격이3초 이내인 구간만 연결한다. 다른 노트·자료 출처나 다른 세션으로 넘어가지 않는다.
- 앞 문맥은 최대8단위·640자·45초까지 보존하며, 발화 사이 최대30초의 쉼을 허용한다. 문장을 이어 붙이는 범위와 구분한다. 실제 인터뷰에서 11.46초의 쉼과 33.3초 앞의 자기 진술이 잘리던 원인을 이 범위 안에서 수정했다. 이 범위가 모든 대명사의 주어를 해결한다고 보장하지 않는다.
- 같은 출처에서 동일 문장이 반복돼도 발생 순서를 유지한다. 첫 문구의 위치가 여러 곳이면 임의의 첫 위치에서 앞 문맥을 가져오지 않고 확인 표시를 남긴다.
- 앞·중간·뒤 선택 외에 마지막의 짧은 원문도 검사한다. 빠지면 기존 선택을 보존한 채 최대1회 추가 선택하고, 여전히 빠지면 원문과 확인 표시를 보완한다.
- 종결 판정은 문장부호와 흔한 한국어 종결 어미의 제한된 휴리스틱이다. `으니까`를 문장 끝으로 오인하지 않도록 수정했다. 경계가 불명확한 발췌는 확인 대상으로 남긴다. 형태소 분석이나 의미적 완전성 검사는 아니다.
- AI는 원문 ID만 선택한다. 앱이 정확한 원문을 복사하며 새 주어·사실·가정 라벨을 생성하지 않는다. 원문에 있는 명확한 가정·조건을 임의로 사실로 바꾸지 않는다.

## 같은 실제 입력의 확인

### 성인 인터뷰와 사무실 소음

기존 약11분 인터뷰의 첫 녹음에 해당하는 확정 전사179개를 그대로 사용했다. 같은 세션의 두 번째 반복 녹음과 비교용 작성 메모는 입력에서 제외했다. TextGrid 정답이 있는 관련 응답과 ASR의 시각·본문 연결을 확인했다. 인터뷰어의 어휘 정답이 없는 구간이 있어 전체 대화 CER는 계산하지 않았다.

최종 frozen 모델 실행 파일로 새로 생성한 결과는 다음과 같다. 소스 도메인 함수가 최종 앱에 동봉할 `model-worker`를 파이프로 실행한 검사이며, 화면 버튼 조작 시험과 구분한다.

| 검사 | 최종 결과 |
|---|---|
| 응답자 자신의 외동 진술과 부모 동거 문맥 | 같은 발췌에 보존 |
| 부모 사망에 대한 가정과 그 전제 | 같은 발췌에 보존 |
| 현재 부모 건강 진술 | 가정 주변 발췌에 보존 |
| 원문과 다른 주어·사건 라벨 생성 | 없음 |
| 발췌의 원문 일치 | 전부 통과 |

선택8개·발췌7개·확인 표시1개였고, 새 모델 호출1회 및 후처리29.558초였다. 입력 준비·구간 분할·초기 모델 파일 검증을 포함한 화면 완료 시간이 아니다. 이전 Ollama 실행·다른 요약 형식의 기록과 속도 배수로 비교하지 않는다.

### 약15분 시각의 낭독 포함 기록

같은 확정 전사와 연결 자료·메모를 포함한306개 근거로 새 모델 선택을 비교했다. 전체 낭독의 정답 전사를 정렬한 CER 시험은 아니다. 문장의 주체·가정과 후반 사건은 원문 인용을 대조하는 별도 확인 항목이다.

문장 보완을 적용한 최초 새 생성에서는 공상·환영을 설명하는 절의 뒤 술어, 마지막 퇴장의 술어, 후반의 음수·입실 대목이 보존됐다. 물을 요청하는 짧은 대사는 주 발췌에서 빠졌다. 처리 범위와 앞·중간·뒤 선택이 충족됐다는 이유로 이 누락을 통과로 처리하지 않았다. 최종 동봉 엔진의 전체 파이프 경로 결과는 아래 실행 확인에 기록한다.

## 회귀 검사와 남은 범위

합성 문장으로 문장 중간 절단, 인과 조건절, 반복 발화 순서, 같은 문구의 다중 위치, 시간·세션 경계, 긴 쉼의 앞 문맥, 짧은 마지막 문장, 최대1회 재선택, 실패 후 이어 하기, 이전 정책·캐시·내보내기를 검사한다. 실제 코퍼스의 정답 본문은 테스트나 공개 Git에 넣지 않았다.

완전한 핵심 선택·주어 해석·전사 누락 자동 감지는 해결되지 않았다. 발췌가 정확한 원문이라는 사실과 요약이 모든 중요한 내용을 담는다는 판단은 다르다. 이번 수정은 확인한 오류를 줄이는 범위이며, 원문과 다시 듣기를 유지한다.
