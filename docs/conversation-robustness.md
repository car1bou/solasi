# 다화자·생활 소음과 긴 요약 개선

후속 검증: [종료 후 전사·요약과 화자 분리](post-recording-quality.md). 새 padding·주어 복사·미인용 원문 보존·실제 두 사람 비교와 남은 한계를 기록했다.

2026-10-14–15, Apple M4·16GiB, macOS 27.0.1. 설계 grilling, 구현 Ponytail. 아래의 완료 상태는 코드·저장·인용 계약과 실제 실행을 구분한다.

## 적용 정책

- 최초 확정 전사와 원음 저장을 우선한다. 최초 전사가 끝난 **8초 이하 비영점 원음의 빈 결과**, 또는 12자 이상 같은 문장이 3회 이상 반복된 구간은 최대 한 번 추가 인식한다. 이 조건은 오인식 확률로 보정된 기준이 아니다. ‘감사합니다’ 같은 문구를 삭제하지 않는다.
- 최초 전사 큐, 로컬 생성·색인·검색 임베딩이 진행·대기 중이면 추가 인식을 미룬다. 새 확정 전사가 생기면 진행 중인 추가 인식을 취소한다. 취소된 자동 시도는 자동 반복하지 않으며 수동 재시도가 가능하다. 이미 진행 중인 일반 생성은 기존 합의대로 유지한다.
- 추가 인식은 같은 Whisper의 **VAD를 끈 후보**다. 첫 결과와 원음, 후보를 나란히 제공하고 사용자가 편집·적용하면 새 버전으로 저장한다. 기존 문장 수가 다르면 첫 ID를 유지하는 전체 구간 수정으로 적용하고 나머지 옛 문장·출처·원음 연결을 보존한다. 후보 생성 이후 수동 수정한 전사는 덮어쓰지 않는다.
- 긴 빈 전사도 원음과 **다시 인식** 버튼을 보여 준다. 자동 범위를 넓히지 않고 사용자가 해당 구간을 요청한다. 원본 이동·삭제·변경으로 선택적 후보를 준비하지 못해도 다음 최초 전사를 계속한다.
- 새 일반 요약은 시간순 문맥·실제 직렬화 입력 예산으로 묶는다. 같은 녹음의 문맥은 최대 120초, 구간 간 공백은 30초를 기준으로 나누고 큰 원문은 텍스트 손실 없이 쪼갠다. 앱이 관리하는 고정 Qwen3.5 4B MLX는 검증한 로컬 토크나이저로 계산하고, 다른 모델은 보수적인 UTF-8 바이트 예산을 사용한다. 새 일반 요약의 출력 예약은 `min(2048, context_limit / 4)`이며 실제 요청의 출력 한도와 같다.
- **처리한 원문 ID·시간 범위와 최종 항목의 실제 인용을 분리**한다. 선택한 모든 원문을 처리하지만 최종 인용 집합이 전체 집합과 같아야 한다는 조건은 새 일반 요약에서 완화한다. 없는 출처·임의 시각은 거절한다. 일반 요약의 병합 결과는 최대6개 항목·항목별 최대6개 직접 인용으로 제한해 다음 병합의 입력 팽창을 줄인다. 전사·자료 요약에는 최소 한 항목이 필요하며, 작성 요청만 있는 메모 구간은 빈 결과가 가능하다.
- 이전 작업의 고정 분할·정책은 유지한다. 구간 결과·병합 캐시는 재시도에 쓰며, 최종 실패에서도 완료한 구간을 인용과 함께 열 수 있다. 회의록의 모든 원문 인용, 결정·담당자·기한 검사는 유지한다. 명시적인 담당 후보·미정·부정은 확정 담당자로 저장하지 않는다.
- 수치의 대상·단위·주어, 좌우, 부정·조건과 후반 정정 보존을 모델에 요구한다. 일부 명확한 좌우·기간/온도 불일치는 원문 대조 경고로 표시한다. 이 경고와 출처 ID 검사는 일반적인 의미 검증을 대신하지 않는다.

## 자료와 접근 조건

[서울코퍼스 공식 OpenSLR113](https://www.openslr.org/113/)의 성인 인터뷰 3개를 모델 출력 전에 선정했다. 남성 25세·23세, 여성 22세 응답자와 인터뷰어의 실제 턴 교대가 포함된다. 원본 길이는 각각 586.797375 / 666.3299375 / 632.8011875초다. **인터뷰어의 `<IVER>` 구간에는 단어 정답이 없다.** 전체 대화 CER를 계산하지 않는다. 화자 분리·겹침 발화 정답 검증도 아니다. 라벨 SHA와 음원 CRC·크기·로컬 SHA는 수집 manifest (로컬 검증 자료·공개본 미포함)에 남겼다.

[DEMAND 공식 배포](https://zenodo.org/records/1227121)의 사무실 `OOFFICE/ch08.wav`와 구내식당 `PCAFETER/ch08.wav`를 사용했다. 각 실제 길이는 300.004초다. 원음과 실제 환경 소음을 전역 SNR10dB로 섞고 길이를 반복한 **파생 혼합 조건**이며, 현장에서 녹음한 회의를 뜻하지 않는다. 실제 환경 음원에 사람 목소리가 있을 수 있어 ‘완전 무발화’로 부르지 않는다.

새 정답 발화 15개 × 깨끗한 원음/사무실/식당 = 45조건, 약 1분 연속 대화 6개 × 3조건 = 18조건이다. 기존 일반 발화·저음량·방·Gaussian 잡음·강연 39조건을 함께 비교했다. 정답 구간을 잘라 인식한 CER와 연속 대화의 출력·시간·부하를 구분한다. 같은 15문장·152문자가 반복되므로 모집단·새 모델의 우열을 일반화하지 않는다.

서울 자료는 CC BY-NC2.0이다. DEMAND 레코드와 제작자 문서의 라이선스 표기가 달라 더 보수적인 제작자 CC BY-SA3.0 조건으로 개인 비상업 시험만 수행했다. 음원은 Git·앱에 배포하지 않는다. 큰 압축 파일은 필요한 prefix와 선택 WAV/FLAC만 보관했으며, 방문한 항목의 CRC를 확인했다. 전체 archive를 모두 받거나 전체 공식 checksum을 확인했다고 주장하지 않는다. 회원 등록·TalkBank 약관 동의는 진행하지 않았다.

## 음성 감지 비교와 결정

같은 Whisper large-v3-turbo로 최소 발화 250ms / 100ms / VAD off를 한 번씩 순차 실행했다. 확정 패딩은 200ms, 용어 힌트는 없음이다. 문자 점수는 NFKC·소문자·문자/숫자만 남긴 최소 편집 거리다. 삽입·삭제·대치 수는 정렬의 편집 성분이며 의미적 환각률·누락률로 부르지 않는다.

| 정답 입력 | 기본 250ms | 100ms | VAD off |
|---|---:|---:|---:|
| 깨끗한 성인 15개, 152자 | 13 / 152 (8.55%) | 20 / 152 (13.16%) | 35 / 152 (23.03%) |
| 같은 성인 + 실제 사무실 | 15 / 152 (9.87%) | 14 / 152 (9.21%) | 32 / 152 (21.05%) |
| 같은 성인 + 실제 식당 | 30 / 152 (19.74%) | 30 / 152 (19.74%) | 54 / 152 (35.53%) |
| 기존 저음량 5개 | 30 / 223 | 30 / 223 | 13 / 223 |
| 기존 즉흥 발화 12개, 한 화자 | 68 / 256 | 68 / 256 | 51 / 256 |

100ms에서 0.21025초 ‘그냥’이 ‘이 시각 세계였습니다’로 바뀌었다. VAD off도 짧은 ‘예’를 뉴스 문구로 잘못 완성했다. **기본 250ms를 유지한다.** VAD off는 84조건 중 13개 개선·10개 악화·61개 동일이며 합계는 209→230편집/1726자로 나빠졌다.

반면 ‘뭐 사람이 뭔가 딱히 궁금하지도 않고요’의 첫 결과 ‘원하지도 않고요’는 후보에서 앞부분을 회복해 10→1편집으로 줄었다. ‘월급 대부분을 생활비로 쓰느라 저축은 생각도 못 해요’도 9→1편집으로 줄었다. 후보가 항상 낫지는 않아 자동 채택하지 않는다. 실제 디지털 0샘플 1초·6초와 선택한 실제 환경 음원 6초에서 기본 설정 출력은 모두 비었다.

기본 원자료 (로컬 검증 자료·공개본 미포함), 100ms (로컬 검증 자료·공개본 미포함), VAD-off 후보 (로컬 검증 자료·공개본 미포함), 집계·쌍별 비교 (로컬 검증 자료·공개본 미포함).

## 실제 긴 대화와 생성 동시 실행

같은 남성 23세 인터뷰 + 사무실 소음 **666.3299375초(11분 6초)**를 실제 속도로 두 번 실행했다. 실제 HTTP 인증·WebSocket/TCP·WAV·Whisper와 Qwen을 사용했고 모델 대역은 없다. 동시 실행의 질문 11건은 같은 작성된 프로세스/스레드 근거를 사용하는 부하이며, 인터뷰에 대한 답변 품질 평가와 구분한다.

동시 생성의 제출→완료 중앙값 22.94초·최대29.65초, 출력167–239토큰이었다. 첫 토큰 시간은 측정하지 않았다. 전사 지연에는 최대30초 구간 확정을 기다리는 시간이 포함된다. 한 번씩 고정 순서로 실행했고 호스트 상태·출력 길이도 달라 제품 속도 개선율이나 반복 하드웨어 벤치마크로 일반화하지 않는다. 시간·출력·파형 집계 (로컬 검증 자료·공개본 미포함), PCM 동일성·작업 완료 증거 (로컬 검증 자료·공개본 미포함).

**브라우저 시험은 완료되지 않았다.** 실제 worklet 경로에서 약651.5초 저장 후 연결이 닫혔고 21.333ms 공백을 기록했다. 이후 도구의 모든 탭이 없어졌으나 원인을 확정하지 못했다. 해당 실행은 실패 기록 (로컬 검증 자료·공개본 미포함)으로 보존했다. 위 성공 표는 TCP 파일 replay이며 마이크·브라우저 수집·절전 복구의 성공으로 대체하지 않는다.

2026-10-15 후속 변경: 아래는 이전 경로의 진단·실측이다. 새 일반 요약의 주어·발언 성격·원문 구절 보존과 선택 방식, 후반 누락 검사, 브라우저 중단 추가 조사는 [요약 보존](summary-fidelity.md)을 따른다.

## 긴 요약의 실패 원인과 실제 재실행

두 가지 실패를 분리해 수정했다.

1. 짧은 전사 조각마다 요약하고 최종 인용에 모든 ID를 요구해 호출 수와 인용 목록이 커졌다. 새 일반 요약은 문맥으로 묶고 처리 범위와 실제 인용을 분리한다. 병합의 항목·인용 개수도 제한한다.
2. 한국어 UTF-8 바이트 수를 토큰 상한으로 사용해 **기본8K 인터뷰**가 13구간·4병합, 345.904초 뒤 두 결과를 합칠 수 없다고 실패했다. 실제 구간의 native 입력은 약1,100–1,250토큰이어서 입력 예산을 과하게 잡고 있었다. 앱이 준비한 Qwen4B MLX의 현재 tag의 모델 내용이 SHA로 검증한 고정 manifest와 같고 tokenizer SHA도 확인한 프로필만 사용하도록 보완했다. 모델을 고정한 뒤 전사 대기 중 바뀌면 chat 전에 거절하며, 생성 뒤에도 digest를 검사한다.

토큰 계산은 각 메시지의 실제 tokenizer 결과 + schema 문자 토큰 + template 예약200이다. 정확한 렌더된 프롬프트 토큰 수라고 부르지 않는다. 실제 native `prompt_eval_count`가 계산 상한보다 크거나 없으면 저장을 거절한다. Ollama가 현재 tag에 덧붙이는 distribution/index metadata layer만 제외한 전체 내용을 고정 manifest와 대조한다. 다른 runner·tensor/config/tokenizer 내용은 같아야 한다. 현재 tag가 다른 runner거나 관리되지 않는 엔진이면 기존 byte 계산을 사용한다. `tokenizers==0.23.3`과 전이 의존성을 lock에 고정했으며 새 모델 가중치는 받지 않았다. 기본8K의 입력 계산 재구성 (로컬 검증 자료·공개본 미포함).

실제 인터뷰 (로컬 검증 자료·공개본 미포함), Qwen 기본8K 전체 새 실행 (로컬 검증 자료·공개본 미포함), 실패한 기본8K (로컬 검증 자료·공개본 미포함), 12B 전체 (로컬 검증 자료·공개본 미포함), Qwen 캐시 재사용 (로컬 검증 자료·공개본 미포함), 시간순 메모 (로컬 검증 자료·공개본 미포함). 모두 별도 DB 사본이며 녹음 종료 후 실행했다. 메모는 비교용 작성 요청이고 원문 정답이 아니다. 이전 캐시의 지시문 snapshot이 없어 exact evidence/cutoff만 확인한 재생이며, 같은 작업의 UI 재시도나 제품 속도비로 해석하지 않는다.

12B의 옛 조각별 전체 시험은 1,811.420초 뒤 실패했다. 새 문맥 정책의 전체 완료는 확인했지만 출력 길이·모델 상태·호스트 부하·정책이 다르므로 이를 고정 가속 배율로 제시하지 않는다. Qwen의 이전9구간 결과도 병합 입력 팽창으로 실패했고, 새 항목·인용 제한과 tokenizer 경로에서 병합 완료를 확인했다. **구조·인용 통과가 의미 품질 통과를 뜻하지 않는다.**

### 내용 대조와 남은 오류

후반 정정·숫자·부정·조건·미결을 분리한 작성 자료를 두 문맥 구간에 배치해 실제 모델로 병합했다. 이 시험의 PCM은 시간 등록용이며 음성 인식 시험이 아니다.

- Qwen 일반 요약35.663초: 120만원 제안·미승인, 금요일4대 취소→월요일3대 미확정, 외부 전송 금지·로컬 조건·계약 미결을 나타냈다. 수치·키워드 guard는 통과했지만 ‘보안 예산’, ‘승인 불성실’ 같은 원문 밖 표현이 남았다. 같은 회의록은 7.512초 뒤 명시적 결정 근거 검사에서 거절했다.
- Gemma12B 일반 요약109.049초·회의록136.211초: 작성한 수치/정정/부정/조건 guard와 구조화 담당자 이서연·2026-10-19 기한, 김민수 미확정 검사를 통과했다. 작은 작성 사례이고 일반 의미 완전성 검증은 아니다.

Qwen 내용 제어 시험 (로컬 검증 자료·공개본 미포함), 12B 내용 제어 시험 (로컬 검증 자료·공개본 미포함).

실제 인터뷰에서는 ‘외동입니다·부모님과 함께 있습니다’를 응답자의 자녀 양육 이야기로 바꾸거나 아버지의 출생지를 발언자에게 연결했다. ‘절대 일어나서는 안 되지만 … 돌아가셨을 때 … 생각하니까’라는 가정을 ‘부모 상실’ 사건으로 요약한 오류도 남았다. 낭독에서는 ASR 오탈자를 설명으로 확장하거나 동경에서 얻으리라는 기대를 이미 얻은 사건처럼 표현했다. Qwen의 기본8K 전체 새 실행은 바늘 대신 눈동자가 손톱 밑을 침투했다고 쓰거나 후반 서사를 최종6항목에서 빠뜨렸다. 처리293개는 모든 원문을 입력한 범위이며 모든 핵심 내용이 최종 요약에 남았다는 증명이 아니다. 모호한 음성과 주어·가정의 해석은 아직 자동으로 보장할 수 없다. 요약과 메모는 원래 구간·출처를 확인하는 초안이다.

12B 본문의 `[s52, …, l113]` 같은 임시 인용 목록은 클릭할 수 있는 구조화 인용과 별개였다. 새 일반 요약은 원문에 실제 같은 변수 표기가 없을 때 이 목록을 제거하고 변경 전 결과를 metadata에 보존한다. 기존12B 결과에 대한 **별도 후처리**에서 목록13개 제거·구조화 인용 동일·입력 불변을 확인했다. 새12B 추론이나 의미 오류 수정으로 보고하지 않는다. 후처리 증거 (로컬 검증 자료·공개본 미포함).

마지막 캐시 없는8K 시험 중 tag wrapper를 raw SHA로 비교해 정상 MLX도 fallback으로 처리하는 문제를 발견했다. 해당 실행은 명시적으로 중단해 중단 기록 (로컬 검증 자료·공개본 미포함)에 보존하고 wrapper 내용 대조·회귀 검사를 보완했다. 이 실행 시간을 완료 시간이나 모델 실패율로 사용하지 않는다.

## 저장·UI·코드 확인

- 최신 앱을 포트62434에서 재시작하고 schema14→15 이행 후 원래 모든 컬럼 값·행 동일·integrity/FK 정상, 기존3기록·노트2·출처11·결과1·녹음2 및 기본Qwen/임베딩·설치5모델을 확인했다. 최종 저장 검사 (로컬 검증 자료·공개본 미포함), 최종 검사 집계 (로컬 검증 자료·공개본 미포함). 전사 후보 적용은 새 버전·옛 전사·원음·기존 답변 근거를 보존한다. 선택적 재처리 실패가 최초 전사 큐를 멈추지 않는 경계도 검사했다.
- 전사 후보의 원문/후보/편집/적용·긴 빈 전사의 수동 버튼·실패 요약 완료 구간은 실제 브라우저/API/DB에서 확인했다. 이 화면 시험은 모델·ASR 대역과 작성 PCM을 사용했으며 실제 음성 정확도와 구분한다. UI 증거 (로컬 검증 자료·공개본 미포함).
- 최종 백엔드212개/31.599초·프런트엔드24개, TypeScript·Vite 빌드·Python compileall·설치 의존성 검사 통과. 독립 정적 리뷰에서 최초 전사 큐·취소/종료·담당 부정·모델 변경 경계를 찾아 회귀 검사와 함께 수정했다.

## 재현

모든 실험은 개발 환경에서 별도 DB를 사용한다. 음원·모델은 승인한 로컬 캐시가 필요하며 모델은 한 번에 하나씩 실행한다. 아래 `*-rerun.json`과 임시 폴더는 새 이름이어야 한다.

```sh
.venv/bin/python experiments/collect_conversation_conditions.py
.venv/bin/python experiments/evaluate_conversation_conditions.py --mode 250 --legacy --windows --output /tmp/conversation-vad250-rerun.json
.venv/bin/python experiments/evaluate_conversation_conditions.py --mode 100 --legacy --windows --output /tmp/conversation-vad100-rerun.json
.venv/bin/python experiments/evaluate_conversation_conditions.py --mode off --legacy --output /tmp/conversation-off-rerun.json

.venv/bin/python experiments/serve_long_recording_fixture.py /tmp/conversation-long-rerun .local-state/runtime/conversation-20261014/s12m23f1-office.wav single
# 위 서버를 유지하고 별도 터미널에서 실행
.venv/bin/python experiments/replay_long_recording_tcp.py /tmp/conversation-long-rerun
.local-state/runtime/qwen-eval-venv/bin/python experiments/build_long_recording_report.py --align /tmp/conversation-long-rerun

.venv/bin/python experiments/validate_recording_assistance.py /tmp/conversation-long-rerun qwen3.5:4b --output /tmp/conversation-summary-rerun.json --cutoff-ms 0 --context-limit 8192
.venv/bin/python experiments/validate_summary_preservation.py qwen3.5:4b --output /tmp/summary-content-rerun.json
```

새 corpus 전체 회원 데이터·현장 회의·화자 분리·겹침·물리 마이크 30–60분·M5/원격 GPU·외부 API는 아직 검증하지 않았다. 원음이 없는 시간을 복구하거나 LLM으로 채우지 않는다.
