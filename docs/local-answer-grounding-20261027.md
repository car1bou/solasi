# 로컬 답변의 설명·한계 문구 비교

## 현재 결론

**시험한 자유 답변 지침과 반복 억제 옵션은 적용하지 않았다.** 기존 질문을 개선하는 후보에도 실제 정보 부족 누락·반복·모순된 한계 문구가 남았다. 사용자가 후속 설계인 **원문 우선 답변·추가 해설은 선택**을 승인해 이 방식으로 구현했다. Qwen 모델·기존 작업·과거 답변·원문 발췌 요약은 유지한다.

## 고정한 자료와 실행 조건

Mac의 기존 Qwen3.5 4B, 기존 모델 파일, 동일한 질문·근거·인용 schema를 사용했다. 외부 API와 새 모델 다운로드는 사용하지 않았다.

- 실제 공개 혼합 손글씨 이미지의 **사용자가 확인한 인식문**: `누적분포함수 CDF: F(x) = P(X ≤ x). a < b이면 F(a) ≤ F(b).`
- 기존 GUI 검증용 메모: 지민은 외동이다. 부모님이 돌아가신다면 혼자 남을까 걱정한다는 **가정**이며 실제로 돌아가셨다는 뜻이 아니다. 후반 결론은 금요일 복습과 제출 기한 미정이다. 인물·일정은 가상 검증 내용이며 실제 인터뷰나 회의가 아니다.
- 작성자가 명시된 경우의 양성 대조만, 작성자 `은서`를 명시한 **합성 자료**로 만들었다.

이 시험은 승인한 인식문을 읽는 답변 생성의 비교다. OCR 정확도나 한국어 전체 답변 정확도를 측정한 결과가 아니다. 지침 비교는 기존 설치 앱의 내장 model-worker, temperature 0, thinking 비활성화로 실행했다. 약한 반복 억제 비교는 동일 체크포인트·버전이 고정된 MLX 라이브러리를 사용하는 별도 검증 worker에서 실행했다. 새 옵션은 설치 앱에 반영하지 않았다.

출처 ID·페이지·시각은 기존 검증기로 검사하고 내용은 별도로 대조했다. 이전 실제 출력은 전체 messages가 일치할 때만 기준 출력으로 재사용했으며 기록에 출처를 남겼다. 여러 차례 같은 작은 자료로 지침을 조정했으므로 일반 성능 수치로 해석하지 않는다.

## 실제 출력에서 확인한 문제

| 질문·조건 | 관찰 | 판정 |
|---|---|---|
| 기존 지침의 CDF 정의·성질 | 원문에 없는 `단조비增함 (단조증함수)`를 붙이고, 전달한 승인 손글씨의 구체적 내용이 없다는 한계 문구 생성 | 원래 문제 재현 |
| 불확실성 범위만 보완 | 무관한 한계는 줄었지만 잘못된 수학 부연이 남음 | 제외 |
| 답변 범위를 좁힌 초기 지침 | 수식 질문은 개선됐지만, 메모의 등장인물 지민을 노트 작성자로 추정 | 제외 |
| 역할 구분·예시를 보완 | 작성자 질문은 개선됐으나, 증명을 요청하면 정의·성질만 주고 증명 부재를 표시하지 않는 결과 | 제외 |
| 요구 항목별 정보 부족을 설명하는 지침 | 정의·작성자·증명 부재는 개선됐지만, 일정 정정 질문에서 180초 제한 시간 초과가 두 번 발생 | 제외 |
| 위 지침의 짧은 출력 진단 | 256토큰에서 `제공된 자료에는 일정이 변경된 기록이 없습니다`를 반복, length로 종료 | 반복 원인 확인용; 통과 결과 아님 |
| 간결화·부족 항목을 짧게 쓰는 후속 지침 | 동일 일정 질문에서 제한 시간 초과, 또는 증명 부족을 숨기는 회귀 | 제외 |
| 반복 패널티 1.05 | 약 141초 후 종료했지만 같은 원문·한계 문장을 여러 번 반복 | 제외 |
| 반복 패널티 1.1 | 약 136초 후 종료했지만, 일정을 인용한 뒤 `ink_note와 page_note의 텍스트는 복습 일정을 언급하지 않습니다`라는 모순된 한계 생성 | 제외 |

요구 항목별 지침은 정의·원문 그대로 답하기·없는 작성자와 시험 날짜·부분 부족·가정과 후반 일정·부등호·없는 증명·거짓 일정 변경·명시된 작성자·미정 담당자의 10개 질문을 실행했다. 한 질문의 시간 초과를 포함해 평가했으며 통과율이나 개선율로 포장하지 않는다. 자유 답변 후보의 추가 두 질문은 탈락 시점에 실행하지 않았고, 이후 원문 우선 방식의 12개 질문 비교에 포함했다.

기존 지침도 동일 일정 질문에서 약 36초와 95초로 시간이 달랐다. 따라서 서로 다른 부하에서 수집한 시간을 속도 개선 비율로 비교하지 않는다. 다만 반복 출력과 제한 시간 실패 자체는 관찰된 실패다.

## 요약 대조와 보존

로컬 원문 발췌 요약은 자유 답변과 다른 경로이므로 공통 지침을 변경하지 않았다. 보관함 복사본 두 개에서 실제 요약을 실행했다. 기존 저장 요청과 새로 고정한 요청은 JSON 저장 표현으로 정규화한 뒤 **모든 필드가 같았으며**, 두 요약 본문도 완전히 같았다. 주어·가정·실제 사건이 아니라는 부정·후반 금요일 일정·미정 제출 기한·두 수식을 모두 보존했다. 실행 시간은 각각 약 52초와 49초이며, 속도 개선 시험이 아니다.

정책 고정의 비공개 구현 시안에서는 새 작업의 제출 시점부터 실제 system과 정책 ID를 저장하고, 근거 고정·예산·실행·재시도에 같은 값을 쓰도록 구성했다. 독립 검토에서 과거 snapshot 단계 실패 작업이 새 지침으로 재시도될 수 있는 문제를 발견해 회귀 검사로 재현하고 보완했다. 실패한 자유 답변 지침을 적용하는 시안은 제품에 반영하지 않았고, 작업 고정 구조는 후속 원문 우선 방식에 재사용했다.

기존 결과의 한계 문구를 문자열 규칙으로 삭제하지 않았고, uncertainty를 강제로 비우지 않았다. 원래 보관함에는 새 비교 작업을 쓰지 않고 복사본과 별도 검증 폴더를 사용했다. 기존 10개 테이블의 모든 행을 전체 내용으로 대조했고 변경·누락은 없었다. 원음·자료·연결 원본 57개 파일의 SHA256도 같았다. 필기 11개 문서·44개 버전과 승인/후보 인식 기록 17개, 저장 결과 15개, 기존 초안 16개를 포함한다. 인증 파일이나 키를 출력·수정하지 않았다.

## 승인한 원문 우선 방식

사용자가 원문 우선 답변과 선택적인 추가 해설을 승인했다. 모델은 짧은 원문 구간 ID만 반환하고 앱이 검증한 인용문과 실제 출처를 조합한다. 새로 쓴 수학 설명·작성자·사건 라벨·한계 문구를 기본 답변에 넣지 않는다. 추가 해설은 별도 입력과 생성 버튼을 사용하며 접힌 영역을 여는 것만으로 추론하지 않는다.

동일 자료의 실제 12개 질문을 이 경로로 실행했다. 모든 실행이 완료됐고, 선택 응답은 전달한 구간 ID만 포함했다. 표시한 각 인용문은 원문의 정확한 부분 문자열이고 출처·페이지는 실제 값이다. CDF 두 수식과 ≤, 지민이라는 주어·가정·실제 사건이 아니라는 부정·후반 금요일 일정·미정 기한이 보존됐다. 명시된 작성자 양성 대조도 해당 원문을 선택했다. 엄격한 증가 질문에서도 원래 ≤를 <로 바꾸지 않았다.

이는 12개 질문에 모두 정답을 생성했다는 뜻이 아니다. 작성자·시험 날짜·증명이 없는 질문에도 모델이 주변 구간을 선택하는 한계가 관찰됐다. 이를 정답·증명·담당자로 명명하지 않고 **관련 원문**으로 표시하며 사용자가 읽도록 한다. 빈 선택은 확보한 검색 근거 연결을 함께 제공한다. 원문 선택 누락·관련성 문제와 선택적 자유 해설의 부정확성은 남아 있다.

기본 답변은 모델 출력 예산 512와 실제 선택 입력·schema를 함께 계산한다. 긴 근거는 문장 분리로 늘어나는 ID·출처 비용까지 확인하며 발췌한다. 과거 snapshot과 고정 작업은 이전 지침을 유지하고, 새 작업은 제출 시점부터 지침·정책·형식·예산을 고정한다.

검토에서 빈 선택의 근거 연결 누락과 다른 질문의 실행 중 해설을 잘못 복원할 수 있는 UI 문제를 발견해 보완했다. 추가 해설 자동 복원은 질문과 과목·회차·자료·페이지·문서 버전·선택 회차가 맞는 작업으로 제한한다. 부모 질문과 해설의 미저장 입력 보호는 서로 구분한다.

## 구현 검증

분리한 Mac 소스의 전체 회귀 검사는 692개 중 688개 통과·선택 검사 4개 생략이다. 기본 UI 빌드와 검사 106개(기존 105개와 질문/범위 복원 1개)를 통과했다. 현재 진행 중인 별도 UI 개발을 보존한 화면 스냅샷도 빌드하고 114개 검사를 통과했다. 해당 별도 개발 변경은 이번 커밋에 포함하지 않는다.

실제 Solasi 0.3.28/build38에 설치하고 다음을 확인했다.

- 같은 CDF 질문은 실제 원문 두 수식만 저장했고, 승인 손글씨 v1과 원본 1쪽이 열렸다. 실제 Markdown 파일에도 관련 원문과 정확한 출처 ID가 남았다.
- 추가 해설 영역을 열기 전후 AI 작업 수는 5개로 같았다. 생성 버튼을 누른 뒤에만 해설 작업 한 건이 추가됐다. 해설의 내보내기에는 ‘추가 해설 · AI 생성’ 제목이 남았다.
- 시험 날짜만 요청한 추가 질문은 빈 선택으로 완료됐다. 화면의 ‘확보한 검색 근거’에서 승인문과 페이지 메모 v2를 열 수 있었다. 다른 질문의 기존 해설은 자동으로 표시하지 않았다.
- 추가 해설 입력을 수정한 상태에서는 다른 결과로 이동하지 못했고, 입력을 되돌린 뒤 정상 이동했다.
- 정상 종료·재실행 후 원문 답변·해설을 각각 다시 열었다. 기존 요약의 주어·가정·부정·후반 내용도 표시됐다. 재실행 전후 AI 작업은 7개로 같았다.
- 기존 10개 테이블의 원래 행과 57개 보호 파일은 변경되지 않았다. 검증용 새 답변 2개와 해설 1개만 별도 저장 결과로 추가했다. 필기·원음·기존 초안과 과거 결과는 유지됐다.

선택적으로 실행한 자유 해설에서는 기존의 잘못된 수학 부연과 무관한 한계 문구가 다시 관찰됐다. **자유 해설의 정확도를 개선했다고 주장하지 않는다.** 기본 결과에서 이를 제외하고 원문과 구분한 변경이다. 원문 선택의 관련성과 누락도 완전히 해결되지 않았다.
