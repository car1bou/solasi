# Qwen의 VAD 적용: 동일 한국어 원음 비교

2026-10-20 · Apple M4 / 16GiB · macOS 27.0.1

## 결과와 적용

**VAD가 발화를 찾지 못한 원음의 출력을 보류하는 효과를 확인했다. 발화가 있는 구간의 전사 내용·문자 오류 수는 개선되지 않았다.**

제품에는 사용자가 승인한 **자동 Qwen 재인식 후보의 발화 미검출 보류**만 반영했다. 최초 전사에서 이미 성공한 VAD 결과를 재사용하며, 원문·원음·필기를 바꾸지 않는다. 사용자가 직접 요청하는 재인식은 원음 전체로 실행한다. VAD 검사 불가·실패를 발화 없음으로 취급하지 않는다. 여백을 둔 잘라내기나 Qwen 용어 힌트 연결은 적용하지 않았다.

## 자료와 대조 조건

자료는 [직전 강의자료 기반 힌트 비교](lecture-material-hints-20261020.md)의 **같은 13개 PCM 파일·같은 참조 전사·같은 용어 목록**이다. 새로 모은 독립 음성 자료로 계산하지 않는다.

- 실제 한국어 기술 강연 2편의 약 2분 연속 발화, 발표자 원본 슬라이드, 사람이 검수한 자동 생성 자막.
- 사람이 전사한 서울코퍼스 인터뷰 3명의 새 발화 구간.
- 실제 사무실·식당 환경 소음을 섞은 파생 조건.
- 사람이 비발화(SIL)로 주석한 3개 비영점 원음. 빈 lexical reference이며 CER를 계산하지 않는다.

원본 출처·이용 조건·선정 과정은 이전 보고서와 같다. 강연 자막은 완벽한 축어 정답이 아니며, 인터뷰어·겹침 발화를 포함한 전체 대화의 CER는 발표하지 않는다.

각 파일에 `힌트 없음 / 슬라이드 목록 / 무관한 명칭`을 적용한다. 인터뷰·SIL의 슬라이드 목록은 LAMP 목록을 주는 범위 밖 용어 대조다. 실제 같은 과목의 관련 용어로 해석하지 않는다. 발표 슬라이드 용어는 이전 시험에서 자막 다운로드 전에 고정됐다.

| 방식 | 입력 처리 | 목적 |
|---|---|---|
| `off` | 기존 30초 이하 원음 조각 그대로 | 새 무적용 대조군 |
| `gate` | 발화 범위가 명시적으로 빈 조각만 추론 생략. 나머지 PCM은 그대로 | 비발화 차단 효과 분리 |
| `trim` | 첫 발화 시작−1초부터 마지막 발화 끝+1초까지 한 구간으로 유지. 원음 범위로 제한 | 앞·뒤 여백 제거의 추가 효과 |

세 방식 모두 같은 최초 30초 경계를 사용한다. `trim`도 **중간 침묵을 제거하거나 발화별로 나누지 않는다.** 문맥은 각 30초 조각 안에서 유지하며 강연 전체를 하나의 입력으로 제공하지 않는다. VAD가 `None` 또는 오류를 반환한 경우는 실험 실패이며 빈 목록으로 대체하지 않는다.

Qwen은 기존 `mlx-community/Qwen3-ASR-1.7B-4bit`, 한국어, temperature 0, batch 1, 조각별 최대 1,024토큰이다. 실제 기존 모델·MLX 환경을 사용했고 새 모델은 받지 않았다. 이번에는 Qwen 안에서 비교했으며 Whisper는 재실행하지 않았다.

## VAD와 원음 시각

기존 제품의 `transcription.speech_activity()`를 사용했다.

- Silero v6.2.0, pinned native whisper.cpp 1.9.5 유틸리티.
- threshold 0.5, 최소 발화 250ms, 최소 무음 100ms, native padding 0ms, CPU 1 thread.
- 모델·유틸리티 해시와 검출 범위를 기록했다. `trim`의 1초 여백은 검출 뒤 별도로 적용했다.
- 발화가 있는 원본 31개 조각 모두에서 발화를 검출했고, SIL 3개 조각은 모두 빈 목록이었다.
- 같은 발화 조각 31개를 20dB 낮춘 **VAD 민감도 전용 검사**에서도 빈 목록은 0이었다. 이 검사는 Qwen 추론·CER 비교에 포함하지 않았다. 단어나 발화 전체가 검출됐다는 보장은 아니다.

native 검사는 파일 길이를 밀리초로 반올림한다. PCM 끝을 몇 프레임 넘을 수 있어 실제 프레임 수로 crop을 제한했고, 해당 조건의 RED→GREEN 회귀 검사를 추가했다. 원본 범위·선택 범위·각 SHA256을 보존하며 글자 수로 시각을 만들지 않는다.

실제 `trim`이 발화 파일에서 덜어낸 원음은 WSL 원본 70ms·사무실 10ms·식당 40ms로 합계 120ms였다. 다른 발화 파일은 1초 여백 아래에서 원본 전체가 남았다. 따라서 적극적인 내부 무음 제거·세밀한 발화 분할의 효과를 입증하는 시험이 아니다. 고정 30초 경계는 설치 앱의 `quiet_cut` 경계와도 다르다.

## 주 비교 결과

**13파일×3용어 조건×3방식 = 117개 결과**를 완료했다. VAD로 출력 차이가 생긴 SIL 3개 파일만 용어 조건을 역순으로 다시 실행했다(27개 결과). 초기 6파일 반복 계획은 역순 실행 전에 SIL 3개로 좁혔고 이전 계획은 로컬에 보존했다. 반복은 사후 일관성 확인이며 독립 품질 검증이 아니다.

총 **144개 결과, 실제 Qwen generate 297회**, 실패·토큰 상한 도달 0회다. 상한 대비 최대 생성은 169토큰이었다. 새 `off`의 39개 결과는 이전 시험의 같은 결과와 문장·표기까지 모두 같았다.

### 발화 구간

- `gate`는 발화 30개 조건 모두에서 `off`와 문자열까지 같았다.
- `trim`은 발화 30개 조건 중 27개가 문자열까지 같았다. 3개 차이는 띄어쓰기·문장부호이며 **정규화한 내용·CER·치환/삭제/삽입 수는 30개 모두 동일**했다.
- 역순 SIL 반복은 각 방식의 9개 결과가 최초 결과와 문자열까지 일치했다.

아래 CER는 **세 방식에 공통**이다. NFKC·소문자화 뒤 문자/숫자만 비교하며, 숫자와 영문/한글 표기 차이도 오류에 포함된다.

| 자료·환경 | 참조 문자 | 힌트 없음 | 슬라이드 목록 | 무관 명칭 |
|---|---:|---:|---:|---:|
| 강연 원본 2편 | 1,222 | 16.86% | 16.94% | 17.27% |
| 강연 사무실 혼합 | 1,222 | 17.51% | 17.51% | 16.86% |
| 강연 식당 혼합 | 1,222 | 17.35% | 17.18% | 17.43% |
| 인터뷰 원본 3명 | 555 | 10.27% | 10.27% | 10.27% |
| 인터뷰 식당 혼합 1명 | 287 | 13.94% | 14.63% | 13.94% |

일반 인터뷰 원본의 삭제/삽입은 힌트 없음 17/13자, 슬라이드 목록 17/14자, 무관 명칭 17/13자이며 세 방식에서 같다. 식당 인터뷰도 각 조건의 삭제/삽입이 그대로였다. 발화 안의 일반 문장 누락·잘못된 추가를 줄였다는 근거는 얻지 못했다. 편집 정렬의 삭제·삽입 수를 의미 누락·환각 문장 수로 환산하지 않는다.

### SIL 원음: 출력과 용어 복사

| 세 SIL 구간의 정규화 출력 문자 수 합계 | 힌트 없음 | 슬라이드 목록 | 무관 명칭 |
|---|---:|---:|---:|
| `off` | 18 | 49 | 39 |
| `gate` | 0 | 0 | 0 |
| `trim` | 0 | 0 | 0 |

`off`에서는 두 SIL 구간의 무관 조건에서 입력한 `다익스트라, 자그로스산맥, 세풀베다`를 그대로 출력했다. 다른 SIL의 관련 조건에서는 `Nginx, MariaDB, PHP, WSL2, Chmod, Chown`을 출력했다. **VAD가 빈 목록인 경우 모델 호출을 생략해 이 출력이 차단됐고 역순에서도 재현됐다.**

빈 참조의 완전성·배경 소리 해석에는 한계가 있다. 빈 참조 대비 모든 출력을 사람이 청취로 확정한 환각이라고 부르지 않는다. 이번 차단 결과만으로 발화가 있는 구간에서의 용어 삽입·소음 환각이 해결됐다고 해석하지 않는다.

## 제품 적용과 복구 동작

1. 최초 확정 전사 뒤 성공한 VAD 결과를 요청에 보존한다. **기존 스냅샷을 재사용하므로 자동 후보에서 VAD를 한 번 더 실행하지 않는다.**
2. Qwen 자동 후보이고 그 목록이 명시적으로 `[]`일 때만 추론을 보류한다. 이전 요청에 필드가 없거나 `None`, 검사 불가·실패이면 기존 Qwen 경로를 유지한다.
3. 화면에 **자동 재인식 보류 / 발화 미검출 · 원음 확인 필요**를 표시한다. 추론을 완료한 것처럼 표시하지 않는다.
4. 원음 재생·수동 입력을 유지하고 **원음 다시 인식** 버튼으로 수동 Qwen 후보를 요청할 수 있다. 수동 요청은 VAD로 차단하지 않는다. 같은 구간의 활성 요청이 있으면 중복 제출을 막는다.
5. 원문·과거 출처를 바꾸지 않고 자동 재처리는 기존 최대 1회 정책을 유지한다. 사용자가 후보를 적용해야 새 전사가 저장된다.

그릴링에서 이 자동/수동 정책을 합의했다. UI UX Pro Max의 오류 설명·복구 경로 기준을 적용했고, ponytail 기준으로 기존 VAD 스냅샷·후보 작업·재시도 API·원음 재생을 재사용했다. 새 서버·의존성·스키마·모델 설정은 추가하지 않았다.

## 통합 검증과 처리 시간

별도 로컬 QA DB에 같은 SIL 원음 3개를 PCM 패킷으로 넣고 제품 함수를 호출했다. 최초 빈 전사는 시험 fixture로 저장했으며 최초 Whisper 인식의 검증이 아니다.

- 실제 native VAD → 자동 후보 보류 → 자동 두 번째 요청 차단을 확인했다.
- 각 보류 뒤 수동 요청이 **실제 설치된 Qwen worker**를 실행했다(주 비교와 별도 3회). 전사 내용은 적용하지 않았으며 기존 전사·원음 해시가 유지됐다.
- 단위 검사는 없는/실패한 VAD 결과의 비차단, 수동 우회, 중복 검사 방지, 원문·과거 연결 보존을 다룬다.
- UI 검사는 SSR 렌더링·버튼 활성/비활성·원음 접근성 이름·TypeScript·빌드다. 실제 설치 앱에서 새 버튼 클릭·키보드·미저장 편집을 재검증한 것은 아니다.

주 비교용 VAD 34개 조각의 사전 검사 합계는 **3.111초**였다. 추론 시간에는 이 사전 검사와 모델 1회 로딩이 포함되지 않으므로 공개 집계에 별도로 보존했다. 주 비교에서 Qwen 호출은 방식별 102→93→93회였다. 세 VAD 보류 파일의 9개 용어 조건에서 줄어든 호출 수이며 일반 사용의 속도 향상률이 아니다. 모델 호출은 순차 실행했지만 전체 Mac 부하·실행 시점은 통제하지 않아 속도 우열을 주장하지 않는다.

## 재현과 증거

각 방식은 같은 manifest와 `split_pcm()`의 30초 이하 조각을 사용한다. 앱 Python 환경에서 기존 `speech_activity()`로 해당 조각의 활동 목록을 고정한 뒤 Qwen 환경에 전달한다. 스냅샷은 manifest 해시·각 조각 해시/프레임·검출기·검사 시간을 포함하며 다른 원음이나 검사 불가 결과는 거절한다.

```sh
<QWEN_PYTHON> experiments/compare_asr_hints.py \
  --engine qwen --manifest <MANIFEST.json> --runtime <RUNTIME> \
  --qwen-vad gate --vad-activity <ACTIVITY.json> --output <FRESH_OUTPUT.json>
```

무적용은 VAD 인자를 생략하고, 잘라내기는 `--qwen-vad trim`을 사용한다. 역순은 해당 하위 manifest·활동 목록에 `--reverse-order`를 추가한다. 원음·자막·모델·raw 결과는 재배포하지 않으며 공개 파일에는 본문·로컬 경로를 넣지 않았다.

[집계·입력/실행 해시·프레임 범위·검출 시각](verification/qwen-vad-20261020.json)을 제공한다. 원본 출처 15개·입력 WAV 13개를 전후 SHA256으로 대조했다. 실제 설치 앱은 0.3.24/build34이며 이번 작업에서 교체·재서명·종료하지 않았다. 제품 변경은 소스와 main에 반영하는 범위다.

### 검증 범위의 한계

짧은 말·작은 목소리가 자연스럽게 VAD에서 빠지는 표본은 이번에 확보하지 못했다. 모든 원본 발화 조각에서 검출됐다는 결과를 VAD 누락률 0으로 일반화하지 않는다. 대학 강의 전체·현장 다화자 겹침 발화·장시간 마이크·절전·필기 복구 검증도 이번 비교에 포함하지 않는다.

## 회귀 검사

- VAD gate·여백·마지막 PCM 반올림 경계의 RED→GREEN, 실제 발화 전달·빈 참조·토큰 상한 기록 검사 포함 실험기 집중 **11/11 통과**.
- 자동 보류·수동 재인식·원문/과거 출처 보존을 포함한 관련 Python 검사 **51/51 통과**.
- 전체 Python **637개 중 632개 통과·선택 검사 5개 생략**, 실패 0. 생략은 임베딩/Gemma 모델 계약 2개·별도 native fixture 3개다. 최초 샌드박스 실행에서 기존 loopback bind 시험 2개가 권한 오류로 실패했으며, 권한을 갖춘 환경에서 전체 검사를 다시 실행해 통과했다.
- UI 새 보류 표시·수동 버튼 검사 RED→GREEN. 프런트엔드 **104/104 통과**, TypeScript·Vite 빌드 통과.
- 별도 제품 함수 검증의 저장 PCM 3개가 원본 payload와 일치했다. 실제 보관함·앱 설치·서명은 바꾸지 않았다.
