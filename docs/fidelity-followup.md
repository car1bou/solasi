# 재전사 후보·무음 환각·요약 주어·가정

2026-10-15 · Apple M4 / 16GiB. 설계 검토는 grilling, 구현은 Ponytail로 진행했다. 기존 음성·모델만 재사용했고 새 다운로드·외부 AI API·원격 GPU를 사용하지 않았다. [본문 없는 집계·입력 해시](verification/fidelity-followup-20261015.json).

## 변경

- 기본 Whisper를 유지한다. 이미 잡힌 재전사 구간 또는 사용자가 **원음 다시 인식**을 누른 구간은, 검증한 Qwen3-ASR 환경이 설치된 Mac에서 Qwen 후보를 생성한다. 설치가 없으면 기존 Whisper VAD off 후보를 사용한다. 선택 엔진은 요청에 고정하며 Qwen 실행 실패 뒤 Whisper까지 연속 추론하지 않는다.
- 자동 재전사는 기존 최대1회·최초 전사 우선 정책을 유지한다. 원래 인식문과 사용자 수정은 보존하고, 후보 적용은 사용자가 한다. 문장 안의 모든 누락을 자동 감지하는 기능을 추가한 것은 아니다.
- PCM이 완전히 0인 원음은 Qwen 추론을 건너뛴다. 녹음 저장은 계속한다. 음성 활동이 감지되지 않았는데 후보 문장이 있으면 발화·소음·감지 누락을 확인하도록 표시한다. 특정 문구를 삭제하는 규칙은 없다.
- 요약의 명시적인 주체↔수신자 반전, 인물의 `앞/옆/뒤` 위치 표현이 행위자로 바뀌는 경우, 같은 대상의 `없다고 가정하면/있다면` 전제 반전을 보완한다. 서술 보어·소유 표현의 정상 의역을 잘못 거절하던 개발 중 반례도 회귀 검사로 남겼다.
- **확인용 발췌는 제목·주어·발언 성격을 중립적으로 표시한다.** 화면의 최종/원래/실패 구간 요약과 Markdown에 적용한다. 원래 모델의 응답·라벨은 metadata에 보존한다. 검사를 통과한 강의 가정·조건·예시와 회의 제안·결정·담당 구분은 유지한다.

## 같은 실제 사람 음성 90조건

이전과 같은 90개 음성 SHA256·정답·순서를 확인했다. 성인 인터뷰·일상 발화·낭독과 생활 소음 파생 조건이며 90명의 독립적인 화자가 아니다. 정답은 사후 점수 계산에만 사용했다. CER는 NFKC/소문자/문자·숫자로 정규화한 문자 편집률이다.

| 경로 | 편집/정답 글자 | CER | 치환 | 누락 | 삽입 |
|---|---:|---:|---:|---:|---:|
| 기본 Whisper large-v3-turbo |185/1829|10.11%|88|86|11|
| 제품 Qwen 재전사 subprocess |137/1829|7.49%|95|29|13|

Qwen 후보가 28조건에서 개선, 15조건에서 악화, 47조건에서 동률이었다. 누락 편집은 줄었지만 삽입은 늘었다. 삽입 편집 수는 의미적 환각률이 아니며, 기본 전사 정확도가 자동으로 바뀐 결과도 아니다.

- 후보 경로는 매 클립 새 프로세스의 정규화·파일 검증·모델 로드를 포함했다. 중앙값 2.01초, 90개 합계 188.56초였다. Whisper는 중앙값 2.14초·합계 216.36초였다. OS 파일 캐시는 남을 수 있고 대기열·사용자 검토 시간은 제외하므로 일반적인 속도 순위로 해석하지 않는다.
- 후보의 최고 MLX 할당은 약2.42GiB, 별도 프로세스 RSS 최고는 약1.68GiB였다. 두 값은 전체 앱·Mac 메모리와 다르며 더해서 사용량으로 계산하지 않는다.
- 90발화는 제품의 PCM 정규화 뒤 모두 비영점이었다. 마지막 디지털 무음 생략 분기는 이 발화 비교에 적용되지 않는다.

## 무음·생활 소음과 제품 경로

| 대조 입력 | 최초 Qwen 후보 | 보완 후 |
|---|---|---|
| 디지털 무음 1초 |문장 생성|추론 생략·빈 후보|
| 디지털 무음 6초 |문장 생성|추론 생략·빈 후보|
| 실제 사무실 소음 6초 |문장 생성|출력 보존·원음 확인|
| 실제 식당 소음 6초 |문장 생성|출력 보존·원음 확인|

환경 소음 자료에는 배경 말소리가 섞일 수 있고 완전한 내용 정답이 없어 두 소음 출력을 전부 환각이라고 판정하지 않았다. VAD가 발화를 놓칠 수도 있어 VAD 결과만으로 후보를 버리지 않는다.

같은 실제 사람 음성 두 구간을 **파일 연결→최초 Whisper→후보 예약→Qwen 후보→적용** 경로로 실행했다. 후보 생성은 각각 약2.54초·2.31초였고, 적용 전 전사 불변·적용 후 기존 ID의 새 버전·옛 출처 스냅샷 보존을 임시 DB에서 확인했다. 실제 Qwen worker의 RSS가 약1.21GiB일 때 취소를 전달했고, 약0.020초에 취소가 전파되며 소유한 FFmpeg/worker 프로세스가 회수됐다. 특정 GPU 연산 단계의 중단 시점을 측정한 결과는 아니다.

## 같은 긴 음성의 새 요약

기존 인터뷰179전사와 낭독292전사의 ID·본문·시각이 이전 시험과 같음을 확인했다. 같은 작성 메모와 로컬 `qwen3.5:4b`, context8192로 **새 native 추론부터** 실행했다. 긴 원음 전체를 다시 ASR한 비교는 아니다. 낭독 원음은878.304초이며 요약 cutoff는876.050초다.

| 자료 | 새 실행 | 호출 | 최종 항목/확인 발췌 | 직접 인용하지 않은 원문 단위 |
|---|---:|---:|---:|---:|
| 인터뷰666.33초 |244.77초|7|39/36|6|
| 낭독878.30초 |408.79초|9|60/39|53|

- 두 실행 모두 병합 선택의 누락 구간은0개다. 이는 중요 사건 전체의 의미 보존을 뜻하지 않는다. 직접 인용하지 않은 원문은 별도 목록으로 유지한다.
- 최종 제품 후처리를 각 새 native 응답에 다시 계산해 저장 결과와 일치함을 확인했다. 이 검산 시간은 위 native 생성 시간에 섞지 않았다.
- 실제 결과99항목을 프런트엔드 컴포넌트로 렌더링했다. 확인 발췌75항목의 미검증 제목·주어·상태는 숨겨지고, 본문99개는 그대로 유지됐다. 원래 모델 응답 metadata도 유지한다.
- **발췌 비율은 줄지 않았다.** 생성 단계의 인물 관계·서술 대상 오류와 원래 ASR 오탈자는 남는다. 이번 변경은 오류 확인·표시와 명시 반례의 보호를 보완한 것이며 자연스러운 긴 요약 품질 전체를 해결하지 않았다. 생성 시간 차이도 변경의 인과적 속도 개선으로 해석하지 않는다.

## 검사와 재현

백엔드334개·프런트엔드28개 검사, TypeScript, Vite빌드, Python구문, 설치 의존성, 변경 공백 검사를 통과했다. 추가 검사에는 모델 파일 변조·추가 로더 파일 거절, 잘린 PCM·토큰 상한 거절, offline 설정, 최대1회·실패 후 이중 추론 금지, 원문 보존, 주어·조건 반례와 표시 렌더링을 포함한다.

```sh
.venv/bin/python experiments/evaluate_sentence_asr.py whisper --output /private/tmp/asr-whisper.json
.venv/bin/python experiments/evaluate_sentence_asr.py qwen-review --output /private/tmp/asr-qwen-candidate.json
.venv/bin/python experiments/validate_recording_assistance.py <LOCAL_INTERVIEW_FIXTURE> qwen3.5:4b --kinds summary --cutoff-ms 666330 --context-limit 8192 --output /private/tmp/interview-summary.json
.venv/bin/python experiments/validate_recording_assistance.py <LOCAL_NARRATION_FIXTURE> qwen3.5:4b --kinds summary --cutoff-ms 876050 --context-limit 8192 --output /private/tmp/narration-summary.json
```

재현에는 기존 로컬 음성 manifest·fixture DB·엔진·모델이 필요하며 상세 결과에는 전사 본문이 있으므로 커밋하지 않는다. 공개 집계에는 본문·원음·모델 응답·인증 정보를 포함하지 않았다.

Qwen 후보는 현재 **기존 비교 환경을 재사용하는 선택 경로**다. 자동 설치 화면은 없다. `.local-state/runtime/qwen-eval-venv`의 고정 의존성은 [lock](../experiments/qwen-requirements.lock), 모델은 [MLX community 배포](https://huggingface.co/mlx-community/Qwen3-ASR-1.7B-4bit)의 revision `78a389c776a5483b2d0d4ea5494e11012e0d6159`다. [worker](../lecture_study/qwen_asr.py)는 소비 파일9개의 크기·SHA256과 예상 밖 로더 파일을 확인하고, offline·Korean·temperature0·최대1024토큰으로 실행한다. 준비된 Qwen 실행이 실패하면 해당 후보를 실패로 남긴다.

문장 내부 누락의 완전한 자동 감지, Qwen의 단어·문장 정렬, 한국어 의미 함의 전체 검증은 남아 있다. 이번에는 실제 마이크·절전 복귀·30–60분 브라우저 녹음·Windows·깨끗한 Mac 설치를 재검증하지 않았다. 이전 브라우저 결과는 [이전 기록](sentence-fidelity.md)에서 구분해 확인한다.
