# 손글씨 지식 편입·자동 색인 검증

확인일: 2026-10-19. Mac Preview 구현·검증 기록. 이 파일은 제품 사용 가이드가 아니라 측정 근거다.

## 공개 실제 손글씨 비교

출처: https://github.com/jkf87/korean-handwriting-ocr-benchmark

고정 커밋: `3a81a6f4b57ea91602a5f7740337a438431b8230`. 공개 수동 정답·손글씨 7장과 인쇄 대조군 1장을 로컬에서 비교했다. 별도 데이터 라이선스 파일이 확인되지 않아 이미지·정답 원문은 앱이나 Git에 포함하지 않는다. 파일 출처·크기·SHA256 manifest는 `.local-state/handwriting-20261019/public-korean-manifest.json`에 있다.

측정: 공개 정답과 페이지 전체 출력을 NFC 정규화하고 공백을 제거한 문자 편집 거리/CER. 머리글·쪽 번호·비선형 배치도 입력에 포함하며 정답을 이 실험에 맞춰 임의 보정하지 않았다. 교과목 전문 필기·수식·벡터 획의 대표 벤치마크로 일반화할 수 없다. 연구소의 기존 성능 수치를 재사용하지 않고 실제 로컬 출력을 측정했다.

| 로컬 엔진 | 실제 손글씨 7장 가중 CER | 처리 시간 중앙값 | 표본별 CER 범위 |
|---|---:|---:|---:|
| Apple Vision accurate revision 3 | 16.00% | 0.685초 | 3.57–47.78% |
| 설치된 Qwen3.5 4B | 9.90% | 55.060초 | 1.51–36.65% |

CER는 낮을수록 좋다. Vision 첫 페이지의 초기 준비 시간은 15.20초였으며 위 중앙값으로 첫 실행 지연을 가리지 않는다. Qwen은 각 요청에 모델을 준비하고 추론·종료하는 실제 경로의 시간이다. 회귀 검사·빌드도 같은 Mac에서 수행 중이었으므로 전용 장비에서의 격리 성능 수치가 아니다.

인쇄 대조군 CER는 Vision 0.32%, Qwen 5.06%였다. Qwen도 항상 더 정확하지 않았고 거친 필기는 두 엔진 모두 오류가 컸다. 자동 후보는 가벼운 Vision을 사용하고, 사용자가 로컬 Qwen 재인식을 선택할 수 있다. 어떤 엔진의 결과도 확인 전에는 검색·답변·요약 근거로 편입하지 않는다.

재현 스크립트: `experiments/compare_handwriting.py`. 실제 저장 획의 helper 렌더링과 사진 이미지의 인식은 다른 입력 조건으로 구분한다. 현재 사진 비교는 수식·도형의 의미 해석 정확도를 증명하지 않는다.

## 구현된 보존·처리 기준

- 승인한 `ink_note`만 검색한다. 후보·거절·stale는 제외한다.
- 획이 A→B→A로 돌아와도 새 후보를 만들며 이전 승인 출처는 보존한다.
- 같은 자료가 여러 과목에 연결되어도 작업·개념 후보·승인을 과목별로 분리한다.
- 같은 과목의 검색 대상이 바뀌면 기존 관련 기록도 갱신한다. 거절한 개념은 같은 원문에서 되살리지 않는다.
- 증분 벡터는 완성된 chunk 단위로 저장한다. 새 모델·전처리의 색인은 완성 후 활성화하고 중간 재개를 지원한다.
- 자동 작업은 녹음·전사·사용자 요청과 충돌할 때 새 호출을 시작하지 않고 대기로 돌아간다. 외부 API를 자동 호출하지 않는다.
- Exa 신규 검색과 키 설정은 제거했다. 과거 웹 인용은 읽을 수 있다.

## 실행 결과와 남은 확인

- Python 전체 검사: 571개 중 566개 통과, 선택 검사 5개 생략. 프런트엔드 검사 98개 통과, TypeScript/Vite 빌드 성공.
- 별도 Mac 검증 앱에서 과목·PDF 원본·기존 필기·인식 검토 패널을 열고 Vision 인식을 실행했다. 시험 획은 글자가 아닌 선이므로 빈 인식문이 나왔고, 사용자가 확인하는 절차로 `검증용 선`을 입력·승인하여 출처로 저장했다. 이는 승인 UI 검증이며 실제 손글씨 정확도 수치에 포함하지 않는다.
- OCR 영역이 없는 수동 확인 출처도 원래 필기를 표시하도록 수정하고, 빈 필기의 로컬 Qwen 경로가 모델 준비 전 변수를 참조하던 오류를 회귀 검사로 수정했다.
- 실제 화면에서 관련 기록 API의 누락된 함수 import를 발견해 수정했다. 기록·과목 페이지 양쪽의 API 회귀 검사를 추가했고, 수정한 번들에서도 해당 API 응답을 확인했다.
- 최종 번들 IPC 시험(`experiments/validate_knowledge_pipe.py`): 자동 인식 후보 → 승인 → 검색 근거 연결, 관련 기록 API, 녹음 중 자동 처리 양보, 한국어 실제 음성 17.52초 전사와 요약 완료. PCM 280,320프레임이 원본과 일치했다. 이후 8,000프레임 저장 중 검증 엔진을 강제 종료·재시작하여 중단 상태·WAV 해시·메모·획·승인 출처 보존을 확인했다. 전체 경과 76.44초는 이 여러 작업과 초기화·복구를 포함하며 전사 속도 수치가 아니다.
- 이 시험은 별도 복사본에서 파일 PCM을 입력한 시험이다. 새 물리 마이크의 장시간 녹음·실제 Mac 절전, 현재 사용 중인 설치 앱 교체·680×480 두 테마 확인은 별도 완료 증거가 필요하다. 공개 이미지의 정확도, 벡터 시험 획의 승인 흐름, 실제 음성 재생 시험을 서로 구분한다.
