# 한국어 전사 재검증

2026-10-17 · Apple M4 / 16GiB / macOS arm64. [본문 없는 집계·출처·해시](verification/korean-asr-20261017.json).

**기본 Whisper large-v3-turbo를 유지한다.** 종료 후 전사가 기본이고 실시간은 선택 기능이다. 준비된 Qwen은 기존 최대1회 자동 재인식 후보로 사용하며 적용은 사용자가 한다. 준비되지 않으면 기존 Whisper VAD off 후보를 사용한다. Qwen 실패 뒤 두 번째 엔진을 연속 실행하지 않는다. 이번 비교로 기본 설정·자동 후보 범위·원문을 바꾸지 않았다.

## 설정과 점수

현재 제품과 같은 해시의 Whisper.cpp1.9.5·FFmpeg9.0.2·Silero6.2.0을 사용했다. 종료 후 처리 기준으로 한국어·VAD 최소250ms·여백1000ms·힌트 없음, mono PCM16 16kHz 정규화 뒤 제품 `transcribe_range`를 호출했다. 짧은 파일의 직접 디코더 검사이며 전체 네이티브 앱의 녹음·작업 예약 경로를 대신하지 않는다.

CER는 NFKC·소문자·유니코드 문자/숫자만 남긴 문자 편집률이다. **S/D/I는 대치/삭제/삽입 문자 수**이며 의미적 누락·환각의 발생률이 아니다. 숫자 표기와 괄호 로마자 차이도 센다. 정답은 점수 계산에만 사용했다.

## 실제 내장 Qwen 후보24개

Whisper 결과에서 취약18개와 같은 조건의 정답 일치 대조6개를 고른 뒤, Qwen 결과를 보기 전에 목록·SHA·정답을 고정했다. 대조는 같은 조건에서 길이를 가깝게 고른 다른 발화이며 완전히 같은 문장의 대응 비교는 아니다.

설치 앱의 실제 frozen `qwen-worker`를 실행했다. 기존 Python 평가 환경을 사용하지 않았다. 모델은 Qwen3-ASR1.7B MLX4bit, 한국어·temperature0·batch1·최대1024토큰·offline이다. 입력 정규화·모델 파일·결과 형식 검증을 유지했다.

| 선택 묶음 | Whisper 편집/정답 문자 · S/D/I | Qwen 편집/정답 문자 · S/D/I |
|---|---:|---:|
| 취약18 |125/521 · 25/92/8|79/521 · 31/43/5|
| 정답 일치 대조6 |0/141 · 0/0/0|4/141 · 1/1/2|

총9개 개선·5개 악화·10개 동률이었다. 대조6개 중2개가 악화했고 초단문3개는 정답을 회복하지 못했다. 삭제 감소만으로 자동 채택하지 않는다. 오류를 본 뒤 고른24개이므로 전체155나 신규55의 모델 우열로 일반화하지 않는다.

## 초단문과 무음·환경 소음

동일한0.195~0.210초 맞장구3개의250ms 결과를 재사용하고, 100ms/off만 추가 인식했다. 여백1000ms·힌트 없음은 유지했다.

| 설정 | 정답4자의 S/D/I | 빈 출력 |
|---|---:|---:|
| VAD250 |0/4/0|3/3|
| VAD100 |2/2/7|2/3|
| VAD off |4/0/23|0/3|

100ms/off는 삭제가 줄어도 정답 회복 대신 대치·삽입이 늘었다. Qwen도 이3개에서 S3/D1로 바뀌었고 정답 일치는0개였다.

디지털 무음1/6초와 실제 사무실/식당6초 대조는250/100에서 모두 빈 출력이었다. off는 디지털 무음에 각각9자, 사무실·식당에 각각5자를 출력했다. 대조에는 CER를 계산하지 않았다. 디지털 무음은 거짓 음성 위험의 증거지만 제품은 완전0 PCM의 추론을 생략한다. 환경 음원에는 실제 배경 말소리가 있을 수 있어 그 출력을 전부 환각으로 판정하지 않는다.

## 출처·보존·한계

- [FLEURS](https://huggingface.co/datasets/google/fleurs)는 CC BY4.0, [서울코퍼스](https://www.openslr.org/113/)는 CC BY-NC2.0이다. [DEMAND](https://zenodo.org/records/1227121)는 기록과 제작자 조건의 표기가 달라 제작자의 CC BY-SA3.0을 보수적으로 적용한 기존 개인 시험 조건을 유지했다.
- [Pansori](https://github.com/yc9701/pansori-tedxkr-corpus)·[Deeply](https://github.com/deeplyinc/Korean-Read-Speech-Corpus)는 CC BY-NC-ND4.0 원본을 개인 비상업 로컬 비교에 사용했다. [KMSAV](https://github.com/etri/kmsav)의 주석·원본 매체 조건은 별도로 기록했다. revision과 제한은 집계에 있다. 이번 평가의 음원·정답·인식문 파일은 Git·앱에 동봉하지 않았다.
- 입력·manifest·모델·실행 파일의 해시는 전후 같았다. 비공개 결과는0600, 폴더는0700이다. 새 모델 다운로드·외부 전사 API 호출은 없었다.
- 실행은155+대조275.488초, Qwen24는57.364초, 추가 VAD14회16.871초, 신규55는98.343초였다. 클립별 로드·검증·캐시·공유 Mac 부하가 섞인 시간으로 모델 지연 우열이나 실시간 성능을 보장하지 않는다.
- **전체 다화자 대화·겹침 발화의 완전한 정답과 전체 CER는 확인하지 않았다.** 문장 내부 누락의 완전한 자동 감지·단어 시각 정렬·의미적 환각률도 미검증이다. 이번 검사를 장시간 마이크 저장·절전 복구 검사의 대체로 쓰지 않는다.
