# 로컬 소음 제거·앞구절 누락 비교

2026-10-21 · Apple M4 / 16GB / macOS 27.0.1

## 적용 판정

**검증한 설정 모두 기본 전사 입력에 적용하지 않았다.** 소음 속 일부 발화에서 좋아진 결과도 있었지만 일반 발화·저음량·SIL의 개별 회귀나 처리 실패가 남았다. 문장 앞부분 누락과 소음 속 오인식이 해결됐다고 보고하지 않는다.

실험 도구의 시간축·가중치 순서·완료 판정은 수정했다. 이 도구 수정과 제품의 전사 품질 개선을 구분하며, 실제 제품 엔진·설치 앱은 변경하지 않았다.

## 적용 기준

일반 발화·저음량 발화·SIL의 개별 결과를 보존하면서 소음 속 발화 또는 앞구절 누락을 개선하는지를 확인한다. 평균 CER가 낮아져도 개별 일반 발화의 오류·삭제가 늘면 기본 경로에 적용하지 않는다. 인식문이 짧아진 것만으로 잡음 제거 성공으로 판단하지 않는다.

원음·기존 전사·사용자 적용 정책은 유지한다. 자동 후보는 유효한 VAD 결과가 빈 목록일 때만 보류하고, 수동 재인식은 원음 전체를 사용한다. 이번 비교에는 외부 API와 HTTP 모델 서버를 사용하지 않았다.

## 고정 음성

[서울코퍼스](https://www.openslr.org/113/)의 성인 인터뷰 3명·수동 전사 6개를 이전 진단과 동일하게 사용한다. 각 화자의 최저·중앙 RMS 발화이며, 같은 발화를 반복한 57개 조건을 독립 발화 57개로 계산하지 않는다. [DEMAND](https://zenodo.org/records/1227121)의 사무실·식당·주방 원음을 혼합한 파생 조건을 포함한다.

| 조건 | 수 |
|---|---:|
| 실제 사람 발화 원본 | 6 |
| 같은 원본 −20dB | 6 |
| 3환경 × 0/−10dB 혼합 | 36 |
| 목표 한국어 발화 없는 환경음 | 6 |
| 수동 SIL 주석 원음 | 3 |

총 166.348초이며 반복 전 6개 참조의 합계는 106자, 조건별 반복 참조는 848자다. 혼합 시 원본 녹음 성분의 RMS를 −40dBFS로 맞췄다. SNR은 기존 배경음도 포함된 녹음 성분 대 추가 환경음의 비율이다. 낮은 녹음 레벨을 확인했으며 실제 속삭임이나 발성 크기를 확인한 자료는 아니다. 자료 구성·원본 해시는 [앞선 VAD 진단](quiet-korean-vad-20261021.md)을 따른다.

기존 로컬 보관 자료의 별도 확인에는 [Google FLEURS](https://huggingface.co/datasets/google/fleurs)의 한국어 낭독 10개·113.58초·441자를 고정했다. 서울코퍼스 표본과 음성 해시·정규화 참조가 겹치지 않는다. 같은 파일을 PCM16/16kHz로 변환한 후 무처리와 필터 조건에 공통으로 사용했다. 화자 ID를 확보하지 않아 10명이 발화했다고 주장하지 않는다.

서울코퍼스 CC BY-NC 2.0, DEMAND CC BY-SA 3.0, FLEURS CC BY 4.0 출처를 유지한다. 공개 저장소에는 원음·참조 전사·모델 파일을 포함하지 않는다.

## 비교 경로

| 경로 | 고정 설정 |
|---|---|
| 무처리 | 동일 PCM16/16kHz 원음 |
| 대역 필터 | highpass 80Hz → lowpass 7600Hz |
| FFT 소음 제거 | FFmpeg afftdn, nr=12 / nf=−50 / tn=1, 아래의 25ms 지연 보정 |
| DeepFilterNet3 | 16→48kHz resample_poly → MLX enhance_array → 16kHz |
| 레벨 보정 DeepFilterNet3 | 입력 RMS −20dBFS 목표, 최대 +40dB·peak 0.95 제한, 처리 후 동일 배율의 역수 적용 |

레벨 보정은 첫 조건을 조사한 뒤 추가한 탐색 조건이며 독립 확인 결과로 취급하지 않는다. 최종 음량을 높여 결과를 유리하게 만드는 대신 처리 후 원래 음량 기준으로 되돌렸다. DeepFilterNet 변환에서 NaN·무한대·PCM 범위 초과·길이 변경은 거절한다. 대역 필터의 한 원본 조건은 PCM 레일값 샘플이 6→9개로 늘어, 기존과 같은 파형이라고 간주하지 않는다.

[FFmpeg afftdn](https://ffmpeg.org/ffmpeg-filters.html#afftdn)은 설치된 실행 파일을 사용한다. DeepFilterNet은 [MLX community 배포](https://huggingface.co/mlx-community/DeepFilterNet-mlx)의 `220d5dfb7266352272d74c2a7d2025c59e07b391/v3`를 고정했다. 구성·가중치 합계 8,683,568바이트의 SHA256을 검증했다. 배포 카드 MIT와 [원본 프로젝트](https://github.com/Rikorose/DeepFilterNet)의 MIT/Apache-2.0 고지를 구분한다. 이 MLX 변환본의 관찰을 모든 DeepFilterNet 구현의 성능으로 일반화하지 않는다. 체크포인트의 GRU bias 수식과 실제 파라미터를 대조하며 원본 PyTorch 전체 추론 출력과의 수치 동등성은 검증하지 않는다.

Whisper large-v3-turbo는 앱의 `transcribe_range`와 기본 내부 VAD 설정으로 실행했다. Qwen3-ASR 1.7B 4bit는 전체 입력·Korean·temperature=0·max_tokens=1024·용어 없음으로 실행했다. **Qwen의 SIL 출력은 자동 후보의 VAD 차단 후 결과가 아니다.** 수동 전체 원음 경로와 같은 입력 조건을 조사하고, 전처리별 VAD 결과는 따로 비교했다.

각 엔진에서 모델 실행을 순차 처리했다. Qwen은 비교 묶음 안에서 모델을 재사용하고, Whisper는 호출마다 native 프로세스를 실행한다. 기록한 시간은 진단용이며 두 엔진의 로딩 포함 범위·환경이 달라 단순 속도 순위를 매기지 않는다. 변환 시간은 모델 최초 준비 시간을 제외한다.

## 비교 도구의 수정

### FFT 지연과 꼬리 보존

처음 사용한 afftdn은 파일의 프레임 수가 같아도 실제 파형을 400샘플(25ms) 늦췄다. 6개 실제 원본에서 같은 지연을 확인했다. 수정본은 400샘플을 뒤에 붙여 내부 버퍼를 비운 다음 `[400, N+400)`을 선택하고 시각을 다시 맞춘다. 임의의 상관 분석 결과로 음성 길이를 늘리거나 줄이지 않는다.

1·199·1,601·32,000프레임의 합성 신호에서 처음·마지막 부근의 peak 위치와 전체 프레임 수를 확인했다. 실제 원본 6개에서도 보정 후 상관 peak 지연이 0이었다. 보정 전 실측은 보존하되 수정본의 정확도 결과로 섞지 않는다.

### DeepFilterNet 가중치 순서와 초기화

초기 실험 도구는 factory가 이미 읽은 가중치를 다시 적용했다. 또한 설치된 라이브러리의 변환기는 `set` 순서로 값을 대입하고, 후처리가 MLX의 dict에 저장된 하위 GRU를 방문하지 못했다. 이에 따라 처음 한 번만 읽어도 실행마다 recurrent bias 합산이 빠질 수 있었으며, 두 번 읽으면 중복 합산될 수도 있었다. 실제 GPU에서 두 동작을 확인했다. factory 결과 자체를 올바른 비교 기준으로 삼지 않는다.

수정 도구는 기존 이름 매핑을 재사용하되 전체 체크포인트·모델 파라미터 대응을 검증하고, 원래 이름을 정렬해 `bias_hh` 다음 `bias_ih` 순서로 각각 한 번 대입한다. 모든 대입 성공을 확인한 뒤 읽힌 필터뱅크로 wrapper를 구성한다. 설치된 라이브러리나 제품 엔진을 수정한 것은 아니다.

체크포인트 기준은 다음과 같다.

```text
b   = concat(bias_ih[:2H] + bias_hh[:2H], bias_ih[2H:])
bhn = bias_hh[2H:]
Wx  = weight_ih
Wh  = weight_hh
```

실제 파라미터 118개·GRU bias 5개의 수식 일치와 필터뱅크 참조를 확인했다. `PYTHONHASHSEED=1/29`의 새 프로세스에서 모든 파라미터 해시와 저음량·SIL 시험 파일 2개의 처리 결과 해시가 일치했다. 중복 로딩과 정렬되지 않은 단일 로딩 결과는 모두 보존하되 품질 판정에서 제외한다. 결과표에는 이 검사를 통과한 정렬 로딩의 새 실행만 사용한다.

### 중단·완료와 영점 무음

준비가 중단된 `completed:false` 입력은 인식·후속 전처리 전에 거절한다. 일부 파일만 성공한 집합을 완료한 전체 비교로 처리하지 않는다. 기존 manifest에 이 필드가 없으면 그대로 지원한다. `--conditions none`은 동일한 무용어 조건을 세 번 실행하지 않도록 하며 기본 용어 비교 3종은 유지한다.

전처리가 정확한 디지털 영점 PCM을 만들었을 때는 기존 앱과 같이 추론을 생략한다. 사람이 SIL로 주석한 비영점 원음을 임의로 영점 처리하지 않는다. 토큰 상한에 도달한 행은 실패로 보존하며, 실패가 있는 그룹의 전체 CER를 계산하지 않는다.

## 측정 정의

참조·출력은 NFKC·소문자·문자와 숫자 보존으로 정규화하고, 공백·문장부호를 제외해 문자 편집 거리를 센다. 삭제·삽입·치환을 별도로 기록한다. 숫자의 문자/숫자 표기나 괄호 영문을 음성적으로 동치 처리하지 않는다. FLEURS의 제공 참조에는 `Gibson` 같은 영문 병기도 있어 절대 CER를 실제 발음 오류 비율로 해석하지 않는다. 낭독 대조에서 확인한 1개 편집 거리 증가에는 이 공통 영문 병기 삭제 외의 추가 치환이 있었다. 같은 최소 거리의 정렬에는 모호성이 있을 수 있으므로 삭제 수를 단어 신뢰도나 오류 확률로 표시하지 않는다.

SIL은 CER 분모가 없으므로 출력 문자 수와 출력한 조건 수를 기록한다. 환경음 단독 조건에는 배경 발화가 있을 수 있어 출력 전체를 의미 환각으로 확정하지 않는다. 목표 한국어 발화가 없는 대조 조건에서 출력이 늘었는지는 별도로 기록한다.

### 앞구절 누락 사례

기존 별도 VAD 검사에서 1.950~2.569초만 검출됐던 저음량 구간을 같은 원음으로 대조했다. 참조 14자에 대한 편집 거리/삭제 수다. 표가 특정 발음의 정확한 단어별 시각을 뜻하지는 않는다.

|---|---:|---:|
| 무처리 | 1/1 | 7/6 |

한 사례의 앞구절이 좋아져도 다른 일반·저음량 조건의 삭제가 늘어나는 설정은 채택하지 않는다. 원문을 언어 지식으로 채우거나 여러 결과 중 정답과 가까운 쪽을 자동 선택하지 않았다.

### 별도 낭독 10개

Qwen 무처리→대역 필터의 편집 거리 합계는 19→19였다. 1개 개선·8개 동일·1개 악화했다. 서울코퍼스 원본·저음량·SIL에서는 같은 인식문이 나왔더라도 별도 표본의 개별 회귀 때문에 기본 적용 조건을 통과하지 못했다.
Whisper 무처리→레벨 보정 DF3의 편집 거리 합계는 14→17였다. 0개 개선·8개 동일·2개 악화했다. 주 비교의 저음량 오류 18→12·앞구절 사례 7→1은 유망했지만 소음 조건의 UTF-8 출력 실패와 별도 일반 발화 회귀가 남아 적용하지 않았다. 이 확인에서도 같은 고정 10개 낭독을 사용했다.

발화 검출 수와 실제 단어 보존은 같은 지표가 아니다. 대역 필터는 기존에 놓친 조건 하나를 찾는 동시에 원래 검출하던 다른 조건 하나를 놓쳤다. 추가 검출에서 나온 후보의 오류·출력 증가도 함께 확인했으며, 전처리된 VAD 결과로 제품의 자동 보류 조건을 바꾸지 않았다.


## 실행과 회귀 검사

새 도구는 제품 실행 경로와 분리된 실험용이다. 기존 Python 환경의 NumPy·SciPy·MLX·mlx-audio를 사용하며 앱의 필수 의존성을 추가하지 않는다. PCM16·mono·16kHz 원음과 고정 manifest를 준비하고, 결과 파일은 아직 없는 경로로 지정한다. 원래 파일에 덮어쓰지 않는다.

```sh
.venv/bin/python experiments/compare_audio_preprocessing.py \
  --manifest /absolute/path/to/fixed-manifest.json \
  --runtime /absolute/path/to/prepared-runtime \
  --method afftdn \
  --output /absolute/path/to/new-filtered-manifest.json

.venv/bin/python experiments/compare_asr_hints.py \
  --engine whisper \
  --manifest /absolute/path/to/new-filtered-manifest.json \
  --runtime /absolute/path/to/prepared-runtime \
  --conditions none \
  --output /absolute/path/to/new-comparison.json
```

`bandpass`도 같은 방식으로 실행한다. `dfnet3`는 고정한 로컬 `config.json`과 `model.safetensors` 폴더를 `--model-folder`로 추가한다. 모델을 자동 다운로드하거나 서버를 띄우지 않는다. 원본 manifest에는 `id`, `path`, `sha256`, `group`, `reference`가 필요하다. 원음 무처리를 평가할 때는 평가기의 `category`, 빈 `hint_terms`·`distractor_terms`, `hint_provenance`도 준비한다. 참조 전사는 평가용이며 모델 입력으로 제공하지 않는다.

레벨 보정은 공개 도구의 별도 기본 옵션으로 추가하지 않았다. 이번 탐색 조건의 정확한 변환은 48kHz 입력 `x`에 대해 다음과 같으며 나머지 리샘플링은 같은 도구를 사용했다.

```python
gain = max(1, min(100, 0.1 / rms(x), 0.95 / peak(x))) if peak(x) else 1
clean = model.enhance_array(x * gain) / gain
```
