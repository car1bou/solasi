## 전사 변경과 같은 음성 비교

종료 후 확정 전사·파일 전사의 VAD padding을 **200→1000ms**로 늘렸다. 최소 발화 250ms는 유지한다. 짧고 약한 발화 앞뒤의 문맥이 잘리지 않도록 한 변경이다. 실시간 확정은 기존 200ms를 유지한다.

| 같은 84클립·정답 1,726자 | 이전 padding 200ms | 새 padding 1000ms |
|---|---:|---:|
| 문자 편집 오류 | 209 | **172** |
| CER | 12.109% | **9.965%** |
| 클립별 변화 | — | 개선10 / 동일74 / 악화0 |

성인 자발화·일상 발화·낭독·낮은 음량·방 울림·실제 사무실/카페/교통 소음 파생 혼합을 포함한 고정 표본이다. 모든 입력 SHA·정답·순서가 같다. 모집단 정확도나 모델 순위로 일반화하지 않는다. 예를 들어 생활비 설명은 9→0오류, 부모님이 말을 들어준다는 발화는 6→0오류로 줄었지만 문장 앞부분의 부분 누락은 남았다.

- 84개 비교 집계 (로컬 검증 자료·공개본 미포함) · 새 집계·로컬 원시 경로 (로컬 검증 자료·공개본 미포함) · 이전 결과 (로컬 검증 자료·공개본 미포함)
- 1초·6초 digital zero와 6초 사무실/카페 환경 소음에서 ASR은 모두 빈 결과였다. 후자의 실제 소음에 사람 소리가 전혀 없다고 단정하지 않는다.
- 100ms 최소 발화+temperature fallback 제거는 약한 발화 일부를 복구했지만 소음에서 `이녀석은`을 만들었다. 이 설정은 채택하지 않았다. 실패 실험 (로컬 검증 자료·공개본 미포함)

### 추가한 실제 두 사람 한국어 인터뷰

[ETRI KMSAV](https://github.com/etri/kmsav/tree/8a96a7d147eccfc8236ae78f42d32f681f5a46e2)의 두 사람 인터뷰 원본을 추가했다. 합성 대화나 발화 이어 붙이기가 아니다. 편집·음악이 있는 공개 인터뷰이며 현장 회의와는 다르다.

- [퀵터뷰 원본](https://www.youtube.com/watch?v=-ZeDaxqB8BM): 163.243초.
- [호텔 델루나 인터뷰 원본](https://www.youtube.com/watch?v=FcD65i_7cas): 139.051초.
- 미디어는 다운로드 시 개별 CC BY 표기를 확인했다. KMSAV 전사·메타데이터는 CC BY-NC-SA 4.0이므로 연구용 로컬 평가에 사용했다. 영상·음성·얼굴 좌표를 배포하지 않는다.

추론 전에 고른 수동 정답 발화 6개·103자에서는 padding 200/1000ms가 모두 **13오류**였다. `장만월→장만원`, 자연스러운 반복 발화 `생각하는 좀 한다고`의 누락, 마지막 `저희` 누락이 남았다. 전체 인터뷰 정답과 안정적인 speaker ID가 없어 전체 CER·DER는 계산하지 않았다. 출처·고정 구간 (로컬 검증 자료·공개본 미포함), 클립/전체 ASR·VAD (로컬 검증 자료·공개본 미포함).

### 음성 활동과 전사 시각 대조

최초 전사를 저장한 다음, 설치된 Silero 6.2를 별도 CPU 1스레드 유틸리티로 실행한다. 원음은 변경하지 않는다. 16kHz·mono·PCM16으로 정규화하며 float32 WAV도 허용한다. 고정한 Whisper 1.9.5 유틸리티의 출력은 **centiseconds**이므로 ms로 변환하고 마지막 VAD 창의 최대40ms 경계 초과만 원음 끝으로 제한한다.

ASR 시각을 앞뒤 250ms 완충한 뒤, 그 밖에 연속 750ms 이상 음성 활동이 남으면 **원음 확인 필요** 후보로 표시한다. 소음·경계 오차일 수 있어 확정 오류라고 하지 않는다. 자동 재인식은 기존 정책대로 여유 있을 때 구간당 최대1회, 결과는 사용자가 적용한다. 수동 수정이 있는 구간은 자동 후보를 만들지 않는다.

- 같은 84클립과 11분 원음에서는 새 시각 검사 후보가 **0개**였다. 실제 부분 누락이 ASR의 넓은 시각 안에 있어 검출되지 않았다. **0후보는 누락이 없다는 뜻이 아니다.** 긴 빈 전사·남은 활동·시간 오프셋·중복 예약·수동 수정 보호는 별도 회귀 검사했다.
- 59.345초 실제 음성에서 검사 자체는 0.131초였다. 최초 로드·디스크·호스트 상태가 다른 상황의 지연 상한은 아니다.
- 보조 검사 실패는 최초 전사를 실패로 바꾸지 않는다. 보조 binary 누락·손상은 core ASR 준비 상태와 분리하고 설정에서 추가 준비할 수 있다. 기존 검증 자산만으로 관리형 엔진을 실제 빌드해 확인했다. 준비 기록 (로컬 검증 자료·공개본 미포함)

## 긴 요약 변경과 내용 검사

새 요약은 `subject_quote`와 그 구절이 실제 있는 `subject_source_id`를 받는다. 인용 ID·정확한 원문 부분 문자열을 검증하고 다음 징후가 있으면 생성한 설명을 원문 발췌로 전환한다.

- 직접 원문에 없는 주어, 설명문에서 사라진 복사 주어, 다른 항목의 주어 혼입.
- 원문에 없는 숫자, 명시적 가정의 사실화, 회의 제안·담당 후보의 확정화.
- 원문에서는 목적어나 장소인 구절이 생성문에서 주체로 바뀐 명백한 조사 패턴.

조사·숫자·문구 검사는 모든 의미 관계를 증명하지 못한다. 강의의 조건·예시 상태는 유지하며 주어 검증 실패와 구분한다. 원래 모델 응답은 metadata에 보존한다. 구 작업의 주어·캐시 계약을 새 복사 규칙으로 소급 변경하지 않는다.

병합은 이미 만든 항목의 ID만 선택한다. 첫 유효 선택 후 재시도에서 더한 ID는 누적하고, 유효 선택을 한 번도 얻지 못하면 일반 사실이 있는 모든 관련 구간을 보존한다. 보호 항목이 같은 시간 범위를 덮는다는 이유로 일반 사실을 삭제하지 않는다. 재시도는 최대1회다.

부모 사망 가정·건강 진술과 후반 물 요청·마심·쓰러짐·방 진입·퇴장은 발췌에 남았다. 그러나 `외동입니다.`와 `어서 일어나세요. 방으로 들어가시라니까.`는 처음 새 결과에서 빠졌다. 앞·중간·뒤 시간 범위를 하나씩 인용하는 방식은 짧은 핵심 진술을 보장하지 못한다.

이를 숨기지 않도록 최종 인용에서 쓰이지 않은 **모든 세분화 원문**을 별도 `직접 인용하지 않은 원문 · 누락 여부 확인` 목록으로 저장했다. 화면에서 펼칠 수 있고 Markdown에도 포함한다. 길이8자 미만도 보존한다. 이미 요약문에 의역됐거나 다른 quote 경계로 남은 내용도 목록에 나올 수 있어, 이 목록을 의미 누락 정답이라고 부르지 않는다.

동일 native 응답을 새 후처리로 다시 처리했을 때, 해당 두 문장은 각각39개·80개의 별도 원문 목록에 남았다. 낭독의 `박물을 향하여`를 `박물이 … 걸어감`으로 만든 대상→행동 주체 오류도 발췌·확인 표시로 바뀌었다. **새 native 추론0회인 후처리 검증**이다. 인터뷰 후처리 (로컬 검증 자료·공개본 미포함), 낭독 후처리 (로컬 검증 자료·공개본 미포함).

### 작성한 강의·회의 제어 문장

실제 Qwen4B의 마지막 제어 시험에서 숫자·정정·미승인·계약 미결·로컬 조건은 보존됐다. 회의록의 담당 이서연·기한·김민수 후보 유지도 통과했다. 일반 요약은 명확한 강의 가정·예시를 여전히 주어 검증 경고 발췌로 돌려 `all_checks=false`였다. 이전 실행에서는 두 조건이 통과했으므로 안정적인 개선이라고 판정하지 않는다. 마지막 native 제어 시험 (로컬 검증 자료·공개본 미포함), 앞선 제어 시험 (로컬 검증 자료·공개본 미포함).

요약의 자연스러운 문장 품질·주어 역할·의미 누락은 **해결되지 않았다**. 현재 개선은 알려진 위험 설명을 발췌로 돌리고, 빠진 원문을 확인 가능하게 하며, 병합 실패가 내용을 버리지 않도록 하는 범위다.

## 화자 분리 비교

제품 의존성을 추가하지 않고 별도 Python 환경에서 공개 ONNX segmentation + WeSpeaker **ResNet34 / CAM++** embedding을 비교했다. Sherpa1.13.8, CPU2스레드, 동일 segmentation·threshold.5·10초 창/1초 이동·최소 on.3/off.5 조건이다. 모델·도구 합계 약79MB이며 SHA·버전을 기록했다. segmentation MIT, Sherpa Apache-2.0, WeSpeaker 공개 가중치는 CC BY4.0 조건이다. 모델 출처·해시·고지 (로컬 검증 자료·공개본 미포함), [공식 WeSpeaker 고지](https://github.com/wenet-e2e/wespeaker/blob/master/docs/pretrained.md).

### 서울코퍼스: 발화 tier 기반 진단

성인 인터뷰 6개 약60초 창을 clean/office/cafe로 비교했다. clean만 발화 tier의 `<IVER>`를 인터뷰어, 일반 발화를 응답자로 사용해 TURN DER를 계산했다. 알 수 없는 소리·웃음·비공개 구간은 평가 범위에서 제외하고 명시적 무음은 포함했다. ±.25초 collar와 collar0을 별도로 보존했다. 환경 혼합은 배경 화자 정답이 없어 DER를 계산하지 않았다.

| clean6개, collar0 | ResNet34 | CAM++ |
|---|---:|---:|
| 자동 추정 화자 수 | 2,2,1,1,7,5 | 6,3,5,3,6,6 |
| TURN DER | 51.16% | 64.18% |
| 2명 사전 지정 TURN DER | 42.17% | 55.26% |
| 자동 실행 native 합계 | 31.49초 | 11.37초 |

이 수치를 일반 회의 화자 정확도로 해석하면 안 된다. [서울코퍼스 원 논문](https://www.researchgate.net/publication/282475115_The_Korean_Corpus_of_Spontaneous_Speech) §2.1(p104)은 응답자만 headset mic를 쓰고 인터뷰어는 마이크를 쓰지 않았다고 명시한다. 실제 clean ResNet의 미검출85.915초 중83.032초가 인터뷰어 tier였다. tier에는 내부 쉼도 있어 이를 모두 가청 발화 누락이라고 할 수도 없다. 원음의 일부 표본과 라벨 정렬도 재확인해 큰 시간 오프셋을 발견하지 못했다.

자동 집계·로컬 원시 경로 (로컬 검증 자료·공개본 미포함) · 2명 지정 결과 (로컬 검증 자료·공개본 미포함) · [공식 코퍼스](https://www.openslr.org/113/).

## 재현

승인된 로컬 캐시를 사용한다. 기존 파일을 덮어쓰지 않도록 새 출력 경로를 사용한다.

```sh
.venv/bin/python experiments/evaluate_conversation_conditions.py --mode 250 --padding-ms 1000 --legacy --windows --output /tmp/pad1000-new.json
.venv/bin/python experiments/validate_summary_preservation.py qwen3.5:4b --output /tmp/summary-controls-new.json
.venv/bin/python experiments/validate_recording_assistance.py /private/tmp/conversation-tcp-qwen-20261014 qwen3.5:4b --cutoff-ms 666330 --kinds summary --context-limit 8192 --output /tmp/interview-summary-new.json

# 별도 비교 환경·공개 모델 준비. 앱 Python 의존성에는 추가하지 않는다.
.venv/bin/python experiments/prepare_diarization.py
.local-state/runtime/diarization-eval-venv/bin/python -m experiments.evaluate_diarization --output /tmp/diarization-new.json
.local-state/runtime/diarization-eval-venv/bin/python -m experiments.evaluate_diarization --groups clean --oracle-two-speakers --output /tmp/diarization-two-new.json
.local-state/runtime/diarization-eval-venv/bin/python -m experiments.evaluate_diarization --manifest .local-state/runtime/kmsav-eval-20261015/manifest.json --groups public-interview --output /tmp/diarization-public-new.json
```

공개 인터뷰 manifest는 원본 URL·입력 SHA·클립 시각·수동 정답을 보존한다. 원본 URL과 전사 패키지를 다시 구하고 FFmpeg16kHz mono PCM16으로 변환한 뒤 manifest와 SHA를 확인해야 한다. 전체 YouTube info JSON의 임시 미디어 URL은 저장소에 넣지 않았다. 원음·라벨 캐시가 없는 다른 PC에서 위 명령만으로 자료가 자동 준비되지는 않는다.
