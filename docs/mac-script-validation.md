# Mac 대본·필기 저장 검증

## 사용자 동작

전사는 이어진 대본으로 표시한다. 문장 클릭과 드래그는 선택 동작이며, **선택 구간 듣기 / 수정**을 누를 때 작업을 시작한다. 일부 단어만 선택해도 닿은 확정 전사 구간 전체를 재생하고 그 범위를 표시한다. 단어 시각을 글자 수로 추정하지 않는다.

여러 녹음에 걸친 선택은 각 버전의 근거를 조회해 원음별로 순서대로 재생한다. 저장된 WAV에 공백이 있으면 기존 PCM 위치 변환을 사용한다. 수정은 선택 당시 버전을 검사하고 한 문장이라도 바뀌면 전체 저장을 거절한다. 원래 인식문, 시각, ID와 과거 근거는 보존한다.

사용 예:

1. 전사 탭에서 두 문장에 걸쳐 드래그한다.
2. 선택 범위와 문장 수를 확인하고 **선택 구간 듣기**를 누른다.
3. **수정**에서 문장별 내용을 고친 뒤 **선택 문장 모두 저장**을 누른다.
4. 대본 위의 TXT 또는 Markdown 링크로 내보낸다. TXT는 이어진 본문이며 Markdown에는 구간 시각·버전 ID·원음 링크가 들어간다.

Markdown은 원음을 포함하는 묶음이 아니다. 링크는 해당 로컬 앱의 실행·인증·현재 포트가 필요하다. 외부 Markdown 뷰어의 브라우저가 인증되어 있다고 가정하지 않는다.

## 수정한 결함

- 필기 충돌을 감지한 뒤 로컬 초안의 기준 버전을 서버 버전으로 바꾸던 문제를 수정했다. 충돌 중 편집·저장·다시 열기를 거쳐도 명시적으로 해결하기 전에 최신 서버 내용을 덮지 않는다.
- 최신 버전 조회가 실패해도 충돌 상태를 유지한다. 조회 실패가 저장 가드를 해제하지 않는다.
- 부분 지우개가 획에 접하기만 했을 때 획 전체가 사라지던 경계 판정을 수정했다.
- 선택 음성 재생 도중 네이티브 탐색 막대를 시작점 이전으로 옮겨도 선택 구간으로 되돌린다. 재생 중 종료점 이상이면 현재 음성을 멈추고 다음 구간으로 이동한다. 일시정지 중 종료점 밖으로 찾으면 시작점으로 되돌리고 일시정지를 유지한다.
- 프런트엔드 worklet 빌드 검사가 실행 중인 앱의 `frontend/dist`를 덮어쓰던 부작용을 제거했다. 검사는 임시 폴더에서 빌드하고 정리한다.
- 스키마 17 이전 데이터를 흉내 내던 테스트 자료를 실제 스키마 16 구조로 교정했다. 제품 DB 마이그레이션은 변경하지 않았으며, 기존 ID·근거·과목 자료 보존 검사를 추가했다.

## 네이티브 실행에서 구분한 문제와 한계

자동 도구의 배경 실행 뒤에는 DOM이 로드되어도 검은 창과 빈 AX가 보였다. 읽기 전용 QA 계측에서 DOM·페이지 크기·서버 응답은 정상이었고, 앱 메뉴의 **Solasi 열기**로 활성화한 뒤 정상 화면을 조작할 수 있었다. 사용자 더블클릭에서도 같은 문제가 난다고 확인한 것은 아니므로 제품에 자동 새로고침을 추가하지 않았다.

QA 전용 셸 실행기는 작업 폴더 조회에서, 이어 만든 C 실행기는 `dyld`의 파일 열기에서 진입 전에 지연됐다. C 실행기를 임시 폴더로 옮긴 뒤 서버가 시작됐다. 시스템 정책상의 원인은 확정하지 않았다. 이는 QA 실행기의 문제이며 제품 실행 경로를 수정한 증거가 아니다.

설치된 실제 앱에서는 최초 녹음 시작이 한 번 권한 오류로 끝난 뒤 재시도에서 16.952초 원음을 보존했다. 별도 QA 앱에서는 클릭 브리지는 통과했지만 `getUserMedia`가 기다리는 동안 네이티브 마이크 판단 콜백에 도달하지 않았고, 사용자가 누르는 것과 같은 **종료** 동작으로 취소했다. 이 QA 시도에서 수집 성공이나 IPC 순서 오류가 입증됐다고 기록하지 않는다. 권한·시작 지연의 원인은 아직 확정하지 않았다.

장시간 실제 마이크 수집, 실제 펜 타블렛의 필압·기울기 센서, 요약의 사람 평가, 네이티브 탐색 막대를 손으로 이동하는 반복 검사는 수행하지 않았다. 탐색 범위 처리는 단위 검사와 네이티브 큐 시작·종료 확인까지이며, 렌더링 시각 단위의 정확한 재생 정지 오차는 측정하지 않았다. PDF 위 필기를 합성한 PDF/PNG 내보내기는 제공하지 않으며 이번에는 기존 JSON 초안 백업을 검증했다.

## 재현

준비한 Python 환경과 Node 환경에서 실행한다. 대형 모델 다운로드는 포함하지 않는다.

```sh
PYTHONPATH=. python -m unittest discover -s tests -v
python -m unittest experiments.test_native_validation -v
cd frontend
npm test
npm run check
npm run build
```

격리된 native QA는 `experiments/serve_native_validation.py --help`를 따른다. 새 출력 폴더를 사용하며 사용자 앱 데이터와 모델 제어 상태를 공유하지 않는다. 모델 가중치·엔진 파일만 기존 캐시를 참조한다.
