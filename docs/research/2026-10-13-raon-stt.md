# Raon-Speech-9B 한국어 전사 후보 검토

확인일: 2026-10-13 (Asia/Seoul)

확인 범위: KRAFTON 공식 모델 카드, 메타데이터·설정, 공개 추론 코드, 기술 보고서. 가중치 다운로드, 의존성 설치, `trust_remote_code` 실행, 전사 추론은 수행하지 않았다. 아래 CER은 저자 보고값이며 이 앱이나 현재 M4에서 측정한 값이 아니다.

## 판단

**Raon은 한국어 전사 품질 비교에 포함한다. 현재 Apple M4·16GiB에서 공개 원본을 기본 엔진으로 지정할 근거는 없다.** 원본 가중치만 16.86GiB이고, 공식 예시는 CUDA 실행이다. CUDA 양자화판은 별도 후보이며 동일 음성에서 품질·지연·메모리를 확인해야 한다. 이 판단은 크기와 공개 실행 경로에 따른 추론이다.

## 확인한 버전과 크기

작은 공식 API 응답의 `siblings[].size`를 합산했다. `.safetensors` 파일 크기이며 토크나이저·코드·캐시·실행 메모리는 제외한다. 가중치 본문을 받지 않았다.

| 공개판 | 확인 revision | 가중치 파일 합계 | 파일의 dtype/형식 | 공식 실행 경로 |
|---|---|---:|---|---|
| 원본 | `cd84c5bf53f6a7f8747f653dbbe7fc5e3c3471a4` | 18,105,967,634 bytes / 16.86GiB | BF16, 일부 F32 | Transformers 사용자 코드, CUDA/BF16; vLLM-Omni |
| AWQ-INT4 | `7231a57f82e65b52344a26361b4d73770711941c` | 7,823,034,274 bytes / 7.29GiB | AWQ 4bit, BF16/F32/I32 혼합 | CUDA/vLLM-Omni, AWQ/FP16 |
| FP8 | `2814f0124e05a795c2d5bdd085d48b6e2e5fb6c1` | 11,163,030,874 bytes / 10.40GiB | compressed-tensors, F8_E4M3/BF16/F32 혼합 | CUDA/vLLM-Omni |

원본 index의 `metadata.total_parameters`는 9,036,060,353, `total_size`는 18,105,806,338 bytes다. 파일 합계와 차이는 컨테이너 헤더 등을 포함하는 차이다. [고정 revision index](https://huggingface.co/KRAFTON/Raon-Speech-9B/blob/cd84c5bf53f6a7f8747f653dbbe7fc5e3c3471a4/model.safetensors.index.json)

두 양자화판은 음성 인코더·코덱·speaker encoder 등의 모듈을 양자화 제외한다. 모델 전체를 4bit/FP8로 바꾼 크기로 해석하지 않는다. 해당 카드의 양자화 성능 표는 L40S에서의 **스트리밍 TTS**이며, ASR CER과 STT 지연의 양자화 전후 비교는 제시되지 않는다. [AWQ 설정](https://huggingface.co/KRAFTON/Raon-Speech-9B-AWQ-INT4/blob/7231a57f82e65b52344a26361b4d73770711941c/config.json), [FP8 설정](https://huggingface.co/KRAFTON/Raon-Speech-9B-FP8/blob/2814f0124e05a795c2d5bdd085d48b6e2e5fb6c1/config.json), [양자화 표](https://huggingface.co/KRAFTON/Raon-Speech-9B-AWQ-INT4#benchmark-results)

## 구조와 전사 인터페이스

보고서는 Qwen3-VL-8B-Instruct에서 출발한 LLM과 음성 인코더·입력 adaptor의 결합을 설명한다. 공개 설정은 Qwen3 텍스트 모델 36층/hidden 4096, Qwen3OmniMoeAudioEncoder 24층, `aut_is_causal=false`다. TTS용 Mimi·생성 모듈도 포함하는 SpeechLM이다. [보고서 §2.1](https://arxiv.org/html/2605.23912v1#S2.SS1), [고정 설정](https://huggingface.co/KRAFTON/Raon-Speech-9B/blob/cd84c5bf53f6a7f8747f653dbbe7fc5e3c3471a4/config.json)

`RaonPipeline.stt(audio, prompt=None)`는 전사 문자열을 반환한다. 확인한 convenience API는 단어/문장 타임스탬프, 화자별 전사, 신뢰도 필드를 반환하지 않는다. optional prompt가 있으나 고유명사 교정 효과는 검증되지 않았다. 기본 생성은 sampling을 사용한다. [고정 pipeline 소스](https://github.com/krafton-ai/Raon-Speech/blob/afec41185e27653aa905d4ad28a7b8497681275e/src/raon/pipeline.py#L223)

STT 기본 설정은 `max_new_tokens=512`, `temperature=0.2`, `max_audio_chunk_length=192000`이다. 입력은 24kHz로 리샘플링하므로 내부 입력 조각은 8초다. 내부 조각화가 사용자에게 확정 전사를 증분 전달하는 실시간 API를 뜻하지 않는다. 출력 토큰 제한을 긴 강의 전체의 안전한 처리 한도로 해석하면 안 된다. [추론 설정](https://github.com/krafton-ai/Raon-Speech/blob/afec41185e27653aa905d4ad28a7b8497681275e/config/infer.yaml), [입력 processor](https://github.com/krafton-ai/Raon-Speech/blob/afec41185e27653aa905d4ad28a7b8497681275e/src/raon/utils/processor.py), [24kHz 설정](https://huggingface.co/KRAFTON/Raon-Speech-9B/blob/cd84c5bf53f6a7f8747f653dbbe7fc5e3c3471a4/config.json)

Raon-SpeechChat은 별도 full-duplex 대화 모델이다. 원본 Raon-Speech의 비인과 인코더를 causal 인코더로 교체한다. 대화의 끼어들기·응답 성능을 회의 전사의 정확도/화자 분리 성능으로 대체해 주장하지 않는다. [보고서 §2.2](https://arxiv.org/html/2605.23912v1#S2.SS2), [공식 README](https://github.com/krafton-ai/Raon-Speech)

## 현재 PC 실행 범위

공식 pipeline은 기본 `device="cuda"`, `dtype="bfloat16"`이며 전체 모델을 `.to(device)` 한다. 소스 docstring에는 CPU도 기재되어 있다. 확인한 공개 pipeline에는 MPS 검증 예, MLX backend, CPU offload/양자화 선택 인자가 없다. 임의로 `device="mps"`를 전달할 수 있다는 점만으로 모든 연산과 메모리 적합성이 검증되는 것은 아니다. [공식 로더](https://github.com/krafton-ai/Raon-Speech/blob/afec41185e27653aa905d4ad28a7b8497681275e/src/raon/pipeline.py#L61)

원본 가중치는 현재 16GiB 통합 메모리보다 크다. OS·앱·activation·KV cache까지 고려하면 공개 기본 로더의 원본 전체 적재를 이 PC의 실용적인 기본값으로 삼지 않는다. 이는 로컬 추론 실패를 실제 측정했다는 뜻이 아니다. AWQ/FP8의 작은 파일 크기도 Mac 지원 증거는 아니다. [CUDA 예시](https://huggingface.co/KRAFTON/Raon-Speech-9B#quick-start), [공식 AWQ serving](https://huggingface.co/KRAFTON/Raon-Speech-9B-AWQ-INT4#2-serve)

검색되는 `mlx-community/Raon-Speech-9B`도 확인했다. 해당 revision `7c497b45256d1f458ab9e3990400b069694b81b2`는 `library_name=transformers`, 양자화 설정 없음, 가중치 합계 18,105,967,634 bytes다. 카드 실행 예도 KRAFTON 원본의 CUDA 경로다. 저장소 이름만으로 M4·16GiB에서 검증된 MLX 모델이라고 분류하지 않는다. [커뮤니티 공개 API](https://huggingface.co/api/models/mlx-community/Raon-Speech-9B?blobs=true), [카드](https://huggingface.co/mlx-community/Raon-Speech-9B), [파일](https://huggingface.co/mlx-community/Raon-Speech-9B/tree/7c497b45256d1f458ab9e3990400b069694b81b2)

## 저자 보고 한국어 ASR 결과

| 보고서 Table 5 입력 | Raon-Speech CER (%) |
|---|---:|
| KSponSpeech-c | 6.56 |
| KSponSpeech-o | 6.96 |
| FLEURS-ko | 1.81 |

이 결과는 저자가 비교한 비슷한 규모의 SpeechLM들 사이의 결과다. 같은 표에는 Whisper, whisper-medium-komixv2, Qwen3-ASR 전사 baseline이 없으므로 이를 근거로 해당 ASR 모델보다 우수하다고 확정하지 않는다. FLEURS는 낭독, KSponSpeech는 자발화 특성을 포함하나, 이 앱의 먼 마이크·강의·다중 화자 회의·전문 고유명사 성능을 보장하지 않는다. [보고서 §5.1, Table 5](https://arxiv.org/html/2605.23912v1#S5.SS1)

보고서 데이터 섹션은 공개/사내 paired audio, 웹 오디오와 Whisper pseudo-label/relabel을 설명한다. 확인한 보고서에는 평가 음성별 학습 중복 배제 목록이나 contamination audit 결과가 없다. 중복이 있다고 단정하지 않으며, contamination-free 비교라고도 부르지 않는다. 공개 CER과 앱의 현재 5개 음성 CER은 표본·정규화·디코딩 조건이 같지 않아 직접 순위로 연결하지 않는다. [보고서 §4.1](https://arxiv.org/html/2605.23912v1#S4.SS1)

## 공식 공개 전사 데모 확인 — 2026-10-14

9B 모델 카드의 Demo 링크는 `https://raon.krafton.ai`로 연결된다. 현재 사이트에는 STT 전용 화면이 있지만, 읽기 전용 `GET /api/models` 응답은 `KRAFTON/A.X-K2-Raon-Speech-21B-A3B` 한 모델만 제공했다. 따라서 이 사이트의 현재 전사 결과를 Raon-Speech-9B의 실측값으로 기록할 수 없다. [9B 모델 카드](https://huggingface.co/KRAFTON/Raon-Speech-9B), [공식 사이트](https://raon.krafton.ai), [확인한 모델 목록](https://raon.krafton.ai/api/models)

확인한 KRAFTON 공개 Spaces 목록에는 `KRAFTON/ax-k2-raon-speech-demo`만 반환됐다. 이 데모의 소스 revision `15406fc2fedebc5e3b1db6f0bfabcddf06b5d643`도 `MODEL_ID = "KRAFTON/A.X-K2-Raon-Speech-21B-A3B"`를 지정하고, 전사 함수에서 `pipe.stt(audio)`를 호출한다. 전사 기능 자체는 확인했지만 실행 대상은 21B다. 소스 commit을 확인한 것과 실제 서버가 적재한 가중치 revision을 확인한 것은 다르며, 후자는 공개 응답에서 확인하지 못했다. [공식 공개 Spaces 목록](https://huggingface.co/api/spaces?author=KRAFTON), [고정 데모 소스](https://huggingface.co/spaces/KRAFTON/ax-k2-raon-speech-demo/blob/15406fc2fedebc5e3b1db6f0bfabcddf06b5d643/app.py), [공개 전사 API 명세](https://krafton-ax-k2-raon-speech-demo.hf.space/gradio_api/info)

9B 모델 메타데이터의 `spaces` 목록은 `tardellirs/model-pulse`, `fastgpu/vram-and-gpu-cost-calculator`, `emanforhelp/model-pulse`였으며, `inferenceProviderMapping`은 null이었다. 이번에 확인한 공식 모델 카드·조직 목록·데모 소스에서는 **실제로 9B를 적재하는 공개 STT 데모를 확인하지 못했다**. 모든 외부 서버의 부재를 입증한 것은 아니다. [9B 공개 메타데이터](https://huggingface.co/api/models/KRAFTON/Raon-Speech-9B)

조사는 공개 페이지·소스·설정에 대한 GET 요청으로 한정했다. 음성·사용자 이름 전송, 전사 실행, 로그인은 수행하지 않았다. 현재 비교표에서 Raon-Speech-9B는 저자 보고값과 실행 제약만 기재하고, 동일 음성의 실측 CER은 미측정으로 유지한다. 9B 실측 비교에는 모델과 가중치 revision을 식별할 수 있는 실행 환경이 필요하다.

## RTX 5070 Ti 16GB의 보류 조건 — 2026-10-14

사용자가 RTX5070Ti16GB 장비와 RustDesk 접근 가능 여부를 알려줬다. 사용자는 직접 시험하고, 현재는 Mac 개발을 우선하도록 요청했다. 원격 접속·설치·가중치 다운로드·전사 실행을 하지 않았다. 기본 전사와 비교 후보 상태를 유지한다.

| 조건 | 확인 결과 |
|---|---|
| GPU 기반 | RTX5070Ti의 Compute Capability는12.0이다. PyTorch2.7/CUDA12.8은 Blackwell 지원을 명시한다. [NVIDIA 표](https://developer.nvidia.com/cuda/gpus), [PyTorch 발표](https://pytorch.org/blog/pytorch-2-7/) |
| 체크포인트 | 원본18.1GB는16GB GPU에 전체 상주시킬 수 없는 크기다. 공식AWQ INT4약7.8GB는 후보지만 입력·KV·CUDA 임시 공간을 포함한 총VRAM 수치가 아니다. [공식 카드](https://huggingface.co/KRAFTON/Raon-Speech-9B-AWQ-INT4) |
| 실제 STT 경로 | 공식AWQ 카드·Hub 코드에 pipe.stt(audio.wav)가 있다. vLLM-Omni도 오디오 chat/completions 경로와 SupportsTranscription 구현을 제공한다. TTS 예제의 simulate-stt는 실제 ASR 평가가 아니다. [카드](https://huggingface.co/KRAFTON/Raon-Speech-9B-AWQ-INT4), [구현](https://github.com/krafton-ai/vllm-omni/blob/8cbabb594578b4ae4d54b20c597d1065ee92d2d7/vllm_omni/model_executor/models/raon/raon.py) |
| 의존성 | Raon은Transformers>=4.57.1,<5.0을 요구한다. Transformers4.57.3 AWQ 로더는autoawq+accelerate를 요구하고 CUDA의bf16 요청을fp16으로 바꾼다.
