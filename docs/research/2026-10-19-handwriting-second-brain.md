# 손글씨와 과목 지식 연결 조사

확인일: 2026-10-19. 상태: 조사와 제안. 손글씨 인식·자동 연결은 아직 구현하지 않았다.

## 현재 코드에서 확인한 사실

- `course_materials.save_page_document`는 PDF 해시·페이지·버전과 텍스트 및 원본 획을 함께 보존한다. 검색에는 `body.text`만 들어간다.
- `InkPoint`는 정규화 좌표·압력·선택적 기울기를 저장하며 점별 시각은 저장하지 않는다. 기존 점에 추측 시각을 부여하면 안 된다.
- `InkStroke`에는 획 ID·도구·색·굵기·불투명도·입력 장치가 있다. 형광펜은 손글씨 텍스트가 아니라 PDF의 강조 위치일 수 있다.
- 직접 실행 엔진은 Qwen3.5 4B와 지원 Gemma 프로필에서 이미지 입력을 연결한다. 이는 한국어 손글씨 정확도가 검증됐다는 뜻은 아니다.
- 원문 저장은 키워드 색인을 갱신한다. 의미 색인은 현재 별도 전체 갱신 작업이다. 새 원문을 자동으로 임베딩하는 증분 작업은 없다.
- 개념은 표준 표기·별칭·정의·근거·버전을 사용자가 저장한다. 관련 자료·전사와 문제·풀이를 조회할 수 있지만 자동 개념 추출·관계 확정은 없다.

## Mac 런타임 확인

이 Mac에서 `VNRecognizeTextRequest`의 accurate 모드와 기본 revision 3으로 지원 언어를 조회했다. 33개 중 `ko-KR`가 포함됐다. 이는 해당 API가 한국어를 지원한다는 확인이며, 손글씨 인식 정확도를 측정한 결과가 아니다.

## 인식 경로 비교

| 경로 | 적합성 | 제약 |
|---|---|---|
| Apple Vision 이미지 문자 인식 | Mac의 첫 비교 기준. 별도 대형 모델 없이 잉크 영역 이미지에서 문자·위치를 얻는 후보 | 실제 OS의 지원 언어를 런타임 확인해야 한다. 한국어 지원만으로 손글씨 품질을 단정할 수 없다. |
| 현재 로컬 Qwen/Gemma 이미지 입력 | 기존 모델을 재사용해 손글씨 인식과 도형·수식 설명 후보를 비교 | 추론 비용·환각이 있다. OCR 문자와 의미 해석을 별도 결과로 저장해야 한다. |
| ML Kit Digital Ink Recognition | Android/iOS의 향후 획 기반 후보. 공식 한국어 `ko` 모델과 오프라인 실행 지원 | 공식 지원 범위가 Android/iOS이며 Mac의 공통 런타임으로 사용할 근거가 없다. 기존 점별 시각은 누락되어 있다. |

## 제안하는 데이터 흐름

1. 사용자가 저장한 원본 획과 PDF는 유지한다. 인식 결과로 획이나 기존 텍스트 메모를 덮어쓰지 않는다.
2. 잉크 영역만 렌더링한 이미지와 동일 영역의 PDF 배경 이미지를 구분한다. 배경의 인쇄 문자가 손글씨로 들어오지 않게 한다.
3. 한국어·영문·숫자·수식·도형·화살표·형광펜을 나눈 비교 자료로 Vision과 설치된 로컬 이미지 모델을 비교한다.
4. 인식문에는 과목, 원본 PDF 해시, 페이지, 경계 상자, 관련 획 ID, 필기 버전, 엔진·모델, 검토 상태를 붙인다.
5. 문자 인식과 그림·수식의 생성 해석을 별도로 보관한다. 확실히 읽지 못한 부분을 강의 문맥으로 채우지 않는다.
6. 검색에서 원래 필기 위치로 돌아갈 수 있게 한다. 지우기·부분 지우기·수정으로 원본 버전이 달라지면 기존 인식 결과는 현재 근거에서 제외하고 재처리한다.
7. 사용자 합의에 따라 확인·수정한 인식문부터 지식 근거로 편입한다. 확인 전 후보는 답변·요약·개념 연결 근거로 사용하지 않는다.

## 세컨드 브레인 활성화 제안

- 변경된 자료·확정 전사·저장 노트·승인한 인식문만 색인 대기열에 넣는다. 같은 버전은 중복 처리하지 않는다.
- 동일 모델·동일 전처리에서만 증분 벡터를 재사용한다. 모델·형식이 바뀌면 새 색인을 완성한 뒤 전환한다.
- 기존처럼 원음 저장·전사를 우선하고, 로컬 생성에 자원을 넘긴다. 무거운 작업은 유휴 시간에 재개한다.
- 저장 이벤트에서 같은 과목의 관련 이전 기록을 먼저 검색한다. 유사도는 관계 후보를 찾는 신호이며 사실 관계의 증명이 아니다.
- 개념·별칭·연결은 원문 인용과 함께 후보로 제시한다. 제안·가정·결정 또는 상반된 진술을 하나의 사실로 자동 합치지 않는다.
- API를 사용하는 개념 추출·손글씨 처리의 자동 외부 전송은 기본으로 켜지 않는다.
- 관계 그래프 DB나 자동 장문 재요약을 먼저 추가하기보다 기존 SQLite·출처·버전·작업 경로를 확장한다.

## 합의한 정책과 후속 설계

- 확인·수정한 인식문부터 지식에 편입한다.
- 로컬 유휴 시간 자동 색인 갱신·관련 기록 및 개념 연결 후보 제안을 기본 동작으로 구체화한다. 개념은 자동 확정·병합하지 않는다.
- 상세 설계: `docs/superpowers/specs/2026-10-19-handwriting-second-brain-design.md`. 상세 설계는 사용자 승인 완료이며 구현 계획 검토 대기다. 손글씨 인식·자동화는 아직 구현되지 않았다.
