# VAD 경계·현재 구간 문맥 보존 비교

2026-10-23 · Apple M4 / 16GB · 기존 로컬 Whisper large-v3-turbo

## 적용 판정

**앞구절 사례는 개선됐지만 두 방식 모두 제품의 기본값에는 적용하지 않았다.** 2초 여백은 별도 일반 낭독에서 오류를 늘렸고, 전체 구간 방식도 다른 저음량 발화·소음·일반 낭독에서 악화했다. 원래 1초 설정과 자동 후보 보류·수동 원음 재인식·사용자 적용 정책을 유지한다.

이번 main 반영 대상은 비교 도구·회귀 검사·집계·보고서다. 제품의 전사 품질이 전체적으로 개선되거나 남은 누락이 해결됐다는 판정이 아니다.

## 목적과 범위

오디오 전처리 없이 VAD가 늦게 잡은 문장 시작을 포함하고, 발화 사이 문맥을 보존할 수 있는지 확인한다. 일반·저음량·소음·SIL의 개별 오류와 삭제 수가 늘지 않고 앞구절 또는 소음 조건을 개선한 방식만 기본 적용 대상으로 정했다. 합계 개선만으로 개별 악화를 숨기지 않는다.

여기서 문맥은 **현재 전사 구간 안의 원음**이다. 이전 전사문을 prompt로 주지 않고, 다른 구간의 PCM이나 녹음 공백을 이어 붙이지 않는다. 현재 파일·종료 후 녹음은 최대 약 30초 구간을 사용하며 실제 앱은 상대 에너지로 조용한 경계를 찾는다. 이번 짧은 고정 표본 비교가 긴 음성의 구간 경계 바깥에서 이미 잘린 음절을 복구하는 시험은 아니다.

## 세 방식

| 방식 | VAD·입력 |
|---|---|
| 기존 1초 | 기존 native VAD + 앞뒤 1,000ms padding |
| 2초 여백 | threshold·최소 발화·모델은 유지, padding만 2,000ms |
| 검출 후 전체 구간 | 기존 `speech_activity()`가 발화를 찾으면 같은 원음 전체를 native VAD 없이 인식. 정상적인 빈 목록만 보류 |

전체 구간 방식의 검사 불가·예외는 발화 없음으로 대체하지 않고 실패로 보존한다. 디지털 영점 원음만 기존 방식대로 추론을 생략한다. 비영점 SIL을 임의로 영점 처리하지 않는다. 전체 구간 방식에서 padding 값은 native VAD가 꺼져 있으므로 인식에 사용되지 않는다.

Qwen 자동 후보는 이미 발화 검출 후 원래 구간 전체를 읽는다. 이번에는 최초 전사에 해당하는 Whisper 경로를 비교했으며 Qwen 모델을 재실행하거나 hotwords를 바꾸지 않았다.

## 경계의 실제 동작

고정된 로컬 whisper.cpp 소스와 실행 경로를 확인했다. native VAD는 검출·최소 발화 길이 검사 **뒤에** padding을 붙인다. 발화를 통째로 놓친 경우에는 padding만 늘려 복구할 수 없다. 여러 발화가 가까우면 간격을 나눠 padding을 배분하고, 선택한 구간을 100ms 영점 신호·overlap과 함께 이어 인식한 뒤 원래 시각으로 매핑한다. 전체 구간 방식은 그 내부 잘라내기·이어 붙이기를 하지 않는다.

기존 저음량 사례는 raw VAD가 약 1,950~2,569ms만 검출했다. 기존 1초 설정의 전사 범위는 950~2,569ms였고, 2초 설정은 0~2,569ms를 포함했다. 이는 실제 출력 시각 대조이며 단어별 정렬이나 모든 발화의 시작 복구를 뜻하지 않는다.

## 같은 실제 한국어 자료

[앞선 저음량·생활 소음 진단](quiet-korean-vad-20261021.md) 및 [전처리 비교](local-denoise-20261021.md)와 같은 PCM·참조를 고정했다. 원음·정답 전사·모델은 공개 저장소에 포함하지 않는다.

- 서울코퍼스 실제 성인 인터뷰 3명·서로 다른 발화 6개, 반복 전 정규화 참조 106자.
- 원본 6개, 같은 원본 −20dB 6개, 사무실·식당·주방 0/−10dB 파생 혼합 36개, 목표 한국어 발화 없는 환경음 6개, 사람이 SIL로 주석한 비영점 원음 3개.
- 총 57조건·166.348초. 반복 조건 57개를 독립 발화 57개로 계산하지 않는다. 소음이 섞인 실제 현장 한국어 회의와 파생 혼합 조건을 구별한다.
- 별도 확인은 같은 로컬 FLEURS 한국어 낭독 10개·113.58초·441자를 사용했다. 과거 비교에서도 사용한 고정 자료이며 처음 보는 독립 평가 자료로 부르지 않는다. 화자 ID가 없어 10명이라고 주장하지 않는다.

세 방식의 주 비교 171행과 별도 확인 30행, 합계 201개 인식 조건을 순차 실행했다. 참조는 평가에만 사용하며 인식 모델에 제공하지 않았다. 새 모델·새 서버·외부 API·음성 증폭·노이즈 제거는 사용하지 않는다.

## 지표와 판정

기존 평가기와 같이 NFKC·소문자·문자/숫자 보존으로 정규화한 문자 편집 거리와 삭제·삽입·치환을 기록한다. 공백·문장부호는 제외하며 숫자와 영문 병기를 발음 동치로 바꾸지 않는다. 따라서 절대 오류 수를 사람이 들은 내용의 오류 확률로 해석하지 않는다. 삭제·삽입 수도 최소 편집 정렬의 문자 수이며 실제 누락·환각 사건 수가 아니다.

SIL·목표 발화 없는 환경음에는 CER 분모를 두지 않고 출력 문자 수를 기록한다. 환경음에는 배경 발화가 있을 수 있어 그 출력 전체를 의미 환각으로 확정하지 않는다. 실패가 포함된 묶음은 성공한 행만 골라 전체 정확도를 계산하지 않는다.

시간은 각 조건의 호출 전체 실측이며 전체 구간 방식에는 외부 VAD 검사도 포함한다. 한 기기에서 고정 순서로 실행했고 초기에는 회귀 검사가 함께 진행돼 안정 상태의 속도 시험은 아니다. 모델 로딩·캐시·시스템 상태의 차이 때문에 고정 가속비로 일반화하지 않는다.

## 실제 결과

새 기준 실행의 57개 출력은 이전 고정 원음 비교의 기준 출력과 문자열까지 57/57 일치했다. 세 방식 모두 주 비교 57행·별도 확인 10행을 완료했고, 처리 실패는 0행이었다. 원음 57개·자료 출처 파일 12개와 별도 낭독 10개의 해시가 유지됐다.

### 주 비교

원본·저음량은 각각 참조 106자, 소음 혼합은 636자다. SIL·목표 발화 없는 환경음의 값은 출력 문자 수다. 개별 악화는 전체 편집 거리 증가 조건 수이며 삭제 증가 조건 수도 별도 표시한다.

| 방식 | 원본 오류 | 저음량 오류 | 소음 혼합 오류 | 환경음 출력 문자 | SIL 출력 문자 | 개별 악화 /57 | 삭제 증가 /57 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 기존 1초 | 12 | 18 | 365 | 5 | 0 | 0 | 0 |
| 2초 여백 | 12 | 12 | 365 | 5 | 0 | 0 | 1 |
| 검출 후 전체 구간 | 12 | 15 | 356 | 9 | 0 | 3 | 3 |

2초 여백은 주 비교의 전체 편집 거리가 커진 조건은 없었지만, 한 식당 혼합 조건의 삭제 수가 9→13으로 늘었다. 해당 조건은 편집 거리 14로 같았고 두 출력 모두 정답을 회복하지 못했다. 이 문자 정렬 차이를 실제 누락 사건 4개로 단정하지 않으면서도 사전에 정한 보수적 삭제 증가 기준에서는 탈락시켰다. 별도 일반 낭독의 실제 악화도 아래에서 확인했다.

전체 구간 방식은 저음량 발화 한 개에서 기존 1오류→4오류·삭제 0→3으로 악화했고, 다른 소음 조건에서도 편집 거리나 삭제가 늘었다. 목표 발화 없는 식당 환경음 한 개에서는 출력이 5→9자로 늘며 자막 문구를 만들었다. 환경음 전체의 출력을 의미 환각이라고 확정하지는 않는다.

### 앞구절 누락 사례

참조 14자에 대한 같은 원음 비교다.

| 방식 | 편집 거리 | 삭제 | 삽입 |
|---|---:|---:|---:|
| 기존 1초 | 7 | 6 | 0 |
| 2초 여백 | 1 | 1 | 0 |
| 검출 후 전체 구간 | 1 | 1 | 0 |

두 대안 모두 이 사례의 오류를 7→1, 삭제를 6→1로 줄였다. 하지만 모델이 음성을 읽기 위해 전달받는 범위를 넓히는 것만으로 다른 발화의 내용 보존까지 보장하지 못했다.

### 별도 일반 낭독 10개

| 방식 | 편집 거리 합계 | 개선/동일/악화 | 삭제 증가 |
|---|---:|---|---:|
| 기존 1초 | 14 | 0/10/0 | 0 |
| 2초 여백 | 18 | 0/9/1 | 1 |
| 검출 후 전체 구간 | 16 | 0/8/2 | 0 |

2초 여백의 악화는 기존 오류 0인 문장에서 지명 오독으로 4오류(삭제 2·치환 2)가 추가된 결과다. 단순 영문 병기나 숫자 표기 차이만으로 생긴 탈락이 아니다. 전체 구간 방식의 추가 2오류 중 하나는 영문 기호 치환이고 다른 하나는 숫자/한글 표기 차이여서, 두 건 모두를 청각적 내용 누락으로 주장하지 않는다.

### 처리 시간

초 단위의 한 번씩 관찰한 호출 시간이며 모델 준비·전사 호출과 전체 구간 방식의 VAD 검사를 포함한다. 주 비교에는 빈 출력 조건도 있어 발화 구간만의 속도와 다르다.

| 방식 | 주 비교 57조건 합계 | 주 비교 중앙값 | 낭독 10개 합계 | 낭독 중앙값 |
|---|---:|---:|---:|---:|
| 기존 1초 | 91.625 | 1.875 | 21.840 | 2.060 |
| 2초 여백 | 96.631 | 1.840 | 22.611 | 2.109 |
| 검출 후 전체 구간 | 90.710 | 1.977 | 25.646 | 2.395 |

이번 시간 차이로 더 빠른 기본 경로를 선택하지 않았다. 품질 기준을 먼저 통과하지 못했고, 반복·역순·안정 상태의 지연 시험도 아니다.

## 재현과 코드 범위

기존 실험기 `compare_asr_hints.py`에 Whisper 전용 옵션만 추가했다. 기본은 이전과 같은 native VAD·1초 여백이며 Qwen 실행은 바꾸지 않는다. Qwen에 비기본 Whisper 옵션을 전달하면 인식 전에 거절한다. 새 의존성·모델 다운로드·앱 설정 항목은 추가하지 않았다.

```sh
.venv/bin/python experiments/compare_asr_hints.py \
  --engine whisper --manifest /absolute/path/to/fixed-manifest.json \
  --runtime /absolute/path/to/prepared-runtime --conditions none \
  --whisper-padding-ms 2000 --output /absolute/path/to/new-pad2.json

.venv/bin/python experiments/compare_asr_hints.py \
  --engine whisper --manifest /absolute/path/to/fixed-manifest.json \
  --runtime /absolute/path/to/prepared-runtime --conditions none \
  --whisper-vad gate-full --output /absolute/path/to/new-full.json
```

기준은 `--whisper-padding-ms 1000`으로 실행한다. 출력 파일은 없는 새 경로를 사용하고, manifest의 원음 해시·참조·그룹·용어 필드는 기존 비교기 형식을 따른다. 참조·인식문·원음 경로가 없는 [공개 집계](verification/vad-context-20261023.json)에 개별 조건의 편집 지표·그룹·결과 해시·코드 해시를 남겼다.
