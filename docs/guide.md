# Solasi 사용 가이드

[Solasi 소개](../README.md) · [설치·개발 안내](development.md)

## 처음 사용할 때

1. `~/Applications/Solasi.app`을 엽니다. 기본 설치 위치가 다른 경우 해당 앱을 여세요.
2. **모델·키 설정 → 엔진·OCR 준비**에서 필요한 항목의 용량·라이선스·저장 위치를 확인하고 준비합니다. 전사 자산은 약 1.73GB, OCR은 약 28MB입니다. 내장 앱은 전사 실행 파일을 다시 빌드하지 않고 모델·VAD 자산을 준비합니다.
3. 생성 기능에 사용할 **로컬 모델** 또는 **외부 API**를 선택합니다. OpenAI·Gemini·Claude는 API 키와 모델 ID가 필요합니다. ChatGPT 등 구독 앱의 로그인 정보는 가져오지 않습니다. 모델 접근 권한과 텍스트·이미지 지원을 설정 화면에서 확인합니다.
4. 의미 검색을 사용하려면 별도의 로컬 EmbeddingGemma를 준비합니다. **모델·키 설정 → 세컨드 브레인**의 자동 갱신이 켜져 있으면 유휴 시간에 변경된 원문을 색인합니다. **검색·개념 → 의미 색인 갱신**으로 직접 실행할 수도 있습니다. 모델 준비 전에는 키워드 검색을 사용합니다.
5. 왼쪽에서 **과목**을 만들고 자료를 연결한 뒤 강의 회차를 기록합니다. 회의와 과목 미지정 기록도 따로 만들 수 있습니다.

모델 다운로드는 사용자가 선택할 때 실행합니다. Qwen3.5 4B MLX는 약 3.97GB, EmbeddingGemma는 약 0.62GB이며, 파일 크기와 실행에 필요한 RAM은 다릅니다. 모델마다 준비 화면의 크기·라이선스를 확인하세요. 직접 실행을 지원하는 모델의 파일·해시 검증이 끝나야 준비 완료로 표시합니다.

## 과목과 자료

- 같은 과목의 PDF는 공용 자료로 연결하고, 페이지 메모·필기를 회차마다 누적합니다. 각 회차의 녹음·전사·일반 노트는 따로 보관합니다.
- PDF·PNG·JPG·UTF-8 TXT/MD는 파일 선택 창에서 **원본 위치를 연결**합니다. 원본을 옮기거나 접근을 거절하면 상태를 표시합니다. 변경된 원본은 재추출하거나 다시 선택하세요.
- **과목 → 자료**에서 PDF 원본 페이지를 봅니다. 추출된 텍스트와 그림은 검색·설명·요약에 사용하며 원본 페이지와 구분합니다.
- 페이지 메모의 텍스트는 근거 검색에 포함합니다. 손글씨는 벡터 획으로 저장하며 자동으로 검색 가능한 텍스트로 간주하지 않습니다.
- 기록을 삭제해도 외부 원본 파일은 삭제하지 않습니다. 과목 자료·페이지 메모·필기는 마지막 강의 회차를 삭제해도 유지합니다.

## PDF 메모와 필기

페이지 위에서 펜·형광펜, 획/부분 지우개, 올가미 이동·크기 조절, 실행 취소·다시 실행을 사용할 수 있습니다. 필압은 입력 기기가 전달하는 값만 사용합니다. 필기 도구와 페이지 보기 설정은 다시 열 때 이어집니다.

페이지의 **저장 상태**를 확인하세요. 저장에 실패하면 다시 불러오기·저장을 시도하거나 현재 초안을 JSON으로 내보낼 수 있습니다. 다른 창·이전 실행의 미저장 초안이 발견되면 내용을 확인해 현재 편집으로 복구할 수 있습니다. 저장 충돌 시 현재 초안과 저장된 내용을 비교해 선택하며, 선택하지 않은 내용은 사본으로 남습니다.

**메모·필기 JSON 내보내기**로 현재 페이지의 내용을 저장합니다. JSON은 원본 PDF와 필기를 합친 문서나 다른 필기 앱의 전용 파일 형식이 아닙니다. PDF 원본과 저장된 필기 색은 화면 모드를 바꿔도 유지됩니다.

## 녹음과 전사

기본 방식은 **녹음 종료 후 전사**입니다. 녹음 중에는 원음을 저장하고 종료한 뒤 전사합니다. 녹음 전에 **전사 방식 → 실시간 전사**를 선택하면 녹음 중 잠정·확정 전사를 처리합니다. 기존 음성 파일은 **녹음 파일 연결**로 전사합니다.

마이크 연결 대기가 30초를 넘으면 시작 시도를 취소합니다. 권한을 허용한 뒤 다시 시작하세요. 이미 녹음이 시작된 뒤의 정상적인 무음은 계속 저장합니다.

입력·저장 확인이 끊기면 살아 있는 마이크로 한 번 자동 복구하고 새 녹음 구간을 만듭니다. 복구에 실패하거나 마이크가 종료되면 받은 원음을 보존하고 **녹음 다시 시작**을 표시합니다. 수집되지 않은 음성을 복원하거나 빈 시간을 임의의 음성으로 채우지는 않습니다.

### 대본 듣기와 수정

1. **전사 → 대본**에서 문장을 클릭하거나 여러 문장을 드래그합니다.
2. **선택 구간 듣기** 또는 **수정**을 누릅니다. 클릭만으로 원음을 재생하지 않습니다.
3. 일부 단어만 선택해도 해당 확정 전사 구간 전체를 재생합니다. 화면에 표시된 실제 범위를 확인하세요. 서로 다른 녹음에 걸친 선택은 각 원음 연결을 따라 순서대로 재생하며 단어별 시각은 제공하지 않습니다.
4. 수정 내용을 저장하면 문장 ID·시각·원래 인식문·이전 근거 버전을 보존합니다. 최대 200개 문장을 한 번에 수정할 수 있습니다. 선택 후 전사가 바뀌었으면 저장을 거절하고 편집문을 유지합니다.

빈 전사·반복·누락 의심이나 출력 형식 오류가 표시된 구간은 원음과 재인식 후보를 확인하세요. 추가 재인식은 여유가 있을 때 최대 한 번 실행하며 후보는 직접 적용합니다. 이미 준비된 Qwen3-ASR을 사용할 수 있는 환경은 해당 후보 엔진을 사용하고, 그렇지 않으면 Whisper 경로를 사용합니다. 의심 표시가 곧 확정 오류를 의미하지 않으며 원음을 추측해 채우지 않습니다.

## 질문과 학습

### 자료에 질문하기

질문 범위는 현재 기록, 같은 과목 또는 선택 회차입니다. 답변의 출처를 열면 PDF 페이지·영역, 전사 원음 시각, 노트 버전을 확인할 수 있습니다. 저장된 결과를 다시 열 때 모델을 재호출하지 않습니다.

**검색·개념**에서 표준 표기·별칭·정의·근거를 직접 저장할 수 있습니다. 개념을 수정해도 식별자를 유지하면서 버전을 추가하며 관련 문제·풀이를 다시 열 수 있습니다. 같은 과목의 등록 용어와 회의 참석자는 전사 힌트에 사용합니다. 현재 기록에 입력한 명칭을 우선하며 실제 적용 힌트를 표시합니다. 힌트가 인식을 악화시키는 경우도 있으므로 원음과 비교하세요.

검색은 반복 근거보다 서로 다른 설명·출처를 우선합니다. 숫자·날짜·부정 표현이 다르면 별도로 유지하며 원문을 삭제하지 않습니다. 표현의 의미가 완전히 같음을 보장하는 기능은 아닙니다.

### 요약 확인하기

로컬 전체 요약은 **핵심 원문 발췌**를 우선합니다. AI가 중요한 구간을 고르고 앱이 앞 문맥과 원문을 그대로 연결하며 생성한 주어·사건 라벨을 붙이지 않습니다. 외부 API 요약은 주어·가정·조건·예시와 원문 근거를 연결해 새 문장으로 정리합니다.

긴 기록은 문맥별로 처리합니다. 앞·중간·뒤의 내용 선택이 부족하면 최대 한 번 보완한 뒤 확인할 원문을 표시합니다. 요약에 사용한 인용, 처리 범위, 직접 인용하지 않은 원문을 확인하세요. 실패한 작업에서도 완료된 구간은 열 수 있습니다. 출처 연결이 있다고 해석까지 정확한 것은 아니므로 가정·조건·예시와 사실을 대조하세요.

### 메모 보강·질문 후보·퀴즈

- **메모 보강:** 메모의 저장 시점과 가까운 확정 전사로 별도 초안을 만듭니다. 확인·수정한 내용을 새 노트 버전으로 추가하며 원래 노트를 보존합니다. 과거 노트는 녹음 시점을 직접 지정할 수 있습니다.
- **질문 후보:** 기본은 꺼짐입니다. 켜면 로컬 모델이 최소 30초 간격으로 최근 확정 전사에서 후보를 추출합니다. API 모델은 직접 추출할 때만 호출합니다. 원문 인용을 확인하고 수정·고정·무시할 수 있으며, 답변은 버튼을 눌렀을 때 생성합니다.
- **퀴즈:** 5문제와 근거·정답·채점 기준을 보관합니다. 제출 전에는 정답·채점 기준·해설을 숨깁니다. 객관식은 코드로 비교하고 자유 답안은 선택한 모델로 채점합니다. 오답·재풀이·원래 판정·사용자 수정 이력을 남깁니다.

확정 전사가 밀려 있으면 새 로컬 생성·채점·검색 임베딩은 **전사 처리 후 실행** 상태로 기다립니다. 대기 중 취소·재시도가 가능하며 제출 답안과 요청 당시 근거를 유지합니다. 이미 실행 중인 추론과 외부 API 생성은 계속합니다. API 요청도 준비 단계에서 로컬 의미 검색이 필요하면 임베딩은 전사를 기다립니다.

## 회의록

회의 참석자를 직접 입력하고 확정 전사를 바탕으로 초안을 작성합니다. 결정·담당자·기한에는 명시적인 원문 구절이 필요하며 없는 값은 미정으로 둡니다. 날짜의 원래 표현, AI 초안·편집 이력·확인 상태를 보존합니다. 제안과 결정, 실제 담당이 맞는지 원문을 대조한 뒤 확인하세요.

## 그림 질문

- **그림:** 자료의 선택 페이지나 추출 그림에 질문합니다. 벡터 그림과 WebP 추출 그림은 페이지 PNG를 사용합니다. 모델의 이미지 지원을 먼저 확인하고 선택 이미지·주변 OCR을 전달합니다. 결과는 AI 해석이며 작은 글자·손글씨·색·차트·수식은 원본과 비교하세요.
웹 검색은 제공하지 않습니다. 이전 버전에서 저장한 웹 인용과 답변은 계속 열고 내보낼 수 있습니다.

## 내보내기

| 대상 | 형식 | 포함 범위 |
| --- | --- | --- |
| 전체 대본 | TXT | 이어진 본문 |
| 전체 대본 | Markdown | 구간별 시각·버전 ID·원음 링크 |
| 요약·질문 결과·회의록 | Markdown | 저장된 내용과 근거·확인 상태 등 결과별 정보 |
| 페이지 메모·필기 | JSON | 해당 페이지의 텍스트·벡터 획 |

Mac 앱의 Markdown 원음 링크는 `solasi://audio/…` 형식이며 **같은 보관함이 필요합니다**. 원음을 포함한 휴대용 묶음이 아닙니다. 이전 HTTP 원음 링크를 포함한 문서는 자동 수정하지 않으므로 새 문서로 다시 내보내세요.

## 저장과 외부 전송

- 원음·전사·노트·필기·생성 결과는 로컬 보관함에 저장합니다. 각 기기는 독립 저장하며 계정·기기 동기화·Drive/NAS 연결은 제공하지 않습니다.
- 외부 자료·외부 오디오 원본은 앱 폴더로 복사하지 않습니다. 추출 텍스트·검색 조각·전사·결과는 앱 DB에 저장합니다. 페이지·그림 캐시는 필요할 때 만들고 총 256MiB를 기준으로 정리합니다. 앱에서 직접 녹음한 원음은 보관합니다.
- 외부 API 생성은 선택한 근거와 이미지를 해당 제공자에 전송합니다. 원음은 로컬에서 전사합니다. 키는 실행 중 메모리 또는 선택한 OS 자격증명 저장소에 보관합니다.
- API 실패 시 다른 제공자로 자동 전환하지 않습니다. 준비된 로컬 모델이 있다면 직접 선택해 재시도할 수 있습니다.
- 모델·엔진 준비는 외부 배포처에서 파일을 다운로드합니다. 질문을 위한 외부 웹 검색은 실행하지 않습니다.

## 화면과 종료

**모델·키 설정 → 화면 모드**에서 시스템 설정·라이트·다크를 선택합니다. 선택은 이 기기에 저장하며 PDF 원본과 필기 색을 바꾸지 않습니다. 아이콘 버튼의 이름은 마우스를 올리거나 보조 기술로 확인할 수 있으며 Tab과 Enter·Space로 조작할 수 있습니다.

기본 창만 닫으면 작업을 유지합니다. **⌘Q** 또는 Dock의 **종료**는 앱과 앱이 실행한 작업 엔진을 종료합니다. 종료 전 페이지 초안을 저장하며 저장하지 않은 노트·대본 수정이 있으면 창을 유지하고 안내합니다. 녹음·생성 중 종료하면 진행 중인 작업은 중단되며 저장된 원음은 보존합니다.

문제가 있으면 [알려진 한계](improvements.md)를 확인하거나 [Issues](https://github.com/car1bou/solasi/issues)에 환경과 재현 순서를 남겨 주세요. 로그 위치와 진단 방법은 [개발 안내](development.md#문제-진단)에 있습니다.

## 손글씨를 검색 근거로 사용하기

사진이나 PDF로 가져온 필기는 **과목 → 자료 → 손글씨 노트로 연결**을 체크한 뒤 파일을 선택합니다. 기존에 일반 자료로 연결한 파일도 이 옵션으로 같은 원본을 다시 선택할 수 있습니다. 이 분류는 같은 원본을 연결한 다른 과목에도 적용됩니다. 일반 강의자료에는 체크하지 않습니다.

손글씨 노트의 원래 OCR과 페이지 이미지는 자동 검색·요약·관련 기록의 근거로 사용하지 않습니다. 페이지를 열면 검토할 문서가 준비되고 유휴 시간에 인식 후보를 만듭니다. 원본 페이지와 덧쓴 펜 필기를 함께 읽으며, 페이지별로 확인·수정한 인식문만 지식으로 추가합니다. 이 노트의 **페이지 설명** 대신 승인 후 **이 페이지에 질문**이나 **자료 전체 요약**을 사용합니다. 수식의 부호·범위와 도형의 관계를 직접 대조하세요.

1. PDF 페이지에 펜으로 필기하고 저장합니다.
2. **손글씨 인식·검토**를 엽니다. 자동 처리가 켜져 있으면 유휴 시간에 Vision 후보가 만들어집니다. 직접 **빠른 인식 · Vision** 또는 **로컬 Qwen으로 인식**을 누를 수도 있습니다. Qwen은 설치된 모델이 필요하며 더 오래 걸립니다.
3. 원본 페이지 위에 표시된 당시 필기와 인식문을 비교합니다. 잘못 읽은 글자를 고친 뒤 **확인하고 지식에 추가**를 누릅니다. 확인 전 후보·거절한 후보는 질문·요약 근거로 쓰이지 않습니다.
4. **관련 기록·개념 후보**에서 같은 과목의 이전 내용을 확인합니다. 개념 후보의 인용을 검토하고 직접 저장하거나 거절합니다.

검토 중 수정한 인식문은 로컬 초안으로 저장되며 재실행 후 복구됩니다. 복구된 초안도 직접 확인하기 전에는 검색 근거에 포함되지 않습니다.

필기를 수정·지우면 이전 인식문은 현재 검색에서 제외됩니다. 예전 답변에는 당시 승인한 출처가 남습니다. 페이지 JSON 내보내기에는 인식 후보·확인 상태·연결 정보도 포함됩니다. 형광펜만 칠한 영역은 손글씨 문자로 인식하지 않습니다.

가져온 원본이 변경되거나 없어지면 그 원본에 연결된 승인문도 새 검색·요약·관련 기록에서 제외됩니다. 원본 상태를 새로고침하고 바뀐 페이지를 다시 검토하세요. 원래 인식문·승인문과 과거 출처는 삭제하지 않습니다. 손글씨 분류는 자동 감지가 아니므로 가져올 때 직접 지정해야 합니다.

검색 화면에 복구된 결과는 마지막 검색 당시의 원문을 보여 줍니다. 필기나 노트를 바꾼 뒤에는 **검색**을 다시 눌러 현재 근거를 확인합니다. 자동 연결은 승인 손글씨와 저장 노트·페이지 메모를 일반 자료의 초기 연결 처리보다 먼저 확인합니다.

**모델·키 설정 → 세컨드 브레인**에서 로컬 자동 처리를 일시 정지하거나 재개할 수 있습니다. 원음 저장·전사·사용자 요청을 우선하며 이미 시작한 추론을 강제 중단하지 않습니다. 색인을 처음 준비하거나 모델을 바꾼 경우 같은 설정에서 완료한 청크 수를 확인할 수 있습니다. 앱을 다시 열면 완료한 청크를 재사용해 이어서 처리합니다. 실패한 자동 작업은 같은 설정에서 재시도할 수 있습니다. 로컬 임베딩 모델이 없으면 키워드 검색은 계속 사용할 수 있습니다. 외부 API 모델의 개념 후보 추출은 버튼으로 실행할 때만 원문을 전송합니다.

손글씨의 읽기 품질은 필체·배치에 따라 달라집니다. 인식문은 원본을 대체하지 않으며 수식·도형의 의미를 자동으로 확정하지 않습니다.
