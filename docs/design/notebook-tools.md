# 필기 도구 · A outline

펜·형광펜·지우개·올가미·이동·실행 취소/재실행은 A 시안을 기준으로 정리한 SVG를 사용한다. 24×24 좌표계, 1.65 선 두께, 둥근 선 끝·연결, `currentColor`를 사용하며 실제 툴바는 20px다. 버튼 배경과 기존 선택 밑줄은 유지한다.

- 다른 도구를 누르면 선택한다. 선택한 펜·형광펜·지우개를 다시 누르면 설정창이 열린다.
- 펜·형광펜: 색, 굵기, 불투명도. 지우개: 획/부분 지우기와 크기.
- Escape 또는 닫기 버튼은 도구 버튼으로 포커스를 돌려준다. Tab과 방향키로 슬라이더를 조절할 수 있다.
- 설정창 밖을 누르면 닫힌다. 페이지 위 첫 입력은 닫기에만 사용해 의도치 않은 필기·삭제를 막는다.
- 기존 설정을 그대로 읽고, 다음 도구 설정 저장부터 선택 항목 `eraserMode`를 함께 저장한다. 다른 도구를 사용 중이거나 앱을 완전히 종료해도 마지막 지우개 방식을 복원한다. 구형 설정에 이 항목이 없으면 선택된 부분 지우기를 이어받고, 그 외에는 획 지우기로 시작한다.

원본 파일: `frontend/public/icons/notebook/`. 앱 경로와 동일한지 자동 검사한다. [20·24px 라이트·다크 비교](notebook-icons-a.svg).

## Mac 확인 · 2026-10-19

설치 앱 0.3.9/build19에서 PDF 페이지의 20px 아이콘, 라이트·다크 설정창, 첫 클릭 선택/재클릭 설정, 지우개 방식 전환, 펜 굵기 변경, Tab·방향키 조절, Escape 포커스 복귀를 확인했다. 비교 시트의 20·24px는 브라우저 SVG 렌더링으로 확인했다. 기존 43개 DB 테이블은 검증 후 원본과 동일했다. 프런트엔드 94개 검사와 프로덕션 빌드가 통과했다.

이번 변경은 필기 UI에 한정한다. 실제 펜 타블렛 입력과 전사·생성 성능은 재측정하지 않았다.

## 재시작·실제 필기·680px 확인 · 0.3.10/build20

- 지우개 방식은 보관함의 기존 설정 레코드에 저장하며 DB 테이블을 추가하지 않는다. 잘못된 값은 저장 전에 거부한다.
- 펜을 선택한 채 종료한 후 부분 지우기 복원, 형광펜을 선택한 채 종료한 후 획 지우기와 크기0.02 복원을 확인했다.
- 실제 Mac 마우스 입력으로 빈 PDF 페이지에 펜과 형광펜 획을 작성했다. 저장된 펜 굵기0.003, 형광펜 굵기0.02/불투명도0.45가 설정과 일치했다. 두 도구의 저장 색상도 획에 적용됐다.
- 획 지우기는 형광펜 한 획 전체만 지웠다. 실행 취소 후 부분 지우기는 같은 획의 중간을 잘라 두 조각을 남겼다. 원래 펜 획과 형광펜 조각의 색·굵기·불투명도가 유지됐고 앱 재실행 뒤에도 결과가 복원됐다.
- 동일한 제품 코드에서 초기 창 폭만680px로 지정한 별도 Mac 검증 앱과 보관함 복사본을 사용했다. 680×820 라이트·다크에서 설정창의 가로·하단 전체 표시를 확인했다. 열릴 때 전체 범위를 화면에 맞추고, 짧은 창에서는 높이를 제한해 내부 스크롤을 허용한다.
- 프런트엔드95개 검사와 네이티브 설정·작업 엔진28개 검사가 통과했다. 새 frozen engine의7826개 파일 해시와 자체 검사를 확인했다.

실제 펜 타블렛의 압력·기울기와 macOS 기본 색상 팔레트의 모든 색상 선택 동작은 이번 검증 범위에 포함하지 않았다.
