# Solasi UI

## 방향과 범위

사용자가 제공한 흑백 해·SOLASI 로고를 앱 아이콘과 화면에 적용한다. 라이트 모드는 흰 작업 화면·옅은 회색 탐색 영역·검정 주요 버튼, 다크 모드는 차콜 배경·밝은 글자를 사용한다. 얇은 구분선과 절제된 모서리로 홈·과목·대본·PDF 필기·설정을 정리했다. 색은 녹음·오류·준비 상태와 원본 자료의 구분에 사용한다.

사용자는 기존 Dock 표시 문제를 해결한 뒤 새 로고를 적용하는 순서와 위 화면 방향을 grilling 검토에서 승인했다. 수정은 ponytail 기준으로 기존 토큰·컴포넌트·AppKit API를 사용했으며 새 의존성은 없다.

녹음 수명 주기, 대본 선택·시간 연결, 모델·API 요청, 필기 좌표·저장·복구·내보내기는 유지한다. 선택·녹음 중인 세션의 mounted wrapper와 `hidden` 처리도 유지한다.

## UI UX Pro Max 적용

사용자가 지정한 로컬 `ui-ux-pro-max` 스킬의 디자인 시스템 검색·탐색 계층·React 폼 지침과 접근성 체크리스트를 적용했다. 검색의 Minimalism & Swiss Style은 작업 앱에 맞지만 함께 제안된 홍보용 Hero/CTA 배치, 청록·주황 팔레트와 영문 웹 폰트는 승인된 흑백·한국어·로컬 우선 방향과 맞지 않아 적용하지 않았다. 색과 글꼴은 아래 기존 의미 토큰과 시스템 글꼴을 사용한다.

| 영역 | 적용 |
| --- | --- |
| 홈 | 중복 큰 로고·설명 제거, 28px 제목, 작은 강의·회의 시작 카드 |
| 과목 | 중첩 카드 대신 구분선 목록, 이름·강의 수·열기 동작, 보이는 새 과목 입력 라벨 |
| 탐색 | 기본 228px / 1050px 이하 188px, 과목·회차 계층과 설정 선택 상태 |
| 준비 상태 | 준비 개수와 펼침 상세, 초기 확인 중·요청 실패 상태 구분 |
| 대본 | 최대 76ch 읽기 폭, 16px 본문·2배 행간, 선택·수정·원음 연결 유지 |
| PDF·설정 | 도구 그룹 줄바꿈, 기술 정보의 글자 계층·간격 통일, 원본 색 보존 |
| 키보드·터치 | 작업 화면 바로가기, 명시적 입력 라벨·초점 표시, coarse pointer 버튼 최소 44px, 감소된 동작 설정 존중 |
| 화면 전환 | 홈·과목·기록·설정 변경 시 문서 스크롤을 위로 복원 |

예: 새 과목은 홈 목록 아래의 `새 과목` 입력에 이름을 쓰고 `과목 추가`로 만든다. 준비 상태는 한 줄을 눌러 항목별 연결 상태를 펼쳐 본다. 키보드 첫 Tab으로 작업 화면 바로가기를 사용할 수 있다.

## 화면 모드와 토큰

`모델·키 설정 → 화면 → 화면 모드`에서 시스템·라이트·다크를 선택한다. 기본은 시스템 설정이며 이 기기에 선택을 저장한다. 저장소가 막히면 이번 실행에 적용하고 저장하지 못한 상태를 표시한다. 수동 선택은 시스템 변경보다 우선한다. PDF 원본과 저장된 잉크·충돌 미리보기 색은 반전하지 않는다.

| 용도 | 토큰 | 라이트 | 다크 |
| --- | --- | --- | --- |
| 탐색 배경 | `--nav` | `#F5F5F3` | `#1C1C1B` |
| 작업 배경 | `--canvas` | `#FFFFFF` | `#171717` |
| 카드 | `--surface` | `#FFFFFF` | `#222221` |
| 본문 | `--ink` | `#202020` | `#F1F1ED` |
| 보조 글자 | `--muted` | `#686864` | `#AEAEA8` |
| 구분선 | `--line` | `#DEDEDA` | `#3D3D39` |
| 주요 동작 | `--primary` | `#202020` | `#F1F1ED` |
| 주요 동작 글자 | `--on-primary` | `#FFFFFF` | `#202020` |
| 선택 영역 | `--selected` | `#E7E7E2` | `#393936` |

예: 새 주요 동작은 기존 `primary` 버튼을 사용하고, 내용 구획은 `card`를 사용한다. 선택한 기록 탭은 `aria-selected`, 필기 도구는 `aria-pressed`로 상태를 전달한다. 장식 SVG는 접근성 이름을 갖지 않는다. 시스템 글꼴을 사용하며 웹 폰트 요청은 없다.

## macOS 아이콘과 창

원본 PNG는 `frontend/public/solasi-icon.png`에 그대로 보존한다. `macos/Solasi.icns`는 16~1024px의 10개 표현을 포함한다. 설치기는 아이콘을 Resources에 복사하고 `CFBundleIconFile`로 지정한다. 설치본은 `0.2.1` / 빌드 `8`이다.

Finder에서 아이콘이 보여도 Dock에서는 macOS 기본 앱 아이콘이 표시되는 사례가 사용자 캡처로 확인됐다. Dock 북마크는 현재 앱으로 해석됐고, 등록 정보와 번들의 아이콘 파일도 일치했다. 해당 앱의 등록 정보 갱신·재실행만으로는 해결되지 않았다. 실행 시 번들 아이콘을 읽어 `NSApp.applicationIconImage`에 지정한 빌드 7에서 사용자가 정상 표시를 확인했고, 같은 경로로 새 흑백 아이콘을 적용한 빌드 8도 사용자가 Dock 정상 표시를 확인했다. 전체 Dock 캐시나 권한 설정을 초기화하지 않았다.

경로 표시줄을 삭제하고 macOS 제목·배경·구분선을 숨겨 본문에 통합했다. 창 버튼과 기존 창 설정은 유지한다. 시작·오류 안내는 앵커 제약으로 창 버튼 아래에 배치한다. 탐색 영역은 위에서 32px 아래에 독립 스크롤 영역을 두고 안쪽 여백 16px를 더해 브랜드 시작 위치 48px를 유지한다. 탐색 목록을 스크롤해도 창 버튼 영역에 내용이 지나가지 않게 한 수정이다. 600px 이하의 배치는 이 데스크톱 여백을 해제한다.

설치기는 기존 실행 설정과 데이터 경로·모델·포트를 보존하고 기존 앱을 백업한다. 실행 확인은 해당 실행 파일의 `txt` 매핑을 검사하므로 종료 후 권한 서비스가 파일을 읽는 상태와 실제 앱 실행을 구분한다. 실제 실행 중 교체 차단도 확인했다.

## 검증

- TypeScript 검사와 Vite 프로덕션 빌드 통과.
- 프런트엔드 검사 48개 통과: 테마·저장 실패, 녹음 복구·취소, 대본 선택·재생, 필기 지우기·충돌 등을 포함한다.
- 화면 구조 회귀 검사에서 작업 화면 바로가기·입력 label 연결·로고 중복 제거·준비 상태 펼침과 초기 문구를 확인했다.
- 주요 글자·버튼·선택·상태 표시 22개 색 조합의 계산상 대비는 최소 5.01:1이다. 전체 접근성 감사는 아니다.
- AppKit에서 ICNS를 읽고 유효성과 512px 이상 표현을 확인하는 assert 검사 통과.
- 최종 네이티브 빌드와 코드 서명 검사 통과. 기존 페이지 문서 전체 행의 SHA-256과 앱 실행 설정을 변경 전과 비교해 일치를 확인했다.
- 실제 네이티브 680px 창 캡처를 1360×1640 물리 픽셀, 즉 680×820 논리 크기로 확인했다. 흑백 리디자인의 라이트·다크 홈, 탐색 목록 스크롤, 녹음 대기·대본 탭, PDF 필기 도구와 부분 지우개 설정을 점검했다. 탐색 스크롤은 32px 창 버튼 영역 아래로 잘린다. 100% PDF는 페이지 내부를 가로 스크롤하며 원본 색·기존 필기·v7 메모를 유지한다. 창 높이 480px 확인을 의미하지 않는다.

이 기록은 디자인·창·아이콘 검증 범위다. 새 음성 인식 성능·장시간 마이크·다른 운영체제 검증을 포함하지 않는다.
