# 대화·과목별 학습 기억 — macOS 검증

2026-11-17. 구현 범위는 저장한 대화의 재개와 같은 과목의 진도·어려움·질문을 다음 대화에서 사용하는 기능이다. 원본 대화와 AI가 정리한 학습 기억은 분리하고, 기억마다 출처를 남긴다.

## 적용 내용

- 대화 생성·선택·재개, 새 대화, 생성 취소·재시도, 원문 내보내기.
- 과목별 학습 주제·진도·어려움·미해결 질문, 퀴즈 관찰 기록. 기억 확인·직접 수정·해결 표시·삭제 및 이전 맥락 사용 중지.
- 사용자 발화를 근거로 한 로컬 유휴 시간 자동 정리. AI 답변은 학습 사실로 추출하지 않는다. 제한된 대화·기억·근거만 생성 입력에 포함한다.
- 외부 제공자에 이전 맥락을 보내는 선택은 기본 해제. 자동 기억 정리에 외부 API를 호출하지 않는다.
- 기존 스키마를 보존하는 추가 테이블과 schema version 20. 세션 삭제·기억 삭제·퀴즈 정정 시 오래된 요청과 요약을 무효화한다.
- 기존 단발 근거 질의응답을 유지하고 대화로 이어가는 진입점을 제공한다.

## 실제 모델 검증

Apple Silicon Mac의 앱 내부 Qwen3.5:4b MLX 실행을 사용했다. 외부 생성 API를 사용하지 않았다. 검증용 과목·대화는 실제 사용 보관함과 분리했다.

첫 발화는 “오늘 확률 과목 PDF 20쪽까지 공부했어. 베이즈 정리의 사전확률과 사후확률이 헷갈려. 이 진도와 어려움을 기억해 줘.”였다. 로컬 모델이 주제, PDF 20쪽 진도, 사전·사후확률의 어려움과 관련 질문을 출처 문장과 함께 저장했다. 앱을 정상 종료하고 다시 실행한 뒤 대화와 네 기억이 복원됐으며, 이어진 답변이 PDF 20쪽과 헷갈린 개념을 정확히 회상했다. 관찰된 생성 시간은 첫 답변 약 50초, 재개 후 답변 약 160초였다. 이는 한 번의 실행 관찰이며 일반적인 속도 보장이 아니다.

실제 실행 중 발견한 인용 불일치와 입력 길이 문제는 원문 문장 선택, 한 발화씩 정리, 짧은 요약과 출력 예산, 사람이 읽을 수 있는 출처 별칭으로 보완했다. 모델 저장소의 기본 태그가 GGUF를 선택해 MLX 해시 검사에 실패하던 다운로드 경로도 수정했다. MLX는 카탈로그의 고정 manifest blob을 받고, 기존 manifest SHA와 모든 blob 크기·SHA 검증을 그대로 수행한다.

최종 새 대화의 첫 실행은 진도 회상 대신 일반 베이즈 설명을 반환했다. 실제 입력에 대화 0개·과목 기억 4개가 모두 포함된 것을 확인한 후, 현재 질문을 JSON 마지막으로 옮기고 회상 질문에서 학습 기록을 우선하도록 시스템 지시를 간결하게 보완했다. 관련 메모리/API 21건이 다시 통과했다. 이후 실행은 180초 제한에 걸렸다. 질문을 마지막의 독립 사용자 메시지로 분리하고 지시문을 줄이는 회귀 테스트를 추가했으며, 수정 전 실패·수정 후 통과와 메모리/API 21건 통과를 확인했다. 이 방식의 최종 재검증은 성공했다.

## 실제 앱과 자료 보존

macOS 앱 0.3.44(build 54)를 기존 설치 위치에 적용했다. 실행 경로를 유지하고 엄격한 코드서명을 검사했다. 배포 엔진의 다른 모듈 8,840개를 그대로 유지했으며, 학습 기억 관련 모듈과 모델 다운로드 함수만 교체했다. 생성한 엔진의 모든 모듈 코드 객체를 검사했다.

작업 중 별도 채팅에서 사용자가 승인한 앱 초기화가 수행됐다. 이를 되돌리지 않고 빈 보관함을 유지한다. 이전 기록은 초기화 작업이 생성한 별도 보관 자료 1,923개 파일(601,795,875바이트)과 본 작업이 초기화 전에 생성한 일관된 SQLite 사본을 보존한다. 설치 직전 보관 자료 전체의 크기·SHA-256을 재검증했다. 보존 자료에는 초기화 전부터 없던 예전 PDF 원본과 임시 검증 원음의 예외가 있으며, 상세 내용은 별도 초기화 보고서에 기록돼 있다. 보관 자료를 원래 편집 가능한 앱 보관함 전체와 동일하다고 주장하지 않는다.

설치 후 실제 앱에서 빈 홈과 설정의 “대화·학습 기억” 제어를 확인했다. 테스트용 기록을 실제 빈 보관함으로 복원하지 않는다.

## GitHub 및 공간 정리

사용자가 공개 게시를 승인한 소스·테스트·문서 123개 파일을 `codex/conversation-learning-memory-20261117` 브랜치의 `028a1411d430fc5486593613b1f0332fbfada2e2`에 저장하고 원격 SHA를 확인했다. 로컬 Git 커밋을 만들지 않았다. 다운로드 경로 보완은 후속 커밋 `404f4949f27b9cc9d1afd093238b344fe87676bf`에 저장하고 브랜치의 원격 SHA로 확인했다. DB·녹음·개인 문서·모델·키·로컬 검증 원본은 게시 대상에서 제외했다.

원격 저장 확인 후 재생성 가능한 빌드 캐시·사용하지 않는 비교 모델 캐시 15개 폴더를 정리했다. 해당 작업 구간에서 관찰한 실제 여유 공간 증가는 4,915,200,000바이트(약 4.58GiB)였다. APFS 복제본의 논리적 크기를 확보 공간으로 합산하지 않는다. 사용하는 앱·소스·모델·보관 자료와 초기화 전 DB 사본은 보호한다. 이후 사용하지 않는 이전 QA 앱 3개와 이 작업의 중복 후보 엔진 4개도 정리했다. 이 구간에는 모델 다운로드가 동시에 진행되어 여유 공간 차이를 순수 정리 효과로 합산하지 않는다.

## 검증 범위와 한계

백엔드 전체 868건을 실행해 857건 통과·9건 건너뜀·네이티브 컴파일 시간 제한 2건을 관찰했다. 두 시간 제한 검사는 캐시 재생성 후 별도 재실행에서 모두 통과했다(최종 개별 결과 859건 통과·9건 건너뜀). 프런트엔드 160건과 제품 빌드도 통과했다. 앱의 저장·재개·기억 UI, 실제 로컬 생성과 설치 서명도 검증했다. Windows·iPad·Android의 실제 설치 및 로컬 모델 실행은 이 작업에서 검증하지 않았다. 로컬 모델은 응답과 유휴 시간 정리가 오래 걸릴 수 있으며, 원문 대화는 즉시 저장되어도 학습 기억 정리는 나중에 완료될 수 있다. 최근 복원 대화는 마지막으로 수정된 대화이며, 단순히 열어본 순서와 다를 수 있다.

## 완료 기록

- 최종 새 대화: 이전 대화 0개·과목 기억 4개 입력. 실제 Qwen3.5:4b가 “PDF 20 페이지까지 공부한 '확률' 과목에서 '베이즈 정리의 사전확률과 사후확률'이 헷갈려 있습니다.”라고 정확히 응답했다. `basis=conversation`, 출처 기억 4개 연결, 입력 481토큰·출력 89토큰·약 115초였다. 시간 제한 후 재시도에도 사용자 질문은 1개로 유지됐다.
- 실제 UI에서 진도를 “PDF 25쪽까지 공부함”으로 수정하고 ‘내가 확인한 기억’ 표시를 확인했다. 네이티브 저장창으로 내보낸 JSON을 다시 읽어 대화 2개 메시지·학습 기억 4개·수정된 진도의 포함을 검증했다. 삭제·망각·정정 시 무효화는 회귀 테스트로 검증했으며 실제 사용자 기록 삭제는 수행하지 않았다.
- 검증 앱은 기존 Documents 내 경로에서 DB 열기 오류가 발생했다. DB 무결성과 같은 엔진의 명령행 시작은 정상임을 확인한 뒤, 합성 검증 DB를 임시 경로로 분리하자 GUI가 정상 시작됐다. 정확한 OS 접근 거부 원인은 확정하지 않았다. 실제 사용 앱의 보관함 위치는 그대로 유지했다.
- 실제 앱에 최종 검증 엔진을 적용하고, QA 앱과 엔진·스키마·프런트엔드의 일치를 검사했다. 최종 엔진을 통한 실제 추론은 분리된 QA 보관함에서 수행했으며 실제 빈 보관함에는 합성 기록을 만들지 않았다.
- 모델 파일 733개를 실제 앱 런타임으로 하드링크한 후 배포 asset의 무결성을 다시 검사했다. 모델 가중치를 중복 복사하지 않았다.
- 원본 로컬 검증 증거는 공개 저장 대상에서 제외했다. `final-new-conversation-proof.json`, `manual-edit-export-proof.json`, `installation-preservation.json`, `qa-installed-equivalence.json`, `final-tests.json`은 로컬 검증 출력에 남긴다.
