## 반영한 변경

- 긴 파일과 라이브 PCM은 최대30초를 유지하면서 마지막6초 안의 조용한 지점을 경계로 고른다. 20ms 단위 에너지를200ms 창으로 합산하고, 최소 에너지가 이 구간 최대의1% 미만일 때 그 창의 가운데에서 나눈다. 일정한 작은 발화는 버리지 않는다. 모든 프레임은 한 구간에 속하고, 입력 gap을 사이에 둔 구간은 나누어 처리한다.
- 30초 이상 녹음에는 VAD 앞뒤200ms 여유를 준다. 짧은 음성은 기존30ms를 유지한다. 파일 경계 분석은 PCM을 최대30초씩 메모리로 읽고 폐기한다. 외부 원본이나 전체 PCM 사본을 보관하지 않는다.
- 같은 과목에 등록한 최신 개념의 표준 표기와 현재 회의의 활성 참석자를 전사 힌트에 연결했다. 직접 입력한 명칭이 먼저 들어간다. 전체200 UTF-8바이트 안에서 이름 단위로 선택하고, 실제 전달한 문자열을 구간에 남긴다. 다른 과목·회의의 명칭은 제외한다. 원래 인식문과 사용자 수정은 보존한다.
- 임시 전사만 greedy/beam1·fallback 없음으로 계산한다. 확정 전사는 기존 디코더를 사용한다. 종료·구간 확정으로 오래된 임시 결과가 불필요해지면 실행 중인 해당 네이티브 작업을 중단하고 확정 전사를 이어간다.

이번 중앙값에서 전사 대기는40.1% 줄고 답변 전체는14.9% 늘었다. 실제 전사 시간은 우회75.25/26.59초, 적용21.72/39.32초로 편차가 크다. 모델을 상주한 상태에서 기기 전체 swap은 각 실행 후약6.54–7.60GiB였고 배경 앱·전력·열 상태를 통제하지 않았다. 속도 차이를 정책만의 인과 효과나 평상시 지연 보장으로 확정하지 않는다. provider 시간도 순수 decode 시간이나 첫 토큰 시간이 아니다.

네 실행 모두51ACK/601,920frames/gap0/확정 CER4%(2/50)였고, 적용한 두 실행에서 **전사 처리 후 실행**을 실제로 관측했다. 남은 ‘겨울에→저울의’ 오류를 자동 수정하지 않았다. ASGI 경로의 짧은 낭독이며 긴 강의·다중 화자·브라우저·실제 마이크·자유 생성의 검증을 대체하지 않는다. 최종4회 원자료 (로컬 검증 자료·공개본 미포함).

성공 비교에서 제외한 기록도 보존했다. 초기 출력 토큰 불일치 (로컬 검증 자료·공개본 미포함), 회귀 검사와 겹친 예비 측정 (로컬 검증 자료·공개본 미포함), 첫 격리 시도 중단 (로컬 검증 자료·공개본 미포함). 마지막 기록은 ASR 성공 assertion에서 중단됐으며 당시 job 오류를 직렬화하지 않아 구체적 원인을 확정하지 못했다. 이후 동일 조건으로 재실행한 위4회는 종료코드0과 `ready:true`를 확인했다.
