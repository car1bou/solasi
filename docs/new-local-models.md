# 새 로컬 모델 비교

2026-10-14. Apple M4·16GiB, macOS 27.0.1, 앱 전용 Ollama 0.40.3. 원시 결과 (로컬 검증 자료·공개본 미포함), 다운로드·manifest 확인 (로컬 검증 자료·공개본 미포함), [Gemma 4 전체 변형](gemma4-variants.md).

후속 계열 비교와 소음·자연 발화는 [E2B QAT·E4B QAT·12B 실제 비교](gemma4-actual-comparison.md)에 따로 기록한다. 아래 E2B는 기존 MLX 배포물이며 QAT 실측과 합치지 않는다.

## 설치와 비교 조건

승인한 Gemma 4 E2B MLX **7,476,595,162B**, EmbeddingGemma 2 270M MXFP8 text **442,218,503B**를 앱 전용 모델 폴더에 받았다. 두 배포물은 Apache-2.0이다. catalog의 모델 identity digest와 실제 `/api/tags` 값을 비교하고 manifest에 참조된 layer 파일의 존재·크기를 검사했다. 로컬 manifest 직렬화 파일의 SHA는 모델 identity digest와 같은 개념이 아니므로 일치한다고 주장하지 않는다.

모델은 한 번에 하나씩 실행하고 unload와 `/api/ps`의 비어 있는 상태를 확인했다. 새 기본값을 적용하지 않았다. 기존 Qwen3.5 4B·EmbeddingGemma의 설정과 기존 색인을 유지한다. 호스트 전체 swap은 비교 전에도 약 7GiB 사용 중이었으며, 깨끗한 시스템 반복 벤치마크나 모델별 GPU 최대 메모리 측정은 아니다.

## 사람 음성 ASR

기존 수집 데이터에서 명칭 포함 5개와 대조 5개, 총 10개 한국어 사람 낭독 클립을 사용했다. 각 SHA·원문·인식문을 JSON에 보존했다. FLEURS CC-BY-4.0의 기존 수집/출처 manifest를 사용하며 음성을 추가 합성하거나 이어 붙이지 않았다. 이미 확인한 자료를 재사용한 진단이므로 미공개 평가나 대표 성능으로 보지 않는다.

Gemma는 실제 OpenAI 호환 `/v1/chat/completions`의 `input_audio`로 16kHz WAV를 전달했다. 한국어 전사 지시, temperature 0, 출력 상한 1024이며 완료 사유 stop을 검사했다. 현재 앱 Whisper의 파일 연결→전사 경로와 같은 클립을 비교했다. 힌트는 두 경로 모두 사용하지 않았다. 모델별 공식 최적 프롬프트를 탐색한 결과는 아니다.

| 모델 | 정규화 CER, 낮을수록 좋음 | 명칭 정확 복원 | 10개 총 처리 시간 |
|---|---:|---:|---:|
| gemma4:e2b | 29/545 = **5.32%** | 3/6 | 76.416초 |
| whisper-large-v3-turbo | 15/545 = **2.75%** | 4/6 | 30.089초 |

CER는 NFKC·소문자·문자/숫자 보존 정규화를 쓴 진단 값이다. 영어 괄호 표기·숫자 표기 차이도 오류에 포함되며 공식 FLEURS 평가 수치와 직접 비교하지 않는다.

- Gemma는 북발트해→북파트, 깁슨→김수, 세풀베다→새풀베다와 일부 손상 문자를 출력했다.
- Whisper는 이 비교에서 북발트해를 복원했지만 깁슨→깁스, 세풀베다→새풀베다는 남았다.
- 같은 설정의 앞선 Gemma 실행은 33/545=6.06%, 47.796초였다. 현재 실행의 5.32%, 76.416초와 달라 단일 실행 속도·정확도를 고정값으로 취급하지 않는다. 앞선 결과 (로컬 검증 자료·공개본 미포함).

**E2B를 한국어 ASR 기본값으로 교체할 근거가 없다.** E4B·12B의 공식 음성 지원만으로 이 명칭 오류가 해결된다고 가정하지 않는다. 제품 음성 전사는 Whisper를 유지하며, Gemma 음성 경로는 비교 실험으로 남긴다.

## 생성과 구조화 출력

같은 작성 전사·노트에서 메모 보강, 질문 후보, 짧은 요약 두 개의 reducer를 비교했다. 아래 요약 시간은 전체 전사→구간 요약을 포함하지 않는다.

| 모델 | 메모 보강 | 질문 후보 | 두 요약 reducer |
|---|---:|---:|---:|
| qwen3.5:4b | 13.401초 | 15.778초 | 7.489초 |
| gemma4:e2b | 12.135초 | 2.602초 | 1.722초 |

이 실행에서는 두 모델 모두 schema·근거 ID·원문 인용 검사를 통과했다. 출력 길이와 선택한 내용이 달라 토큰 수를 통제한 속도 비교는 아니다. **검사 통과는 의미 정확도를 보장하지 않는다.** Qwen 카드에는 없는 ‘오늘/다음’ 시점이 추가됐고 Gemma 보강문은 뮤텍스에서 ‘한 실행 흐름’을 ‘하나의 임계 구역’으로 모호하게 바꿨다.

앞선 실행은 메모 인용 enum에 원래 메모까지 허용해 생성 후 전사 전용 검증과 불일치했다. 실제 생성 schema와 입력 예산 계산 모두 전사 ID만 허용하도록 고쳤다. 추가로 숫자의 대상·주체·부정·시점과 원문 인용을 보존하도록 지시를 보완했다. 생성 결과의 자동 의미 교정이나 성공 보장은 추가하지 않았다.

전체 기능 실제 실행 (로컬 검증 자료·공개본 미포함)은 별도 작성한 네 구간 전사와 원본 메모를 두 모델에 동일하게 제공한다. 구간 요약 두 개를 완료한 뒤 세 번째 호출 직전에 실패를 주입하고 같은 작업을 재시도해 캐시·병합·원본 보존을 검사한다. 결과와 후반 정정의 수동 대조는 [메모·요약·후보 문서](assistance.md)에 기록한다.

## 의미 검색

작성한 한국어 문서 12개·정답 질의 12개에서, 제품의 모델별 검색 prefix를 사용해 벡터 내적 순위를 비교했다. 전체 하이브리드 검색 API의 품질 평가와 구분한다.

| 모델 | 차원 | Recall@1 | Recall@3 | MRR | 12문서 임베딩 |
|---|---:|---:|---:|---:|---:|
| EmbeddingGemma | 768 | 11/12 | 11/12 | 0.9375 | 1.216초 |
| EmbeddingGemma 2 270M | 768 | 11/12 | 12/12 | 0.9444 | 1.181초 |

작은 작성 자료에서 새 모델이 한 질의의 상위 3개 진입을 개선했으나 보편적 우위를 판정하지 않는다. 새 모델은 별도 검색 profile을 사용하고 이전 색인과 섞지 않는다. 사용자가 모델을 선택하고 색인을 갱신해야 한다.
