# Solasi

수업·회의의 원음, 전사, 자료와 노트를 연결하는 로컬 앱입니다. 수업에서는 같은 과목의 이전 회차까지 검색하고 요약·퀴즈·풀이 기록을 남깁니다. 회의에서는 현재 기록으로 회의록을 작성하고 수정·확인·Markdown 내보내기를 합니다.

공개본의 범위와 원본 개발 커밋은 [PUBLIC_EXPORT.md](PUBLIC_EXPORT.md)에 기록했습니다.

## Mac 앱 실행

Mac 기본 실행 경로는 **앱에 포함한 화면·Python 작업 엔진·직접 모델 실행**입니다. 앱이나 모델용 HTTP/WebSocket 서버를 시작하지 않습니다. 모델 가중치와 사용자 기록은 기존 보관함을 재사용하며, 일반 실행에 개발 checkout·Python·Node·컴파일러 설치가 필요하지 않습니다.

`~/Applications/Solasi.app`을 더블클릭하고, 종료할 때는 **⌘Q** 또는 Dock의 **종료**를 사용합니다. 기본 창만 닫으면 진행 중인 작업을 유지합니다. 종료 전 페이지 초안을 저장하며, 저장하지 않은 노트·대본 수정이 있으면 창을 유지하고 안내합니다. 마이크 권한은 녹음 시작 시 요청합니다.

현재 패키지는 **이 Mac에서 준비한 Apple Silicon 전용 로컬 빌드**입니다. 포함된 전사 바이너리의 배포 대상 때문에 macOS 27.0 이상이 필요합니다. 독립 실행과 공개 배포용 서명·공증은 별개이며, 현재는 ad-hoc 서명입니다. 다른 Mac이나 깨끗한 OS 설치까지 검증한 배포판은 아닙니다.

### 소스에서 Mac 앱 만들기

빌드 머신에는 Python 3.12, Node/npm, Apple Command Line Tools가 필요합니다. `requirements-macos.lock`은 직접 추론·패키징을 함께 검사한 별도 고정 환경입니다. 기존 개발용 `requirements.lock`과 섞어 설치하지 않습니다.

```sh
python3.12 -m venv .venv-macos
.venv-macos/bin/python -m pip install -r requirements-macos.lock
cd frontend
npm ci
npm run build
cd ..

# 직접 임베딩 엔진 준비: docs/embedding-worker.md의 고정 archive·headers 사용
.venv-macos/bin/python scripts/freeze_macos_engine.py \
  --runtime-dir /absolute/path/to/prepared-runtime \
  --embedding-engine /absolute/path/to/embedding-engine \
  --destination /absolute/path/to/new-bundled-engine

.venv-macos/bin/python scripts/install_macos_app.py \
  --engine /absolute/path/to/new-bundled-engine \
  --data-dir /absolute/path/to/vault \
  --runtime-dir /absolute/path/to/prepared-runtime
```

새 빌드 폴더를 지정해야 하며, 모델과 기록은 엔진 패키지에 복사하지 않습니다. 빌드 기록은 포함 파일의 해시와 실제 macOS 최소 버전을 기록합니다. 새 보관함·런타임 폴더는 먼저 준비해야 합니다. 기존 앱 갱신은 `--replace`가 필요하며 기존 앱을 백업하고 보관함 경로를 유지합니다.

**이전 HTTP 버전에서 전환할 때**는 모든 창의 미저장 입력을 저장하고 앱을 종료한 다음, 기존 WebKit origin의 초안을 내보내고 가져오기·해시 대조를 마쳐야 합니다. `--draft-backup` 없는 교체는 거절합니다. [이전과 검증 절차](docs/mac-internal-runtime-validation.md)를 따르세요. 원래 IndexedDB와 앱 백업은 자동 삭제하지 않습니다.

설치 아이콘은 `macos/Solasi.icns`, 화면 아이콘 원본은 `frontend/public/solasi-icon.png`입니다. 시스템 설정을 따르는 라이트·다크 모드를 제공합니다. [UI 설계·검증과 Figma](docs/orbit-ui-design.md).

실패 로그는 `~/Library/Logs/local.solasi.launcher/engine.log`에 저장합니다. 같은 보관함을 다른 Solasi 프로세스에서 동시에 열 수 없습니다.

### 개발용 브라우저 경로

기존 개발·회귀 검사 경로는 유지합니다. 이 경로는 loopback 서버와 Ollama를 사용하며 Mac 앱의 기본 경로와 다릅니다.

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.lock
.venv/bin/python -m pip install --no-deps -e .
.venv/bin/lecture-study --data-dir /absolute/path/to/development-vault
```

## 처음 사용할 때

1. **모델·키 설정 → 엔진·OCR 준비**에서 필요한 항목의 용량·라이선스·저장 위치를 확인하고 준비합니다. 전사 준비는 약 1.73GB 다운로드에 소스·빌드·임시 공간이 더 필요합니다. OCR 약 28MB는 별도입니다. 내장 앱에서는 전사 실행 파일을 다시 빌드하지 않고 모델·VAD 자산만 준비합니다. 완료 전 파일·해시 실패는 준비 완료로 표시하지 않습니다.
2. 생성 기능은 API 또는 로컬 모델을 선택합니다. OpenAI·Gemini·Claude의 **API 키와 모델 ID**를 연결하거나 직접 실행을 검증한 로컬 모델을 준비합니다. 실제 모델 접근·텍스트·이미지 지원을 확인합니다. 구독 앱의 로그인 정보를 가져오지 않습니다.
3. 의미 검색을 사용하려면 별도의 로컬 EmbeddingGemma를 준비한 뒤 **검색·개념 → 의미 색인 갱신**을 실행합니다. 준비 전에는 키워드 검색으로 동작합니다.
4. 왼쪽에서 **과목**을 만들거나 선택해 공용 자료를 연결하고 강의 회차를 기록합니다. 같은 PDF의 페이지 메모·필기는 회차마다 누적됩니다. 회의와 과목 미지정 기록도 따로 열 수 있습니다.
5. 기본은 **녹음 종료 후 전사**입니다. 녹음 중에는 원음을 저장하고 종료하면 전사합니다. 녹음 전에 **전사 방식 → 실시간 전사**를 선택하면 잠정·확정 전사를 녹음 중 처리합니다. 기존 파일은 **녹음 파일 연결**로 전사합니다. 입력·저장 확인이 끊기면 살아 있는 마이크로 한 번 자동 복구하고 새 녹음 구간을 만듭니다. 실패하거나 마이크가 종료되면 원음을 보존하고 **녹음 다시 시작**을 표시합니다. 확정 전사를 수정해도 원래 인식문과 이전 근거 버전이 보존됩니다. 빈 전사·반복 의심 구간은 원음과 재인식 후보를 확인하고 직접 적용할 수 있습니다.

로컬 생성 후보 Qwen3.5 4B MLX는 약 3.97GB, EmbeddingGemma는 약 0.62GB입니다. 내장 앱에서는 Gemma 4 E2B와 12B의 직접 생성·이미지 입력도 검증했습니다. 다른 비교 모델은 직접 실행이 확인될 때까지 사용 가능으로 표시하지 않습니다. QAT 실측의 수정 헤더 artifact와 catalog의 Ollama 공식 배포물은 [비교 문서](docs/gemma4-actual-comparison.md)에서 구분합니다. 기본 모델은 유지합니다. 크기·manifest digest·라이선스는 준비 화면에서 확인합니다. 실제 PC의 생성 지연·RAM은 파일 크기와 다릅니다. 모델 다운로드는 사용자 선택으로 실행합니다.

### 전사 대본 듣기·수정·내보내기

- **전사 → 대본**에서 문장을 클릭하거나 여러 문장을 드래그한 뒤 **선택 구간 듣기** 또는 **수정**을 누릅니다. 클릭만으로 원음을 재생하지 않습니다.
- 일부 단어를 선택해도 닿은 확정 전사 구간 전체를 듣습니다. 표시한 실제 구간을 순서대로 재생하며, 서로 다른 녹음과 저장된 PCM의 공백도 각 원음 연결을 따라 처리합니다. 단어별 시각은 제공하지 않습니다.
- 수정은 최대 200개 문장을 한 번에 저장합니다. 문장 ID·시각·원래 인식문·이전 근거 버전을 보존합니다. 선택 뒤 전사가 바뀌면 전체 저장을 거절하고 수정 내용을 유지합니다.
- **TXT 내보내기**는 이어진 본문, **Markdown 내보내기**는 구간별 시각·버전 ID·원음 링크를 저장합니다. 내장 앱의 Markdown 원음 링크는 `solasi://audio/…` 형식이며 같은 보관함이 필요합니다. 이전에 내보낸 HTTP 링크는 자동 수정하지 않으므로 새 문서로 다시 내보내세요. 원음이 포함된 휴대용 묶음은 아닙니다.

## 자료와 출처

- **과목 → 자료**에서는 PDF 원본 페이지와 페이지별 메모·필기를 봅니다. 펜·형광펜, 획/부분 지우개, 올가미 이동·크기 조절, 실행 취소·다시 실행을 제공합니다. PDF 텍스트 추출은 검색·설명·요약을 위해 내부에서 사용합니다.
- 페이지 메모의 텍스트는 근거 검색에 포함합니다. 손글씨는 벡터 획으로 보존하며 자동으로 텍스트로 간주하지 않습니다. 필압은 기기가 전달하는 값만 사용합니다.
- PDF·PNG·JPG·UTF-8 TXT/MD는 **네이티브 파일 선택으로 원본 위치를 연결**합니다. 외부 자료와 외부 오디오 원본을 앱 폴더로 복사하지 않습니다.
- 추출 텍스트, 검색 조각, 전사와 결과를 앱 DB에 저장합니다. 페이지·그림 캐시는 필요할 때 만들고 총 256MiB를 기준으로 정리합니다. 앱이 직접 녹음한 원음은 보관합니다.
- 원본 이동·접근 거절·물리적 변경은 표시합니다. 원본이 변경되면 재추출하고 다시 선택합니다. PDF는 페이지·bbox, 전사는 원음 시간, 노트는 버전으로 근거를 엽니다.
- 기록 삭제는 앱 데이터와 연결을 정리하며 외부 원본을 삭제하지 않습니다. 과목에 연결된 자료·페이지 메모·필기는 마지막 강의 회차를 삭제해도 유지합니다.

각 기기의 데이터는 로컬에 독립적으로 저장합니다. 계정·기기 동기화·Drive/NAS 연결은 제공하지 않습니다. 현재 구현과 실행 확인은 Mac을 우선하며, Windows·Android·iPadOS 앱은 후속 개발 대상입니다. [로컬 과목·필기 설계](docs/superpowers/specs/2026-10-15-local-course-notes-design.md).

확정 구간은 최대30초이며 긴 입력은 조용한 경계를 선택합니다. 종료 후 처리도 같은 전사 모델·확정 설정을 사용합니다. 실시간 모드의 잠정 전사는10초 주기로 요청하며 처리 중에는 최신 요청을 유지합니다. 종료 시 오래된 잠정 작업을 중단해 확정 전사를 우선합니다. 재인식 후보는 검증한 Qwen3-ASR 비교 환경이 이미 설치된 Mac에서 해당 모델을 사용하고, 준비되지 않았으면 기존 Whisper 경로를 사용합니다. 후보는 원음 확인 후 직접 적용합니다. [후보 경로·무음·긴 요약 검증](docs/fidelity-followup.md).

## 질문·학습·회의·그림

- **질문:** 현재 기록/같은 과목/선택 회차의 근거를 사용합니다. 요청 시 근거 버전과 확정 전사 cutoff를 고정합니다. 같은 결과를 다시 열 때 모델을 호출하지 않습니다.
- **학습:** 새 로컬 전체 요약은 AI가 핵심 구간을 고르고 앱이 앞 문맥과 원문을 그대로 연결하는 **핵심 원문 발췌**입니다. 생성된 주어·사건 라벨은 붙이지 않습니다. 외부 API 요약은 주어·가정·조건·예시와 원문 근거를 연결하는 재서술 방식을 사용합니다. 원문은 문맥·입력 예산별로 묶으며 앞·중간·뒤 선택이 부족하면 최대1회 보완한 뒤 확인할 원문을 표시합니다. 실패한 작업에서도 완료 구간을 열 수 있고, 처리 범위·실제 인용·직접 인용하지 않은 원문을 구분합니다.
- **메모 보강:** 저장 시점과 인근 확정 전사를 연결해 별도 보강안을 만듭니다. 수정·확인한 내용을 새 노트 버전으로 추가하며 원래 노트를 보존합니다. 과거 노트는 녹음 시점을 직접 지정합니다.
- **질문 후보:** 기본은 꺼짐입니다. 켜면 로컬에서 최소 30초 간격으로 최근 확정 전사의 후보를 추출합니다. API는 직접 추출할 때만 호출합니다. 원문 인용을 확인하고 수정·고정·무시할 수 있으며 답변은 버튼으로 실행합니다.
- **퀴즈:** 5문제와 근거·정답·채점 기준을 로컬 보관함에 저장합니다. 제출 전 정답·기준·해설은 화면용 응답에서 제외합니다. 객관식은 코드로 비교하고 자유 답안은 선택 모델로 채점합니다. 오답·재풀이·원래 판정·사용자 수정 이력을 보관합니다.
- **검색·개념:** 반복되는 근거는 서로 다른 설명 뒤로 보냅니다. 감지한 숫자·날짜·부정 표현이 다르면 별도로 유지하며 원문은 삭제하지 않습니다. 표준 표기·별칭·정의·근거를 직접 저장합니다. 개념 ID를 유지하면서 버전을 갱신하고 관련 문제·풀이를 다시 엽니다. 등록한 같은 과목의 표준 표기와 현재 회의 참석자는 전사 힌트에 포함됩니다. 이번 기록에 직접 입력한 명칭을 우선하고 실제 적용 힌트를 표시합니다. 힌트로 인식이 악화되는 단어도 있어 원음과 대조합니다.
- **회의록:** 참석자를 직접 입력합니다. 생성된 결정·담당자·기한은 명시적인 확정 전사 구절을 요구하고, 없는 값은 미정입니다. 날짜의 원래 표현을 보존합니다. AI 초안·편집 이력·확인 상태와 네 섹션을 내보냅니다. 생성 모델의 의미 오류까지 검증하는 장치는 아니므로 초안을 검토합니다.
- **그림:** 자료의 선택 페이지 또는 추출 그림에 질문합니다. 벡터 그림은 페이지 PNG를 사용합니다. 모델의 이미지 지원을 먼저 확인하고 선택 이미지·주변 OCR을 전달합니다. 결과는 AI 해석으로 표시합니다. WebP 추출 그림은 페이지 질문을 사용합니다. 작은 글자·손글씨·색·차트·수식은 원본과 대조합니다.
- **웹 참고:** 별도 Exa 키가 있을 때만 사용자가 입력한 검색어를 전송합니다. 실제 반환 URL·본문 구절·조회 시각을 저장하고 내부 자료와 구분합니다. 키가 없거나 검색이 실패하면 상태를 표시합니다.

확정 전사가 밀려 있으면 새 로컬 답변·요약·메모 보강·질문 후보·서술형 채점·검색 임베딩을 기다리게 하고 **전사 처리 후 실행**을 표시합니다. 대기 중 취소·같은 요청 재시도가 가능하며, 제출한 답안과 요청 당시 근거 버전은 유지합니다. 이미 실행 중인 추론과 외부 API 생성 호출은 계속합니다. 외부 API 답변도 준비 단계에 로컬 의미 검색이 필요하면 해당 임베딩은 전사를 기다립니다.

API 생성 요청은 선택한 근거와 이미지를 해당 제공자에 전송합니다. 원음은 로컬 전사합니다. API 실패를 다른 제공자로 자동 전환하지 않으며, 사용자가 준비된 로컬 모델로 명시적으로 재시도할 수 있습니다. 키는 실행 중 메모리 또는 선택한 OS 자격증명 저장소에 보관합니다.

개발용 브라우저 실행의 앱 Ollama는 전용 loopback 포트와 모델 폴더, cloud 비활성화를 사용합니다. 공식 Ollama `serve`는 표준 `~/.ollama`의 identity와 서버 설정을 참조할 수 있습니다. 완전히 격리된 홈 환경은 제공하지 않습니다.
